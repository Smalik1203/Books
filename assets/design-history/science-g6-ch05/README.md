# Class 6 Science — Chapter 5

Independent authoring entry point for **Measurement of Length and Motion**, using the shared Class 6/7 Science edition: 189 × 272 mm, Source Serif 4 / Source Sans 3, full-size body copy, soft Investigate panels, and the shared Think It Through icon. Chapters 1–4 and 10 are not regenerated by this entry point.

The supplied 22-page PDF is traced by hash and source-page coverage in `source-coverage.json`. The editorial ledger records the complete rewritten lesson, seven investigations, thirteen assessment questions and six further activities. Comparison tables preserve qualifiers; activities and questions stay whole.

Generated painted PNGs have real alpha transparency. The pencil viewport crops transparent margin without changing the source bitmap, so its endpoints can align with live, evenly spaced SVG ruler graduations. Diagrams are not full-size measuring instruments. The main contextual scene is 874 units wide; identification images are smaller, the playground scene is 380 units high, and figures do not grow to fill gaps. Short lesson pages are documented with their protected next blocks in `render-audit.json`. Glossary, summary and final assessment pages end naturally.

Regenerate and verify:

```sh
node build/compose-science-g6-ch05.mjs
node build/record-science-g6-ch05.mjs
node build/build.mjs class-6/ch05-measurement-length-motion --pdf --bleed
node build/audit-science-g6-ch05.mjs
node build/check-science-g6-ch05.mjs
node build/check-reference-fit.mjs class-6/ch05-measurement-length-motion --block=89,963
node build/check-science-regressions.mjs
python build/proof-science-g6-ch05.py
```

PDFs and review images remain local under the repository ignore rules. Final full-page PDF proofs are rendered through Poppler, including footer and trim. `export-verification.json` records both trim and bleed page sizes and image transparency.
