The distance formula

The distance between the points $P(x_1, y_1)$ and $Q(x_2, y_2)$ is

$$PQ = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

This is called the distance formula.

Remarks. 1. In particular, the distance of a point $P(x, y)$ from the origin $O(0, 0)$ is ${OP = \sqrt{x^2 + y^2}}$.  2. We can also write ${PQ = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}}$. (Why?)

Example 1

Do the points $(3, 2)$, $(-2, -3)$ and $(2, 3)$ form a triangle? If they do, name the type of triangle they form.

Call the given points $P(3, 2)$, $Q(-2, -3)$ and $R(2, 3)$. Let us use the distance formula to find PQ, QR and PR.

${PQ = \sqrt{(3 + 2)^2 + (2 + 3)^2} = \sqrt{5^2 + 5^2} = \sqrt{50} = 7.07}$ (approx.)

${QR = \sqrt{(-2 - 2)^2 + (-3 - 3)^2} = \sqrt{(-4)^2 + (-6)^2} = \sqrt{52} = 7.21}$ (approx.)

${PR = \sqrt{(3 - 2)^2 + (2 - 3)^2} = \sqrt{1^2 + (-1)^2} = \sqrt{2} = 1.41}$ (approx.)

The sum of any two of these distances is greater than the third distance, so the points P, Q and R form a triangle. Also ${PQ^2 + PR^2 = 50 + 2 = 52 = QR^2}$, so by the converse of the Pythagoras theorem, ${\angle P = 90^\circ}$. So PQR is a right triangle. If one distance had been equal to the sum of the other two, the three points would have been on one line.
