The diagonals AC and BD bisect each other, so they have the same mid-point. The mid-point of AC is ${\left(\frac{7}{2}, 4\right)}$. If D is $(x, y)$, the mid-point of BD is ${\left(\frac{3 + x}{2}, \frac{5 + y}{2}\right)}$. So ${3 + x = 7}$ and ${5 + y = 8}$, which give ${D = (4, 3)}$. As a check, ${AB = \sqrt{4 + 9} = \sqrt{13}}$ and ${DC = \sqrt{4 + 9} = \sqrt{13}}$, so the opposite sides AB and DC are equal, as they should be.

Is there a point on the $x$-axis whose distance from the point $(1, 3)$ is 2 units?

A point on the $x$-axis is $(x, 0)$. Its distance from $(1, 3)$ is 2 if ${(x - 1)^2 + 9 = 4}$, that is, ${(x - 1)^2 = -5}$. A square is never negative, so no value of $x$ works, and there is no such point. The picture agrees: the point $(1, 3)$ is 3 units above the $x$-axis, so every point of the axis is at least 3 units away from it.
