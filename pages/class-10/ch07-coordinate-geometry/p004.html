Then ${PT = 11}$ units and ${QT = 7}$ units. (Why?) Using the Pythagoras theorem in the right triangle PTQ, we get ${PQ = \sqrt{11^2 + 7^2} = \sqrt{170}}$ units. Since ${13^2 = 169}$, this distance is a little more than 13 units, which you can check by measuring on graph paper.

Now let us find the distance between any two points $P(x_1, y_1)$ and $Q(x_2, y_2)$. Draw PR and QS perpendicular to the $x$-axis. From the point P, draw a perpendicular to QS, meeting it at the point T (Fig. 7.5). The figure shows both points in the first quadrant, with Q above and to the right of P, so that the lengths are easy to read.

Then ${OR = x_1}$ and ${OS = x_2}$, so ${RS = x_2 - x_1 = PT}$. Also ${SQ = y_2}$ and ${ST = PR = y_1}$, so ${QT = y_2 - y_1}$. Now, using the Pythagoras theorem in $\triangle PTQ$, we get

${PQ^2 = PT^2 + QT^2}$

${PQ^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2}$

A distance is never negative, so we take only the positive square root. This gives the following result.

The distance formula

The distance between the points $P(x_1, y_1)$ and $Q(x_2, y_2)$ is

$$PQ = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

This is called the distance formula.

Remarks. 1. In particular, the distance of a point $P(x, y)$ from the origin $O(0, 0)$ is ${OP = \sqrt{x^2 + y^2}}$.  2. We can also write ${PQ = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}}$. (Why?)
