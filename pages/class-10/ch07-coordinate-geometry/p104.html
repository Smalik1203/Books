Example 6

Prove that the points $A(-1, 1)$, $B(3, -1)$, $C(4, 1)$ and $D(0, 3)$, taken in order, are the vertices of a rectangle.

Solution.

Step 1 ${AB^2 = 4^2 + (-2)^2 = 20}$ and ${CD^2 = (-4)^2 + 2^2 = 20}$ distance formula
Step 2 ${BC^2 = 1^2 + 2^2 = 5}$ and ${DA^2 = (-1)^2 + (-2)^2 = 5}$
Step 3 ${AB = CD}$ and ${BC = DA}$, so ABCD is a parallelogram opposite sides equal
Step 4 ${AC^2 = 5^2 + 0^2 = 25}$ and ${BD^2 = (-3)^2 + 4^2 = 25}$ the diagonals
Step 5 ${AC = BD = 5}$ equal diagonals
Answer A parallelogram with equal diagonals is a rectangle, so ABCD is a rectangle

Since ${AB^2 = 20}$ and ${BC^2 = 5}$, neighbouring sides are not equal, so the rectangle is not a square.

Example 7

Find the point on the $x$-axis which is equidistant from $A(-2, 5)$ and $B(2, -3)$.

Solution.

Step 1 let the point be $P(x, 0)$ it is on the $x$-axis
Step 2 ${(x + 2)^2 + 25 = (x - 2)^2 + 9}$ ${PA^2 = PB^2}$
Step 3 ${4x + 29 = -4x + 13}$, so ${8x = -16}$ and ${x = -2}$ $x^2$ cancels
Check ${PA = \sqrt{0 + 25} = 5}$ and ${PB = \sqrt{16 + 9} = 5}$
Answer $(-2, 0)$
Example 8

The point $P(x, y)$ is equidistant from $A(5, 1)$ and $B(-1, 5)$. Prove that ${3x = 2y}$.

Solution.

Step 1 ${PA^2 = PB^2}$ given ${PA = PB}$
Step 2 ${(x - 5)^2 + (y - 1)^2 = (x + 1)^2 + (y - 5)^2}$ distance formula
Step 3 ${-10x + 25 - 2y + 1 = 2x + 1 - 10y + 25}$ $x^2$ and $y^2$ cancel
Step 4 ${-12x + 8y = 0}$ collecting terms
Answer ${8y = 12x}$, that is, ${3x = 2y}$
