${AQ = RS = OS - OR = x - x_1}$

${PC = ST = OT - OS = x_2 - x}$

${PQ = PS - QS = PS - AR = y - y_1}$

${BC = BT - CT = BT - PS = y_2 - y}$

Putting these values in (1), we get

$$\dfrac{m_1}{m_2} = \dfrac{x - x_1}{x_2 - x} = \dfrac{y - y_1}{y_2 - y}$$

taking $\dfrac{m_1}{m_2} = \dfrac{x - x_1}{x_2 - x}$, we get ${m_1x_2 - m_1x = m_2x - m_2x_1}$

so ${(m_1 + m_2)x = m_1x_2 + m_2x_1}$, and $x = \dfrac{m_1x_2 + m_2x_1}{m_1 + m_2}$

in the same way, taking $\dfrac{m_1}{m_2} = \dfrac{y - y_1}{y_2 - y}$, we get $y = \dfrac{m_1y_2 + m_2y_1}{m_1 + m_2}$

The section formula

The coordinates of the point $P(x, y)$ which divides the line segment joining the points $A(x_1, y_1)$ and $B(x_2, y_2)$ internally in the ratio ${m_1 : m_2}$ are

$$\left(\dfrac{m_1x_2 + m_2x_1}{m_1 + m_2},\ \dfrac{m_1y_2 + m_2y_1}{m_1 + m_2}\right) \qquad (2)$$

This is known as the section formula.

You can also get this formula by drawing perpendiculars from A, P and B to the $y$-axis and working in the same way.

In the section formula, ${PA : PB = m_1 : m_2}$ and P lies between A and B. If P lies on the line AB but outside the segment AB, with ${PA : PB = m_1 : m_2}$, we say that P divides the segment AB externally. You will study the section formula for that case in higher classes.

If the ratio in which P divides AB is ${k : 1}$, then the coordinates of P are

$$\left(\dfrac{kx_2 + x_1}{k + 1},\ \dfrac{ky_2 + y_1}{k + 1}\right)$$
