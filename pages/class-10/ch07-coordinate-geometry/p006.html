${AB = \sqrt{(1 - 4)^2 + (7 - 2)^2} = \sqrt{9 + 25} = \sqrt{34}}$

${BC = \sqrt{(4 + 1)^2 + (2 + 1)^2} = \sqrt{25 + 9} = \sqrt{34}}$

${CD = \sqrt{(-1 + 4)^2 + (-1 - 4)^2} = \sqrt{9 + 25} = \sqrt{34}}$

${DA = \sqrt{(1 + 4)^2 + (7 - 4)^2} = \sqrt{25 + 9} = \sqrt{34}}$

${AC = \sqrt{(1 + 1)^2 + (7 + 1)^2} = \sqrt{4 + 64} = \sqrt{68}}$

${BD = \sqrt{(4 + 4)^2 + (2 - 4)^2} = \sqrt{64 + 4} = \sqrt{68}}$

So ${AB = BC = CD = DA}$ and ${AC = BD}$. All four sides of the quadrilateral ABCD are equal, and its diagonals AC and BD are also equal. So ABCD is a square. Four equal sides alone would not be enough: a rhombus has them too.

Another way. Find the four sides and one diagonal, say AC, as above. Here ${AD^2 + DC^2 = 34 + 34 = 68 = AC^2}$. So by the converse of the Pythagoras theorem, ${\angle D = 90^\circ}$. A quadrilateral with all four sides equal and one angle of $90^\circ$ is a square. So ABCD is a square.
