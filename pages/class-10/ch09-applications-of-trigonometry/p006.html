We know the height AB of the building, so start with the right triangle PAB.

$\tan 30^\circ = \dfrac{AB}{AP}$,   so   $\dfrac{1}{\sqrt{3}} = \dfrac{10}{AP}$,   which gives ${AP = 10\sqrt{3}}$

So the building is ${10\sqrt{3}}$ m, or 17.32 m, from P. Now let ${DB = x}$ m. Then ${AD = (10 + x)}$ m, and in the right triangle PAD,

$\tan 45^\circ = \dfrac{AD}{AP}$,   so   $1 = \dfrac{10 + x}{10\sqrt{3}}$

${10 + x = 10\sqrt{3}}$,   so   ${x = 10(\sqrt{3} - 1) = 7.32}$

So the flagstaff is 7.32 m long.
