in right $\triangle PBD$,   $\dfrac{PD}{BD} = \tan 30^\circ = \dfrac{1}{\sqrt{3}}$,   so   ${BD = PD\sqrt{3}}$

in right $\triangle PAC$,   $\dfrac{PC}{AC} = \tan 45^\circ = 1$,   so   ${PC = AC}$

Also ${PC = PD + DC}$, so ${PD + DC = AC}$. Since ${AC = BD}$ and ${DC = AB = 8}$ m, this gives ${PD + 8 = BD = PD\sqrt{3}}$. (Why?)

${PD(\sqrt{3} - 1) = 8}$,   so   $PD = \dfrac{8}{\sqrt{3} - 1} = \dfrac{8(\sqrt{3} + 1)}{(\sqrt{3} + 1)(\sqrt{3} - 1)} = 4(\sqrt{3} + 1)$

So the height of the multi-storeyed building is ${PC = 4(\sqrt{3} + 1) + 8 = 4(3 + \sqrt{3})}$ m, and the distance between the two buildings is also ${AC = PC = 4(3 + \sqrt{3})}$ m.

Example 7

From a point on a bridge across a river, the angles of depression of the banks on opposite sides of the river are $30^\circ$ and $45^\circ$. If the bridge is 3 m above the banks, find the width of the river.

In Fig. 9.10, A and B are points on the banks on opposite sides of the river, so AB is the width of the river. P is a point on the bridge 3 m above the banks, so ${DP = 3}$ m. We need the side AB of $\triangle APB$.

Here ${AB = AD + DB}$. As in Example 6, the angles of depression at P are equal to the angles at A and B, which are alternate angles. So in right $\triangle APD$, ${\angle A = 30^\circ}$.

$\tan 30^\circ = \dfrac{PD}{AD}$,   so   $\dfrac{1}{\sqrt{3}} = \dfrac{3}{AD}$,   which gives ${AD = 3\sqrt{3}}$

In right $\triangle PBD$, ${\angle B = 45^\circ}$, so ${BD = PD = 3}$ m. Then

${AB = BD + AD = 3 + 3\sqrt{3} = 3(1 + \sqrt{3})}$

So the river is ${3(1 + \sqrt{3})}$ m wide.
