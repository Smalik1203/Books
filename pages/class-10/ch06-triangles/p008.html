Here $\frac{AB_1}{B_1B} = \frac{AC_1}{C_1C}$, each equal to $\frac{1}{4}$, and you can see that the lines $B_1C_1$ and BC are parallel, that is, $B_1C_1 \parallel BC$. In the same way, by joining $B_2C_2$, $B_3C_3$ and $B_4C_4$, you can see that

$\dfrac{AB_2}{B_2B} = \dfrac{AC_2}{C_2C} = \dfrac{2}{3}$   and   $B_2C_2 \parallel BC$

$\dfrac{AB_3}{B_3B} = \dfrac{AC_3}{C_3C} = \dfrac{3}{2}$   and   $B_3C_3 \parallel BC$

$\dfrac{AB_4}{B_4B} = \dfrac{AC_4}{C_4C} = \dfrac{4}{1}$   and   $B_4C_4 \parallel BC$

So if a line divides two sides of a triangle in the same ratio, the line is parallel to the third side. You can repeat the activity with an angle XAY of a different size and any number of equal parts on AX and AY, and each time you will get the same result. This gives the following theorem, which is the converse of Theorem 6.1.

Theorem 6.2

If a line divides any two sides of a triangle in the same ratio, then the line is parallel to the third side.

This theorem can be proved by taking a line DE such that ${\frac{AD}{DB} = \frac{AE}{EC}}$ and supposing that DE is not parallel to BC (Fig. 6.12). If DE is not parallel to BC, draw a line DE′ parallel to BC. Then

$\dfrac{AD}{DB} = \dfrac{AE'}{E'C}$   (Why?)

so $\dfrac{AE}{EC} = \dfrac{AE'}{E'C}$   (Why?)

Adding 1 to both sides of the second line, you can see that E and E′ must be the same point. (Why?)
