The point $B(6, 0)$ lies on both lines $AB$ and $PQ$. So the solution of the pair of linear equations is $x = 6$ and $y = 0$, and the pair is consistent. You can check this: $6 + 3 \times 0 = 6$ and $2 \times 6 - 3 \times 0 = 12$.

Example 2

Find out graphically whether this pair of equations has no solution, a unique solution or infinitely many solutions.

$$5x - 8y + 1 = 0 \qquad 3x - \frac{24}{5}y + \frac{3}{5} = 0$$

Multiplying the second equation by $\frac{5}{3}$, we get $5x - 8y + 1 = 0$. This is the same as the first equation. So the lines of the two equations coincide, and the pair has infinitely many solutions. Plot a few points on graph paper and check this yourself.
