$9x - 4y = 2000$   (1)

$7x - 3y = 2000$   (2)

Step 1Multiply (1) by 3 and (2) by 4, to make the coefficients of $y$ equal: $27x - 12y = 6000$ (3) and $28x - 12y = 8000$ (4).
Step 2Subtract (3) from (4). The terms in $y$ cancel: $(28x - 27x) - (12y - 12y) = 8000 - 6000$, that is, $x = 2000$.
Step 3Put $x = 2000$ in (1): $9 \times 2000 - 4y = 2000$, so $4y = 16000$ and $y = 4000$

So $x = 2000$ and $y = 4000$, and the monthly incomes are ₹18,000 and ₹14,000. Check: $18000 : 14000 = 9 : 7$, and their spending is $16000 : 12000 = 4 : 3$. Each of them saves ₹2000, since $18000 - 16000 = 14000 - 12000 = 2000$.

This is called the elimination method, because we first eliminate one variable to get a linear equation in one variable. Here we eliminated $y$; try eliminating $x$ instead. You could also have solved this problem by substitution or by drawing a graph. Try both, and see which way is most convenient. Whichever method you use, the answer must come out the same, because the pair has only one solution.

The elimination method

Step 1. Multiply both equations by suitable non-zero numbers, so that the coefficients of one variable ($x$ or $y$) become equal in size.

Step 2. Add or subtract the equations so that this variable is eliminated. If you get an equation in one variable, go to Step 3. If you get a true statement with no variable, the pair has infinitely many solutions. If you get a false statement with no variable, the pair has no solution.

Step 3. Solve the equation in one variable.

Step 4. Put this value in either of the original equations, to get the value of the other variable.
