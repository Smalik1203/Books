Using What You Know

The chapter showed you how to solve a pair of linear equations, and how the coefficients tell you whether a pair has one solution, none or infinitely many. What changes now is that a question may ask for something other than $x$ and $y$, or ask about a whole family of equations.

Given that $3x + 2y = 11$ and $2x + 3y = 4$, find $x + y$ and $x - y$.

Adding the two equations gives $5x + 5y = 15$, so $x + y = 3$. Subtracting the second from the first gives $x - y = 7$. We never needed $x$ and $y$ themselves, although they now follow easily: adding $x + y = 3$ and $x - y = 7$ gives $2x = 10$, so $x = 5$ and $y = -2$.

For which value of $k$ does the pair $x + 2y = 3$ and $3x + ky = 9$ have infinitely many solutions? Is there a value of $k$ for which it has no solution?

For infinitely many solutions we need $\frac{1}{3} = \frac{2}{k} = \frac{3}{9}$. The last ratio is already $\frac{1}{3}$, so $k = 6$. For no solution we would need $\frac{1}{3} = \frac{2}{k}$ but $\frac{3}{9} \neq \frac{1}{3}$. The second condition can never hold, because $\frac{3}{9}$ is $\frac{1}{3}$ whatever $k$ is. So no value of $k$ gives a pair with no solution: for $k = 6$ the lines coincide, and for every other $k$ they intersect.

Riya says that $x = 1$, $y = 1$ satisfies both $3x - y = 2$ and $6x - 2y = 4$, so it is the only solution of the pair. Is she right?

The values do satisfy both equations: $3 - 1 = 2$ and $6 - 2 = 4$. But $\frac{3}{6} = \frac{-1}{-2} = \frac{2}{4}$, so the second equation is just the first multiplied by 2, and the lines coincide. The pair has infinitely many solutions; for example, $x = 0$, $y = -2$ is another. Finding one solution does not show that it is the only one.
