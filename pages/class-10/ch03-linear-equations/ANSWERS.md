## 3.1 Introduction

### Akhila at the fair

*How would you find out how many rides she had, and how many games of Hoopla
she played?* and *Can we find the solutions of this pair of equations?*

- $y = \dfrac{1}{2}x$ and $3x + 4y = 20$.
- Putting $y = \dfrac{1}{2}x$ in the second equation: $3x + 2x = 20$, so $5x = 20$.
- $x = 4$, $y = 2$: **4 rides on the Giant Wheel and 2 games of Hoopla.**
- Check: $3 \times 4 + 4 \times 2 = 20$ rupees.

## 3.3 Algebraic Methods

  $63x - 28y = 14000$ and $63x - 27y = 18000$; subtracting gives $y = 4000$,

### Exercise Set 3.2

1. - (i) $x = 14 - y$, so $14 - 2y = 4$: **$x = 9$, $y = 5$**.
   - (ii) $s = t + 3$, so $2(t + 3) + 3t = 36$ and $5t = 30$: **$s = 9$, $t = 6$**.
   - (iii) $y = 3x - 3$, and then $9x - 3(3x - 3) = 9$ is $9 = 9$, true for
     every $x$: **infinitely many solutions**, every point of $y = 3x - 3$.
   - (iv) Multiplying by 10: $2x + 3y = 13$ and $4x + 5y = 23$. Then
     $x = \frac{13 - 3y}{2}$, so $26 - 6y + 5y = 23$: **$x = 2$, $y = 3$**.
   - (v) $x = -\frac{\sqrt{3}}{\sqrt{2}}y$, so $-\frac{3}{\sqrt{2}}y - 2\sqrt{2}y = 0$,
     which holds only for $y = 0$: **$x = 0$, $y = 0$**.
   - (vi) Clearing fractions: $9x - 10y = -12$ and $2x + 3y = 13$. Then
     $x = \frac{13 - 3y}{2}$, so $117 - 27y - 20y = -24$ and $47y = 141$:
     **$x = 2$, $y = 3$**.
2. Subtracting, $7y = 35$, so $y = 5$ and $x = -2$. Then $5 = -2m + 3$:
   **$x = -2$, $y = 5$, $m = -1$**.
3. - (i) $x - y = 26$ and $x = 3y$: $2y = 26$. **39 and 13.**
   - (ii) $x + y = 180$ and $x - y = 18$: **$99^\circ$ and $81^\circ$**.
   - (iii) $7x + 6y = 3800$ and $3x + 5y = 1750$. From the second
     $x = \frac{1750 - 5y}{3}$, so $12250 - 35y + 18y = 11400$ and $17y = 850$:
     **a bat costs ₹500 and a ball ₹50**.
   - (iv) Fixed charge $f$, rate $k$ a km: $f + 10k = 105$ and $f + 15k = 155$.
     So $5k = 50$: **fixed charge ₹5, ₹10 a km; 25 km costs ₹255**.
   - (v) $11x - 9y = -4$ and $6x - 5y = -3$. From the second
     $y = \frac{6x + 3}{5}$, so $55x - 54x - 27 = -20$: **the fraction is
     $\frac{7}{9}$**. Check: $\frac{9}{11}$ and $\frac{10}{12} = \frac{5}{6}$.
   - (vi) Jacob $j$, son $s$: $j + 5 = 3(s + 5)$ and $j - 5 = 7(s - 5)$, that
     is, $j - 3s = 10$ and $j - 7s = -30$. So $4s = 40$: **Jacob is 40 and his
     son 10**.

### Exercise Set 3.3

1. - (i) $3x + 3y = 15$ and $2x - 3y = 4$ add to $5x = 19$:
     **$x = \frac{19}{5}$, $y = \frac{6}{5}$**.
   - (ii) $2x - 2y = 2$ is $x - y = 1$; with $3x + 4y = 10$,
     $4x - 4y = 4$ adds to $7x = 14$: **$x = 2$, $y = 1$**.
   - (iii) $3x - 5y = 4$ and $9x - 2y = 7$. Multiplying the first by 3 and
     subtracting: $13y = -5$. **$x = \frac{9}{13}$, $y = -\frac{5}{13}$**.
   - (iv) $3x + 4y = -6$ and $3x - y = 9$. Subtracting: $5y = -15$.
     **$x = 2$, $y = -3$**.

   By substitution each gives the same solution.
2. - (i) $\frac{x + 1}{y - 1} = 1$ and $\frac{x}{y + 1} = \frac{1}{2}$, that
     is, $x - y = -2$ and $2x - y = 1$. Subtracting: $x = 3$, $y = 5$.
     **The fraction is $\frac{3}{5}$.**
   - (ii) $n - 5 = 3(s - 5)$ and $n + 10 = 2(s + 10)$, that is,
     $n - 3s = -10$ and $n - 2s = 10$. Subtracting: $s = 20$. **Nuri is 50 and
     Sonu 20.**
   - (iii) Tens digit $x$, units digit $y$: $x + y = 9$ and
     $9(10x + y) = 2(10y + x)$, that is, $88x = 11y$, or $y = 8x$. So
     $9x = 9$: **the number is 18**.
   - (iv) $x$ notes of ₹50 and $y$ of ₹100: $x + y = 25$ and
     $50x + 100y = 2000$, that is, $x + 2y = 40$. Subtracting: $y = 15$.
     **10 notes of ₹50 and 15 of ₹100.**
   - (v) Fixed charge $f$, extra $k$ a day: $f + 4k = 27$ and $f + 2k = 21$.
     So $2k = 6$: **fixed charge ₹15, and ₹3 for each extra day**.
