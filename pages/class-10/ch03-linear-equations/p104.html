Example 6 · Single correct

What is the solution of $3x + 2y = 11$ and $2x + 3y = 4$?

Choose one correct option.

  1. $(-2, 5)$
  2. $(5, -2)$
  3. $(3, 1)$
  4. $(5, 2)$

Solution.

Step 1Adding: $5(x + y) = 15$, so $x + y = 3$. Subtracting: $x - y = 7$.
Step 2So $x = 5$ and $y = -2$. Check: $15 - 4 = 11$ and $10 - 6 = 4$.
Answer(b) $(5, -2)$
Example 7 · Multiple correct

Which of these pairs have exactly one solution?

Select all correct options.

  1. $x + y = 5$, $x - y = 1$
  2. $2x + 4y = 6$, $x + 2y = 3$
  3. $3x - y = 2$, $6x - 2y = 5$
  4. $x = 2$, $y = 3$

Solution.

Step 1A pair has exactly one solution when $\frac{a_1}{a_2} \ne \frac{b_1}{b_2}$: true of (a) and (d), whose lines cross.
Step 2In (b) all ratios are equal (the same line); in (c) the $x$ and $y$ ratios agree but not the constants (parallel lines).
Answer(a), (d)
Example 8 · Multiple correct

For the pair $2x - 3y = 8$ and $4x - 6y = 9$, which statements are correct?

Select all correct options.

  1. $\frac{a_1}{a_2} = \frac{b_1}{b_2}$
  2. $\frac{a_1}{a_2} \ne \frac{c_1}{c_2}$
  3. The pair has no solution.
  4. Their graphs are intersecting lines.

Solution.

Step 1$\frac{2}{4} = \frac{-3}{-6} = \frac{1}{2}$, but $\frac{8}{9} \ne \frac{1}{2}$.
Step 2So the lines are parallel and there is no solution.
Answer(a), (b), (c)
