Example 12

A school sold 480 tickets for a play. An adult’s ticket cost ₹60 and a child’s ticket ₹35, and the school collected ₹22,050. How many tickets of each kind were sold?

Solution.

Step 1 let $a$ adult and $c$ child tickets be sold: $a + c = 480$ and $60a + 35c = 22050$
Step 2 $60a + 35(480 - a) = 22050$, so $25a + 16800 = 22050$ $c = 480 - a$
Step 3 $25a = 5250$, so $a = 210$ and $c = 270$
Step 4 $60 \times 210 + 35 \times 270 = 12600 + 9450 = 22050$ check
Answer 210 adult tickets and 270 child tickets
Example 13

In triangle $ABC$, $\angle C = 90^\circ$, $\angle A = (2x + y)^\circ$ and $\angle B = (x + 2y)^\circ$. If $\angle A$ is $20^\circ$ more than $\angle B$, find $x$ and $y$, and the three angles.

Solution.

Step 1 $(2x + y) + (x + 2y) = 90$, so $x + y = 30$ angle sum $180^\circ$
Step 2 $(2x + y) - (x + 2y) = 20$, so $x - y = 20$ $\angle A - \angle B$
Step 3 $2x = 50$, so $x = 25$ and $y = 5$ adding
Step 4 $\angle A = 2 \times 25 + 5 = 55^\circ$ and $\angle B = 25 + 2 \times 5 = 35^\circ$
Answer $x = 25$, $y = 5$; the angles are $55^\circ$, $35^\circ$ and $90^\circ$
