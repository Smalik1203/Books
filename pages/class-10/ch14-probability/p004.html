$P(F) = \dfrac{4}{6} = \dfrac{2}{3}$

Are E and F elementary events? No: E has 2 outcomes and F has 4.

Look again at Example 1, where E is getting a head and F is getting a tail, and at Example 3, where E is getting a number greater than 4 and F is getting a number less than or equal to 4.

${P(E) + P(F) = \frac{1}{2} + \frac{1}{2} = 1}$   (1)

${P(E) + P(F) = \frac{1}{3} + \frac{2}{3} = 1}$   (2)

Getting a number that is not greater than 4 is the same as getting a number less than or equal to 4. So in both (1) and (2), F is the event not E. We write the event not E as $\overline{E}$. So ${P(E) + P(\overline{E}) = 1}$, which gives ${P(\overline{E}) = 1 - P(E)}$.

Complementary events

For any event E,

$$P(\overline{E}) = 1 - P(E)$$

The event $\overline{E}$, not E, is called the complement of the event E, and E and $\overline{E}$ are called complementary events.

Before going further, try to answer these two questions.

  1. What is the probability of getting 8 in a single throw of a die?
  2. What is the probability of getting a number less than 7 in a single throw of a die?

For (i): a single throw of a die has only six possible outcomes, 1, 2, 3, 4, 5 and 6. No face of the die is marked 8, so no outcome is favourable to getting 8. Getting 8 is impossible, and ${P(\text{getting } 8) = \frac{0}{6} = 0}$.

So the probability of an event that cannot happen is 0. Such an event is called an impossible event.

For (ii): every face of a die is marked with a number less than 7, so a single throw is sure to give a number less than 7. The number of favourable outcomes is the number of all possible outcomes, 6. So ${P(\text{number less than } 7) = \frac{6}{6} = 1}$.

So the probability of an event that is sure to happen is 1. Such an event is called a sure event or a certain event.
