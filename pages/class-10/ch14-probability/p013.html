  1. Which of these arguments are correct, and which are not? Give a reason for each answer, using the equally likely outcomes of the experiment.
    1. If two coins are tossed together, there are three possible outcomes: two heads, two tails, or one of each. So each of these outcomes has probability $\frac{1}{3}$.
    2. If a die is thrown, there are two possible outcomes: an odd number or an even number. So the probability of getting an odd number is $\frac{1}{2}$.
