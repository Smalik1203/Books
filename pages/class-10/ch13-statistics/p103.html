Type 1 · Class marks and class size

Example 1

The class marks of a distribution are 12, 17, 22, 27 and 32. The class size and the first class are

  1. 5, and 12 – 17
  2. 10, and 7 – 17
  3. 5, and 9.5 – 14.5
  4. 2.5, and 10.75 – 13.25

Solution.

Step 1 class size $= 17 - 12 = 5$ the gap between class marks
Step 2 the first class has class mark 12, so it runs from $12 - 2.5 = 9.5$ to $12 + 2.5 = 14.5$ half the size each side
Answer (c)

Option (a) starts the class at 12, (b) doubles the size, and (d) halves it.

Example 2

The classes of a distribution are 30 – 39, 40 – 49, 50 – 59 and 60 – 69. Make the classes continuous. Then find the class size and the class marks.

Solution.

Step 1 the gap between 39 and 40 is 1, so take $\frac{1}{2} = 0.5$ off each lower limit and add it to each upper limit close the gaps
Step 2 29.5 – 39.5,  39.5 – 49.5,  49.5 – 59.5,  59.5 – 69.5
Step 3 class size $= 39.5 - 29.5 = 10$
Step 4 $\dfrac{29.5 + 39.5}{2} = 34.5$, and so on the mid-point of each class
Answer Class size 10; class marks 34.5, 44.5, 54.5 and 64.5

The class marks are the same as those of the classes with gaps, because both limits moved by the same 0.5.
