To find the median, you need the classes and their frequencies. The distribution is of the less than type, so 140, 145, 150, …, 165 are the upper limits of the classes. So the classes are below 140, 140 – 145, 145 – 150, …, 160 – 165. There are 4 girls with height less than 140 cm, so the frequency of the class below 140 is 4. There are 11 girls with height less than 145 cm, so ${11 - 4 = 7}$ girls have heights in the class 140 – 145. In the same way, the frequency of 145 – 150 is ${29 - 11 = 18}$, the frequency of 150 – 155 is ${40 - 29 = 11}$, and so on. This gives Table 13.16.

Now ${n = 51}$, so ${\frac{n}{2} = \frac{51}{2} = 25.5}$. This observation lies in the class 145 – 150. So

$l = 145$,   $cf = 11$,   $f = 18$,   $h = 5$

$\text{Median} = l + \left(\dfrac{\frac{n}{2} - cf}{f}\right) \times h = 145 + \left(\dfrac{25.5 - 11}{18}\right) \times 5 = 145 + \dfrac{72.5}{18} = 149.03$

So the median height of the girls is 149.03 cm. This means that about half the girls are shorter than 149.03 cm, and about half are taller.
