Example 5

A group of students surveyed 20 households in a locality and made this frequency table of the number of family members in each household. Find the mode of the data.

Family size1 – 33 – 55 – 77 – 99 – 11
Number of families78221

The highest class frequency is 8, and the class with this frequency is 3 – 5. So the modal class is 3 – 5, and

$l = 3$,   $h = 2$,   $f_1 = 8$,   $f_0 = 7$,   $f_2 = 2$

Putting these values into the formula,

$\text{Mode} = l + \left(\dfrac{f_1 - f_0}{2f_1 - f_0 - f_2}\right) \times h = 3 + \left(\dfrac{8 - 7}{2 \times 8 - 7 - 2}\right) \times 2 = 3 + \dfrac{2}{7} = 3.286$

So the mode of the data is 3.286.

Example 6

Table 13.3 gives the marks of 30 students in a mathematics examination. Find the mode of the data. Then compare the mode with the mean, and say what each of them tells you.

In Table 13.3 the largest number of students, 7, got marks in the class 40 – 55. So the modal class is 40 – 55, and

$l = 40$,   $h = 15$,   $f_1 = 7$,   $f_0 = 3$,   $f_2 = 6$

$\text{Mode} = 40 + \left(\dfrac{7 - 3}{14 - 3 - 6}\right) \times 15 = 40 + \dfrac{4}{5} \times 15 = 52$

So the mode is 52 marks. In Section 13.2 you found that the mean of the same marks is 62. So more students got about 52 marks than any other mark, while the average mark of a student is 62.

Remark 1. In Example 6 the mode is less than the mean. In other data the mode may be equal to the mean, or greater than it.

Remark 2. Which measure you need depends on the question being asked. If you want the average mark of the students, find the mean. If you want the mark that most students got, find the mode.
