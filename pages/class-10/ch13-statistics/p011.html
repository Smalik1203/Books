13.3Mode of Grouped Data

Recall from Class 9 that the mode is the value that occurs most often among the observations, that is, the observation with the highest frequency. In Class 9 you found the mode of ungrouped data, and now you will find the mode of grouped data. Two or more values may share the highest frequency, and such data is called multimodal. Grouped data can be multimodal too, but every problem in this chapter has only one mode.

First, recall how the mode of ungrouped data is found.

Example 4

A bowler took these numbers of wickets in 10 cricket matches: 2, 6, 4, 5, 0, 2, 1, 3, 2, 3. Find the mode of the data.

Make a frequency distribution table of the data:

Number of wickets0123456
Number of matches1132111

The bowler took 2 wickets in the largest number of matches, 3. So the mode of the data is 2.

In a grouped frequency distribution you cannot find the mode by looking at the frequencies. You can only find the class with the highest frequency, which is called the modal class. The mode is a value inside the modal class, and it is given by the formula below.

Mode of grouped data
$$\text{Mode} = l + \left(\dfrac{f_1 - f_0}{2f_1 - f_0 - f_2}\right) \times h$$

Here $l$ is the lower limit of the modal class and $h$ is the size of a class interval, all the classes being of the same size. $f_1$ is the frequency of the modal class, $f_0$ is the frequency of the class before it, and $f_2$ is the frequency of the class after it.
