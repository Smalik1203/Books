Let us group the marks of Example 1 into class intervals of width 15. A mark equal to the upper limit of a class goes into the next class. For example, the 4 students with 40 marks are counted in the class 40 – 55, not in 25 – 40. This gives Table 13.2.

Each class now needs one value to stand for all the observations in it. We assume that the observations in a class are spread evenly around its middle. So the mid-point of the class, called its class mark, can stand for them. The class mark is the average of the upper and lower limits of the class:

$$\text{class mark} = \dfrac{\text{upper class limit} + \text{lower class limit}}{2}$$

For the class 10 – 25 in Table 13.2, the class mark is ${\frac{10 + 25}{2} = 17.5}$. The class marks of the other classes are found in the same way, and they are the $x_i$ in Table 13.3. For the $i$th class, $f_i$ is its frequency and $x_i$ is its class mark. Now the mean is found exactly as in Example 1.

The last column adds up to $\sum f_ix_i$. So the mean of the data is

$$\bar{x} = \dfrac{\sum f_ix_i}{\sum f_i} = \dfrac{1860.0}{30} = 62$$

This way of finding the mean is called the direct method.

Tables 13.1 and 13.3 use the same data and the same formula, but the two means are different. Why, and which one is more accurate? The difference comes from assuming that each class is centred at its mid-point. The mean 59.3 is exact, and 62 is an approximate mean.
