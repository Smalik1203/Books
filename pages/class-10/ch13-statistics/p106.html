Example 9 · Multiple correct

In the assumed mean method, $d = x - a$. Which statements are correct?

Select all correct options.

  1. $d$ is each class mark's distance from the assumed mean $a$.
  2. Mean $= a + \frac{\sum fd}{\sum f}$
  3. $\sum f(x - \bar{x}) = 0$
  4. The answer depends on which $a$ is chosen.

Solution.

Step 1The method shifts every class mark by $a$ and shifts the mean back; the deviations from the true mean always cancel.
Step 2A different $a$ changes $\sum fd$ to match, so the mean comes out the same.
Answer(a), (b), (c)
Example 10 · Multiple correct

For the data 0–10: 5, 10–20: 8, 20–30: 12, 30–40: 7, 40–50: 8, the median is found by $l + \frac{\frac{n}{2} - cf}{f} \times h$. Which statements are correct?

Select all correct options.

  1. $l = 20$
  2. $cf = 13$
  3. The median is 30.
  4. $h = 10$

Solution.

Step 1The median class is 20–30, so $l = 20$, $f = 12$, $h = 10$, and the cumulative frequency before it is 13.
Step 2Median $= 20 + \frac{20 - 13}{12} \times 10 \approx 25.8$, not 30.
Answer(a), (b), (d)
