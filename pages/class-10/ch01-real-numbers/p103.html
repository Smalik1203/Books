Problem 2

Two numbers have HCF 16. Which of these cannot be their LCM?

  1. 64
  2. 240
  3. 124
  4. 160
Solution

The HCF divides each number, and each number divides the LCM, so the HCF must divide the LCM. Now $64 = 16 \times 4$, $240 = 16 \times 15$ and $160 = 16 \times 10$, but 124 is not a multiple of 16. So the answer is (c). The other three do happen: 16 and 64, 48 and 80, and 16 and 160 all have HCF 16, and their LCMs are 64, 240 and 160.

Problem 3

For which of these is there a natural number $n$ that makes the number end with the digit 0?

  1. $4^n$
  2. $12^n$
  3. $15^n$
  4. $20^n$
Solution

$4^n = 2^{2n}$,   $12^n = 2^{2n} \times 3^n$,   $15^n = 3^n \times 5^n$,   $20^n = 2^{2n} \times 5^n$

A number ends with 0 only when both 2 and 5 are among its prime factors, and by uniqueness no other primes can appear. Only $20^n$ has both, so the answer is (d). Every power of 15 ends with 5.

Problem 4

Which of these numbers is irrational?

  1. $\sqrt{3} \times \sqrt{27}$
  2. $(2 - \sqrt{3})^2$
  3. $\dfrac{\sqrt{12}}{\sqrt{3}}$
  4. $\sqrt{2} \times \sqrt{18}$
Solution

(a) $\sqrt{81} = 9$   (c) $\sqrt{12 \div 3} = \sqrt{4} = 2$   (d) $\sqrt{36} = 6$

(b) $4 - 4\sqrt{3} + 3 = 7 - 4\sqrt{3}$

The answer is (b): $4\sqrt{3}$ is irrational, so $7 - 4\sqrt{3}$ is irrational too. The other three contain square roots, but each works out to an integer.
