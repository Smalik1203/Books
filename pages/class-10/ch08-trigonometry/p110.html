Assertion and reason

In Questions 16 to 19, choose (a) if both A and R are true and R explains A; (b) if both are true but R does not explain A; (c) if A is true but R is false; (d) if A is false but R is true.

  1. Assertion (A): ${\sin 45^\circ + \cos 45^\circ = \sqrt{2}}$.

    Reason (R): ${\sin 45^\circ = \cos 45^\circ = \frac{1}{\sqrt{2}}}$.

  1. Assertion (A): ${\tan 60^\circ = 2\tan 30^\circ}$.

    Reason (R): ${\tan 60^\circ = \sqrt{3}}$ and ${\tan 30^\circ = \frac{1}{\sqrt{3}}}$.

  1. Assertion (A): ${(\sec A - \tan A)(\sec A + \tan A) = 1}$ for every acute angle A.

    Reason (R): $\sin A$ and $\cos A$ are never more than 1.

  1. Assertion (A): ${\cos 0^\circ = \sec 0^\circ}$.

    Reason (R): ${\cos A = \sec A}$ for every acute angle A.

Very short answer
  1. Find the value of ${\operatorname{cosec}^2 60^\circ - \cot^2 30^\circ}$.
  1. If ${2\cos\theta = \sqrt{3}}$ and $\theta$ is an acute angle, find $\theta$ and $\tan\theta$.
  1. Find the value of ${(1 + \cot^2\theta)(1 - \cos\theta)(1 + \cos\theta)}$ for an acute angle $\theta$.
  1. In $\triangle DEF$, right-angled at E, ${DE = 1}$ cm and ${EF = \sqrt{3}}$ cm. Find $\angle F$.
Short answer
  1. If ${\sec\theta = \frac{61}{11}}$ for an acute angle $\theta$, find $\sin\theta$ and $\cot\theta$.
  1. Prove that ${(\sin\theta + \cos\theta)^2 + (\sin\theta - \cos\theta)^2 = 2}$.
  1. Prove that ${\sqrt{\sec^2\theta + \operatorname{cosec}^2\theta} = \tan\theta + \cot\theta}$ for an acute angle $\theta$.
  1. If ${\cos(A - B) = \frac{\sqrt{3}}{2}}$ and ${\sin(A + B) = 1}$, where ${0^\circ \lt A + B \leq 90^\circ}$ and ${A \gt B}$, find A and B.
Long answer
  1. Prove that ${\dfrac{1 + \cos\theta + \sin\theta}{1 + \cos\theta - \sin\theta} = \dfrac{1 + \sin\theta}{\cos\theta}}$ for an acute angle $\theta$.
  1. If ${\tan\theta + \sin\theta = m}$ and ${\tan\theta - \sin\theta = n}$, where $\theta$ is an acute angle, show that ${m^2 - n^2 = 4\sqrt{mn}}$.
