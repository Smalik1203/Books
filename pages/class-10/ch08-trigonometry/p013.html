Trigonometric Ratios of 0° and 90°

Let us see what happens to the trigonometric ratios of angle A if we make it smaller and smaller in the right triangle ABC of Fig. 8.16, until it becomes zero. As $\angle A$ gets smaller and smaller, the side BC gets shorter. The point C gets closer to the point B, and when $\angle A$ is very close to $0^\circ$, AC becomes almost the same as AB (Fig. 8.17).

When $\angle A$ is very close to $0^\circ$, BC is very close to 0, and so the value of ${\sin A = \frac{BC}{AC}}$ is very close to 0. Also, when $\angle A$ is very close to $0^\circ$, AC is nearly the same as AB, and so the value of ${\cos A = \frac{AB}{AC}}$ is very close to 1.

This shows us how we can define the values of $\sin A$ and $\cos A$ when ${A = 0^\circ}$. We define ${\sin 0^\circ = 0}$ and ${\cos 0^\circ = 1}$. Using these, we have

$\tan 0^\circ = \dfrac{\sin 0^\circ}{\cos 0^\circ} = 0$,   and   $\cot 0^\circ = \dfrac{1}{\tan 0^\circ}$, which is not defined   (Why?)

$\sec 0^\circ = \dfrac{1}{\cos 0^\circ} = 1$,   and   $\operatorname{cosec} 0^\circ = \dfrac{1}{\sin 0^\circ}$, which again is not defined   (Why?)
