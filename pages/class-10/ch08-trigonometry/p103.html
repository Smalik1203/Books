Problem 2

If ${\sin(A - B) = \frac{\sqrt{3}}{2}}$ and ${\cos(A + B) = 0}$, where ${0^\circ \lt A + B \leq 90^\circ}$ and ${A \gt B}$, then

  1. ${A = 75^\circ}$, ${B = 15^\circ}$
  2. ${A = 60^\circ}$, ${B = 30^\circ}$
  3. ${A = 45^\circ}$, ${B = 45^\circ}$
  4. ${A = 90^\circ}$, ${B = 0^\circ}$
Solution

${\sin(A - B) = \frac{\sqrt{3}}{2}}$, so ${A - B = 60^\circ}$; ${\cos(A + B) = 0}$, so ${A + B = 90^\circ}$

adding, ${2A = 150^\circ}$, so ${A = 75^\circ}$ and ${B = 15^\circ}$

The answer is (a). Option (b) has ${A - B = 30^\circ}$, whose sine is $\frac{1}{2}$, and (c) has ${A - B = 0^\circ}$. Option (d) has ${A + B = 90^\circ}$, but ${\sin 90^\circ = 1}$.

Problem 3

For an acute angle $\theta$, the value of ${(1 - \sin^2\theta)\sec^2\theta}$ is

  1. $0$
  2. $1$
  3. $\tan^2\theta$
  4. $\cos^2\theta$
Solution

${(1 - \sin^2\theta)\sec^2\theta = \cos^2\theta \times \frac{1}{\cos^2\theta} = 1}$

The answer is (b). Option (d) stops after the first step and forgets $\sec^2\theta$, and (c) mixes up ${\sec^2\theta - 1}$ with the product.

Problem 4

In $\triangle ABC$, right-angled at B, ${AB = 12}$ cm and ${\angle A = 60^\circ}$. Then AC is

  1. 24 cm
  2. ${12\sqrt{3}}$ cm
  3. 6 cm
  4. ${8\sqrt{3}}$ cm
Solution

AB is adjacent to angle A and AC is the hypotenuse, so ${\cos 60^\circ = \frac{AB}{AC}}$

${\frac{1}{2} = \frac{12}{AC}}$, so ${AC = 24}$ cm

The answer is (a). Option (b) is BC, from $\tan 60^\circ$; (c) multiplies 12 by $\cos 60^\circ$ instead of dividing; and (d) divides 12 by $\sin 60^\circ$, treating AB as the opposite side.
