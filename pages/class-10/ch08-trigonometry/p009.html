In $\triangle ABC$, ${\tan A = \frac{BC}{AB} = 1}$ (Fig. 8.11), that is, ${BC = AB}$. Let ${AB = BC = k}$, where $k$ is a positive number. Then

${AC = \sqrt{AB^2 + BC^2} = \sqrt{k^2 + k^2} = k\sqrt{2}}$

so $\sin A = \dfrac{BC}{AC} = \dfrac{1}{\sqrt{2}}$   and   $\cos A = \dfrac{AB}{AC} = \dfrac{1}{\sqrt{2}}$

so $2 \sin A \cos A = 2\left(\dfrac{1}{\sqrt{2}}\right)\left(\dfrac{1}{\sqrt{2}}\right) = 1$, which is the required value

Example 5

In $\triangle OPQ$, right-angled at P, ${OP = 7}$ cm and ${OQ - PQ = 1}$ cm (Fig. 8.12). Find the values of $\sin Q$ and $\cos Q$.

In $\triangle OPQ$, we have

${OQ^2 = OP^2 + PQ^2}$

${(1 + PQ)^2 = OP^2 + PQ^2}$   (Why?)

${1 + PQ^2 + 2PQ = OP^2 + PQ^2}$

${1 + 2PQ = 7^2}$   (Why?)

${PQ = 24}$ cm and ${OQ = 1 + PQ = 25}$ cm

so $\sin Q = \dfrac{7}{25}$   and   $\cos Q = \dfrac{24}{25}$
