Type 4 · Finding an angle from its ratio

Example 6

If ${\sin(A - B) = \frac{\sqrt{3}}{2}}$ and ${\cos(A + B) = 0}$, where ${0^\circ \lt A + B \leq 90^\circ}$ and ${A \gt B}$, then

  1. ${A = 75^\circ}$, ${B = 15^\circ}$
  2. ${A = 60^\circ}$, ${B = 30^\circ}$
  3. ${A = 45^\circ}$, ${B = 45^\circ}$
  4. ${A = 90^\circ}$, ${B = 0^\circ}$

Solution.

Step 1 ${A - B = 60^\circ}$ $\sin 60^\circ = \dfrac{\sqrt{3}}{2}$
Step 2 ${A + B = 90^\circ}$ $\cos 90^\circ = 0$
Step 3 adding, ${2A = 150^\circ}$, so ${A = 75^\circ}$ and ${B = 15^\circ}$
Answer (a)

Option (b) has ${A - B = 30^\circ}$, whose sine is $\frac{1}{2}$, and (c) has ${A - B = 0^\circ}$. Option (d) has ${A + B = 90^\circ}$, but ${\sin 90^\circ = 1}$.

Example 7

If ${\sqrt{3}\tan 2\theta = 3}$, where $2\theta$ is an acute angle, find $\theta$ and the value of $\sin 3\theta$.

Solution.

Step 1 $\tan 2\theta = \dfrac{3}{\sqrt{3}} = \sqrt{3}$
Step 2 ${2\theta = 60^\circ}$ Table 8.1
Step 3 ${\theta = 30^\circ}$, so ${3\theta = 90^\circ}$
Answer ${\theta = 30^\circ}$ and ${\sin 3\theta = \sin 90^\circ = 1}$
