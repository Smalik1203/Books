Example 9 · Multiple correct

Which of these are identities for acute $\theta$?

Select all correct options.

  1. $\sin^2\theta + \cos^2\theta = 1$
  2. $1 + \cot^2\theta = \text{cosec}^2\theta$
  3. $\sec\theta - \tan\theta = 1$
  4. $(\sec\theta - \tan\theta)(\sec\theta + \tan\theta) = 1$

Solution.

Step 1(a) and (b) are the standard identities, and (d) is $\sec^2\theta - \tan^2\theta = 1$.
Step 2At $\theta = 60^\circ$, $\sec\theta - \tan\theta = 2 - \sqrt{3}$, not 1.
Answer(a), (b), (d)
Example 10 · Multiple correct

$\theta$ is acute and $\sin\theta = \frac{1}{2}$. Which statements are correct?

Select all correct options.

  1. $\theta = 30^\circ$
  2. $\cos\theta = \frac{\sqrt{3}}{2}$
  3. $\tan\theta = \sqrt{3}$
  4. $\sec\theta = 2$

Solution.

Step 1$\sin 30^\circ = \frac{1}{2}$, so $\theta = 30^\circ$ and $\cos\theta = \frac{\sqrt{3}}{2}$.
Step 2$\tan 30^\circ = \frac{1}{\sqrt{3}}$ and $\sec 30^\circ = \frac{2}{\sqrt{3}}$.
Answer(a), (b)
