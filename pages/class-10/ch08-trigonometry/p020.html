Let us see what we get by dividing (1) by $BC^2$. We get

$\dfrac{AB^2}{BC^2} + \dfrac{BC^2}{BC^2} = \dfrac{AC^2}{BC^2}$

that is, $\left(\dfrac{AB}{BC}\right)^2 + \left(\dfrac{BC}{BC}\right)^2 = \left(\dfrac{AC}{BC}\right)^2$

that is, ${\cot^2 A + 1 = \operatorname{cosec}^2 A}$   (4)

Note that $\operatorname{cosec} A$ and $\cot A$ are not defined for ${A = 0^\circ}$. So (4) is true for all A such that ${0^\circ \lt A \leq 90^\circ}$.

Three trigonometric identities

${\sin^2 A + \cos^2 A = 1}$   for ${0^\circ \leq A \leq 90^\circ}$

${1 + \tan^2 A = \sec^2 A}$   for ${0^\circ \leq A \lt 90^\circ}$

${1 + \cot^2 A = \operatorname{cosec}^2 A}$   for ${0^\circ \lt A \leq 90^\circ}$

Using these identities, we can write each trigonometric ratio in terms of the other trigonometric ratios. That is, if any one of the ratios is known, we can also find the values of the other ratios.

Let us see how we can do this with the identities. Suppose we know that ${\tan A = \frac{1}{\sqrt{3}}}$. Then ${\cot A = \sqrt{3}}$, and

${\sec^2 A = 1 + \tan^2 A = 1 + \frac{1}{3} = \frac{4}{3}}$, so ${\sec A = \frac{2}{\sqrt{3}}}$ and ${\cos A = \frac{\sqrt{3}}{2}}$

${\sin A = \sqrt{1 - \cos^2 A} = \sqrt{1 - \frac{3}{4}} = \frac{1}{2}}$, so ${\operatorname{cosec} A = 2}$
