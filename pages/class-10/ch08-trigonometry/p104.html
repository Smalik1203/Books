Type 2 · An expression from one ratio

Example 4

If ${5\tan\theta = 4}$, then $\dfrac{5\sin\theta - 3\cos\theta}{5\sin\theta + 2\cos\theta}$ is

  1. $\dfrac{1}{6}$
  2. $\dfrac{17}{22}$
  3. $6$
  4. $-\dfrac{3}{2}$

Solution.

Step 1 $\dfrac{5\sin\theta - 3\cos\theta}{5\sin\theta + 2\cos\theta} = \dfrac{5\tan\theta - 3}{5\tan\theta + 2}$ dividing above and below by $\cos\theta$
Step 2 $= \dfrac{4 - 3}{4 + 2} = \dfrac{1}{6}$ ${5\tan\theta = 4}$
Answer (a)

Option (b) takes ${\tan\theta = 4}$ in place of ${5\tan\theta = 4}$, (c) turns the fraction upside down, and (d) cancels $5\sin\theta$ from the top and the bottom, which is not allowed in a sum. Dividing by $\cos\theta$ is allowed here: $\tan\theta$ is defined, so $\cos\theta$ is not zero.

Type 3 · The values at 0°, 30°, 45°, 60° and 90°

Example 5

Evaluate $\dfrac{4}{\cot^2 30^\circ} + \dfrac{1}{\sin^2 60^\circ} - \cos^2 45^\circ$.

Solution.

Step 1 $\cot^2 30^\circ = 3$,   $\sin^2 60^\circ = \dfrac{3}{4}$,   $\cos^2 45^\circ = \dfrac{1}{2}$ squaring the values in Table 8.1
Step 2 $\dfrac{4}{3} + \dfrac{4}{3} - \dfrac{1}{2} = \dfrac{8}{3} - \dfrac{1}{2}$
Step 3 $= \dfrac{16 - 3}{6}$ common denominator 6
Answer $\dfrac{13}{6}$
