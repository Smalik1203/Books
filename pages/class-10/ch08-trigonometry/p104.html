Example 6 · Single correct

What is $(1 + \tan^2 A)\cos^2 A$, for acute $A$?

Choose one correct option.

  1. 0
  2. 1
  3. $\tan^2 A$
  4. $\sec^2 A$

Solution.

Step 1$1 + \tan^2 A = \sec^2 A$.
Step 2$\sec^2 A \times \cos^2 A = 1$.
Answer(b) 1
Example 7 · Multiple correct

Which of these are equal to 1?

Select all correct options.

  1. $\sin^2 30^\circ + \cos^2 30^\circ$
  2. $\sec^2 45^\circ - \tan^2 45^\circ$
  3. $\cos 90^\circ$
  4. $\tan 30^\circ \tan 60^\circ$

Solution.

Step 1The first two are the identities $\sin^2 + \cos^2 = 1$ and $\sec^2 - \tan^2 = 1$, and $\frac{1}{\sqrt{3}} \times \sqrt{3} = 1$.
Step 2$\cos 90^\circ = 0$.
Answer(a), (b), (d)
Example 8 · Multiple correct

$A$ is acute and $\tan A = 1$. Which statements are correct?

Select all correct options.

  1. $A = 45^\circ$
  2. $\sin A = \cos A$
  3. $\sin A = \frac{1}{\sqrt{2}}$
  4. $\sec A = 2$

Solution.

Step 1$\tan A = 1$ means the opposite and adjacent sides are equal: $A = 45^\circ$ and $\sin A = \cos A = \frac{1}{\sqrt{2}}$.
Step 2$\sec 45^\circ = \sqrt{2}$, not 2.
Answer(a), (b), (c)
