Using What You Know

The chapter gave you six ratios, their values for five angles, and three identities. What changes now is that a question may give a condition on the ratios instead of a triangle, and often the angle itself is never needed.

$\theta$ is an acute angle and ${7\sin^2\theta + 3\cos^2\theta = 4}$. Find $\tan\theta$.

There are two ratios in the equation, so first turn it into one. Since ${\cos^2\theta = 1 - \sin^2\theta}$, the equation becomes ${7\sin^2\theta + 3 - 3\sin^2\theta = 4}$, so ${4\sin^2\theta = 1}$ and ${\sin\theta = \frac{1}{2}}$, because $\sin\theta$ is positive for an acute angle. From Table 8.1, ${\theta = 30^\circ}$, and so ${\tan\theta = \frac{1}{\sqrt{3}}}$. The identity turned an equation in two ratios into an equation in one.

If ${\sin\theta + \cos\theta = \sqrt{2}\cos\theta}$, show that ${\cos\theta - \sin\theta = \sqrt{2}\sin\theta}$.

From the given equation, ${\sin\theta = (\sqrt{2} - 1)\cos\theta}$. Multiply both sides by ${\sqrt{2} + 1}$: since ${(\sqrt{2} + 1)(\sqrt{2} - 1) = 2 - 1 = 1}$, this gives ${(\sqrt{2} + 1)\sin\theta = \cos\theta}$. So ${\cos\theta = \sqrt{2}\sin\theta + \sin\theta}$, that is, ${\cos\theta - \sin\theta = \sqrt{2}\sin\theta}$. The value of $\theta$ was never needed.

Find $\theta$, where ${0^\circ \leq \theta \leq 90^\circ}$, if ${2\cos^2\theta - 3\cos\theta + 1 = 0}$.

Treat $\cos\theta$ as the unknown of a quadratic equation, as in Chapter 4. The equation factorises as ${(2\cos\theta - 1)(\cos\theta - 1) = 0}$, so ${\cos\theta = \frac{1}{2}}$ or ${\cos\theta = 1}$. From Table 8.1, ${\theta = 60^\circ}$ or ${\theta = 0^\circ}$. Both values satisfy the equation, as you can check by putting them back in.

Can ${\tan A + \cot A}$ be less than 2 for an acute angle A?

For an acute angle, $\tan A$ and $\cot A$ are both positive, and ${\tan A \cot A = 1}$. So ${\left(\sqrt{\tan A} - \sqrt{\cot A}\right)^2 = \tan A - 2\sqrt{\tan A \cot A} + \cot A = \tan A + \cot A - 2}$. A square is never negative, so ${\tan A + \cot A \geq 2}$, and the answer is no. The sum is exactly 2 only when ${\tan A = \cot A}$, that is, when ${A = 45^\circ}$. For example, ${\tan 30^\circ + \cot 30^\circ = \frac{1}{\sqrt{3}} + \sqrt{3} = \frac{4}{\sqrt{3}}}$, which is more than 2. So of all acute angles, $45^\circ$ gives the smallest value of ${\tan A + \cot A}$, and that value is 2.
