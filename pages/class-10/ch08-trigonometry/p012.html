Trigonometric Ratios of 30° and 60°

Now let us work out the trigonometric ratios of $30^\circ$ and $60^\circ$. Take an equilateral triangle ABC. Each angle of an equilateral triangle is $60^\circ$, so ${\angle A = \angle B = \angle C = 60^\circ}$. Draw the perpendicular AD from A to the side BC (Fig. 8.15).

${\triangle ABD \cong \triangle ACD}$   (Why?)

so ${BD = DC}$   and   ${\angle BAD = \angle CAD}$   (CPCT)

Now $\triangle ABD$ is a right triangle, right-angled at D, with ${\angle BAD = 30^\circ}$ and ${\angle ABD = 60^\circ}$ (Fig. 8.15). To find the trigonometric ratios, we need to know the lengths of the sides of the triangle. So let ${AB = 2a}$. Then

${BD = \frac{1}{2}BC = a}$

${AD^2 = AB^2 - BD^2 = (2a)^2 - a^2 = 3a^2}$, so ${AD = a\sqrt{3}}$

Now we have

$\sin 30^\circ = \dfrac{BD}{AB} = \dfrac{a}{2a} = \dfrac{1}{2}$,   $\cos 30^\circ = \dfrac{AD}{AB} = \dfrac{a\sqrt{3}}{2a} = \dfrac{\sqrt{3}}{2}$

$\tan 30^\circ = \dfrac{BD}{AD} = \dfrac{a}{a\sqrt{3}} = \dfrac{1}{\sqrt{3}}$

also $\operatorname{cosec} 30^\circ = \dfrac{1}{\sin 30^\circ} = 2$,   $\sec 30^\circ = \dfrac{1}{\cos 30^\circ} = \dfrac{2}{\sqrt{3}}$   and   $\cot 30^\circ = \dfrac{1}{\tan 30^\circ} = \sqrt{3}$
