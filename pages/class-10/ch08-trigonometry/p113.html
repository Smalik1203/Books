10 ${AB = 10\sin 30^\circ = 5}$ and ${BC = 10\cos 30^\circ = 5\sqrt{3}}$. Option (c) is BC alone.
11 ${1 - 2\sin^2 30^\circ = 1 - \frac{1}{2} = \frac{1}{2}}$, which is $\cos 60^\circ$, but ${1 - 2\sin 30^\circ = 0}$. Lata has not squared the sine.
12 ${(\operatorname{cosec}\theta - \cot\theta)(\operatorname{cosec}\theta + \cot\theta) = 1}$, so ${\operatorname{cosec}\theta + \cot\theta = \frac{5}{2}}$. Then ${\operatorname{cosec}\theta = \frac{29}{20}}$ and ${\cot\theta = \frac{21}{20}}$, so ${\sin\theta = \frac{20}{29}}$ and ${\cos\theta = \frac{21}{29}}$. Option (a) is $\sin\theta$, (c) is $\cot\theta$ and (d) is $\sec\theta$.
13 ${2\sin^2\theta - (1 - \sin^2\theta) = 2}$ gives ${\sin^2\theta = 1}$, so $\theta$ is $90^\circ$. At $60^\circ$, $45^\circ$ and $30^\circ$ the left-hand side is ${\frac{5}{4}}$, ${\frac{1}{2}}$ and ${-\frac{1}{4}}$.
14 ${\frac{\sqrt{3} - \frac{1}{\sqrt{3}}}{1 + 1} = \frac{2}{2\sqrt{3}} = \frac{1}{\sqrt{3}}}$, which is ${\tan 30^\circ}$. Option (a) is $\tan 60^\circ$ alone.
15 The expression is ${(\sin^2\theta + \cos^2\theta)^3 = 1^3 = 1}$. Option (b) keeps only the 3.
16 ${\frac{1}{\sqrt{2}} + \frac{1}{\sqrt{2}} = \frac{2}{\sqrt{2}} = \sqrt{2}}$, and R gives exactly the two values that add to it, so the answer is (a).
17 ${2\tan 30^\circ = \frac{2}{\sqrt{3}}}$, but ${\tan 60^\circ = \sqrt{3} = \frac{3}{\sqrt{3}}}$. A is false and R is true: (d).
18 A is the identity ${\sec^2 A - \tan^2 A = 1}$, so it is true. R is true, but it says nothing about $\sec A$ or $\tan A$: (b).
19 ${\cos 0^\circ = \sec 0^\circ = 1}$, so A is true. But ${\cos 60^\circ = \frac{1}{2}}$ and ${\sec 60^\circ = 2}$, so R is false: (c).

Three things from this section are worth keeping. A condition on the ratios can often be turned into one ratio with an identity. An expression can often be found without ever finding the angle. And the values in Table 8.1 are worth knowing well, because a question may lead you back to them from any direction.
