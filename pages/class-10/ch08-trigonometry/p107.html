A2 ${\cos^2 A = 1 - \frac{9}{25} = \frac{16}{25}}$, so ${\cos A = \frac{4}{5}}$: (a). Option (b) is $\tan A$, and (c) is $\sec A$.
A6 PQ is opposite to R and PR is the hypotenuse: (b). Option (a) is $\cos R$, and (c) is $\tan R$.
A8 For an acute angle, ${0 \lt \cos A \lt 1}$: (c). Options (a) and (b) are greater than 1, and (d) is negative.
B1 ${\theta = 45^\circ}$, so ${2 \times 1 + \frac{1}{2} = \frac{5}{2}}$: (b). Option (a) takes ${\cos^2 45^\circ = 1}$.
B2 The sides are 3, 4 and 5, so ${\sin A \cos A = \frac{3}{5} \times \frac{4}{5} = \frac{12}{25}}$: (c). Option (a) is $\sin A$ alone.
B3 ${AB = 10\sin 30^\circ = 5}$ and ${BC = 10\cos 30^\circ = 5\sqrt{3}}$: (d). Option (c) is BC alone.
B4 ${2\sin 30^\circ = 1}$, but ${2\sin 30^\circ \cos 30^\circ = \frac{\sqrt{3}}{2} = \sin 60^\circ}$: (b).
B5 ${\operatorname{cosec}\theta + \cot\theta = 2}$, so ${\operatorname{cosec}\theta = \frac{5}{4}}$ and ${\cot\theta = \frac{3}{4}}$, which give ${\sin\theta = \frac{4}{5}}$ and ${\cos\theta = \frac{3}{5}}$: (a). Option (b) is $\sin\theta$, and (c) is $\cot\theta$.
C1 ${2\sin^2\theta - (1 - \sin^2\theta) = 2}$ gives ${\sin^2\theta = 1}$, so ${\theta = 90^\circ}$: (a).
C3 ${(QR + 4)^2 = QR^2 + 64}$ gives ${QR = 6}$, so ${\tan R = \frac{8}{6} = \frac{4}{3}}$: (c). Option (a) is $\cot R$, and (b) is $\sin R$.
C4 It is ${(\sin^2\theta + \cos^2\theta)^3 = 1^3 = 1}$: (d). Option (b) keeps only the 3.

Three things from this section are worth keeping. A condition on the ratios can often be turned into one ratio with an identity. An expression can often be found without ever finding the angle. And the values in Table 8.1 are worth knowing well, because a question may lead you back to them from any direction.
