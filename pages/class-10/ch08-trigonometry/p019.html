8.4Trigonometric Identities

You may recall that an equation is called an identity when it is true for all values of the variables involved. In the same way, an equation involving trigonometric ratios of an angle is called a trigonometric identity if it is true for all values of the angle or angles involved. For example, ${(a + b)^2 = a^2 + 2ab + b^2}$ is true for all values of $a$ and $b$, so it is an identity, but ${2x = 6}$ is true only for ${x = 3}$.

In this section, we prove one trigonometric identity, and then use it to prove other useful trigonometric identities.

In $\triangle ABC$, right-angled at B (Fig. 8.22), we have

$$AB^2 + BC^2 = AC^2 \qquad (1)$$

Dividing each term of (1) by $AC^2$, we get

$\dfrac{AB^2}{AC^2} + \dfrac{BC^2}{AC^2} = \dfrac{AC^2}{AC^2}$

that is, $\left(\dfrac{AB}{AC}\right)^2 + \left(\dfrac{BC}{AC}\right)^2 = \left(\dfrac{AC}{AC}\right)^2$

that is, ${(\cos A)^2 + (\sin A)^2 = 1}$

that is, ${\cos^2 A + \sin^2 A = 1}$   (2)

This is true for all A such that ${0^\circ \leq A \leq 90^\circ}$. So this is a trigonometric identity. Let us now divide (1) by $AB^2$. We get

$\dfrac{AB^2}{AB^2} + \dfrac{BC^2}{AB^2} = \dfrac{AC^2}{AB^2}$

that is, $\left(\dfrac{AB}{AB}\right)^2 + \left(\dfrac{BC}{AB}\right)^2 = \left(\dfrac{AC}{AB}\right)^2$

that is, ${1 + \tan^2 A = \sec^2 A}$   (3)

Is this equation true for ${A = 0^\circ}$? Yes, it is. What about ${A = 90^\circ}$? Well, $\tan A$ and $\sec A$ are not defined for ${A = 90^\circ}$. So (3) is true for all A such that ${0^\circ \leq A \lt 90^\circ}$.
