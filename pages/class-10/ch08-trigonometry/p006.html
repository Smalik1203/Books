Example 1

Given ${\tan A = \frac{4}{3}}$, find the other trigonometric ratios of the angle A.

Solution.

Step 1 Draw a right triangle ABC, right-angled at B (Fig. 8.8): ${\tan A = \frac{BC}{AB} = \frac{4}{3}}$
Step 2 ${BC = 4k}$ and ${AB = 3k}$ $k$ is a positive number
Step 3 ${AC^2 = AB^2 + BC^2 = (3k)^2 + (4k)^2 = 25k^2}$, so ${AC = 5k}$ the Pythagoras theorem
Step 4 $\sin A = \dfrac{BC}{AC} = \dfrac{4k}{5k} = \dfrac{4}{5}$   and   $\cos A = \dfrac{AB}{AC} = \dfrac{3k}{5k} = \dfrac{3}{5}$ the definitions
Step 5 $\cot A = \dfrac{1}{\tan A} = \dfrac{3}{4}$,   $\operatorname{cosec} A = \dfrac{1}{\sin A} = \dfrac{5}{4}$   and   $\sec A = \dfrac{1}{\cos A} = \dfrac{5}{3}$ the reciprocals
Answer $\sin A = \dfrac{4}{5}$, $\cos A = \dfrac{3}{5}$, $\cot A = \dfrac{3}{4}$, $\operatorname{cosec} A = \dfrac{5}{4}$, $\sec A = \dfrac{5}{3}$
