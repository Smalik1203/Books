Think of the problem that was given to Gauss, whom you read about in Chapter 1, when he was just 10 years old. He was asked to find the sum of the positive integers from 1 to 100, and at once he said that the sum is 5050. How do you think he did it? He wrote

$$S = 1 + 2 + 3 + \cdots + 99 + 100$$

and then wrote the same numbers in reverse order,

$$S = 100 + 99 + \cdots + 3 + 2 + 1$$

Adding these two, he got

$2S = (1 + 100) + (2 + 99) + \cdots + (99 + 2) + (100 + 1)$

$\phantom{2S} = 101 + 101 + \cdots + 101 + 101$   (100 times)

So $S = \frac{100 \times 101}{2} = 5050$, that is, the sum is 5050.

We will now use the same idea to find the sum of the first $n$ terms of the AP ${a, a + d, a + 2d, \ldots}$ The $n$th term of this AP is $a + (n - 1)d$. Let $S$ be the sum of its first $n$ terms. Then

$$S = a + (a + d) + (a + 2d) + \cdots + [a + (n - 1)d] \qquad (1)$$

Writing the terms in reverse order,

$$S = [a + (n - 1)d] + [a + (n - 2)d] + \cdots + (a + d) + a \qquad (2)$$

Now add (1) and (2) term by term. Each pair of terms adds up to $2a + (n - 1)d$, so

$$2S = \underbrace{[2a + (n - 1)d] + [2a + (n - 1)d] + \cdots + [2a + (n - 1)d]}_{n \text{ times}}$$

There are $n$ terms, so $2S = n[2a + (n - 1)d]$. Dividing both sides by 2 gives the sum.

The sum of the first n terms of an AP

The sum of the first $n$ terms of the AP with first term $a$ and common difference $d$ is given by

$$S = \dfrac{n}{2}[2a + (n - 1)d]$$
