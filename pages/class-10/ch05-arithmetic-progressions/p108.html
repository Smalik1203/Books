Assertion and reason

In Questions 14 to 17, choose (a) if both A and R are true and R explains A; (b) if both are true but R does not explain A; (c) if A is true but R is false; (d) if A is false but R is true.

  1. Assertion (A): The common difference of the AP $12, 7, 2, -3, \ldots$ is $-5$.

    Reason (R): The common difference of an AP is found by subtracting a term from the term just before it.

  1. Assertion (A): The list $2, 5, 9, 14, \ldots$ is not an AP.

    Reason (R): In an AP, the difference between any two consecutive terms is the same.
