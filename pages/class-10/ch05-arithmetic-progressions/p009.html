Example 3

Find the 10th term of the AP $2, 7, 12, \ldots$

Here $a = 2$, $d = 7 - 2 = 5$ and $n = 10$. Using ${a_n = a + (n - 1)d}$, we get ${a_{10} = 2 + (10 - 1) \times 5 = 2 + 45 = 47}$. So the 10th term of the AP is 47. You can check this by writing out the first ten terms: 2, 7, 12, 17, 22, 27, 32, 37, 42, 47.

Example 4

Which term of the AP $21, 18, 15, \ldots$ is $-81$? Is any term of this AP equal to 0? Give a reason for your answer.

Here $a = 21$, $d = 18 - 21 = -3$ and $a_n = -81$, and we have to find $n$. Since ${a_n = a + (n - 1)d}$,

$-81 = 21 + (n - 1)(-3) = 24 - 3n$

$-105 = -3n$, so $n = 35$

So the 35th term of the AP is $-81$. Next, is there an $n$ for which $a_n = 0$? If there is, then

$21 + (n - 1)(-3) = 0$

$3(n - 1) = 21$, so $n - 1 = 7$ and $n = 8$

So the 8th term of the AP is 0.

Example 5

Find the AP whose 3rd term is 5 and whose 7th term is 9.

Using ${a_n = a + (n - 1)d}$ for the two terms we know,

$a_3 = a + (3 - 1)d = a + 2d = 5$   (1)

$a_7 = a + (7 - 1)d = a + 6d = 9$   (2)

Subtracting (1) from (2) gives $4d = 4$, so $d = 1$, and then (1) gives $a = 3$. So the AP is $3, 4, 5, 6, 7, \ldots$
