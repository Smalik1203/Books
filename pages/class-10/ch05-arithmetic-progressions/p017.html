Example 15

Find the sum of the first 24 terms of the list of numbers whose $n$th term is given by $a_n = 3 + 2n$.

Since $a_n = 3 + 2n$,

$a_1 = 3 + 2 \times 1 = 5$

$a_2 = 3 + 2 \times 2 = 7$

$a_3 = 3 + 2 \times 3 = 9$

So the list of numbers is $5, 7, 9, 11, \ldots$ Here $7 - 5 = 9 - 7 = 11 - 9 = 2$, and so on, so the list is an AP with common difference 2. To find $S_{24}$, we put $n = 24$, $a = 5$ and $d = 2$ into the formula.

$$S_{24} = \dfrac{24}{2}[2 \times 5 + (24 - 1) \times 2] = 12(10 + 46) = 672$$

So the sum of the first 24 terms of the list is 672.
