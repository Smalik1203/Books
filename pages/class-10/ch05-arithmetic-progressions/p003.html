5.2Arithmetic Progressions

Look at these lists of numbers.

(i) $1, 2, 3, 4, \ldots$

(ii) $100, 70, 40, 10, \ldots$

(iii) $-3, -2, -1, 0, \ldots$

(iv) $3, 3, 3, 3, \ldots$

(v) $-1.0, -1.5, -2.0, -2.5, \ldots$

Each number in a list is called a term. Can you write the next term of each list? To do so, you need the rule that the list follows. Let us find the rule for each one.

In (i), each term is 1 more than the term before it.

In (ii), each term is 30 less than the term before it.

In (iii), each term is got by adding 1 to the term before it.

In (iv), every term is 3, so each term is got by adding 0 to the term before it.

In (v), each term is got by adding $-0.5$ to the term before it, that is, by taking away 0.5.

In every one of these lists, each term after the first is got by adding a fixed number to the term before it. A list like this is called an arithmetic progression, or AP for short.

Arithmetic progression

An arithmetic progression is a list of numbers in which each term, except the first, is got by adding a fixed number to the term before it. This fixed number is called the common difference of the AP. It can be positive, negative or zero.

We write the first term of an AP as $a_1$, the second term as $a_2$, …, the $n$th term as $a_n$, and the common difference as $d$. Then the AP is $a_1, a_2, a_3, \ldots, a_n$, and

$$a_2 - a_1 = a_3 - a_2 = \cdots = a_n - a_{n-1} = d$$
