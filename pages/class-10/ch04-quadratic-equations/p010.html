What this chapter showed
  1. A quadratic equation in the variable $x$ has the form $ax^2 + bx + c = 0$, where $a$, $b$, $c$ are real numbers and $a \neq 0$.
  2. A real number $\alpha$ is a root of $ax^2 + bx + c = 0$ if $a\alpha^2 + b\alpha + c = 0$. The zeroes of the polynomial $ax^2 + bx + c$ and the roots of the equation $ax^2 + bx + c = 0$ are the same.
  3. If $ax^2 + bx + c$ can be factorised into two linear factors, the roots of $ax^2 + bx + c = 0$ are found by setting each factor equal to zero.
  4. The quadratic formula: the roots of $ax^2 + bx + c = 0$ are $\dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$, provided ${b^2 - 4ac \geq 0}$.
  5. The equation $ax^2 + bx + c = 0$ has two distinct real roots if $b^2 - 4ac \gt 0$, two equal real roots if $b^2 - 4ac = 0$, and no real roots if $b^2 - 4ac \lt 0$.

A root that solves the equation does not always answer the question.

When a quadratic equation comes from a problem, check each root against the problem. A length, a speed or a number of people cannot be negative, so a root like $-12$ is set aside, as in Example 8.
