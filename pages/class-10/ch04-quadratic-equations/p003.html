(i) Let the number of marbles John had be $x$. Then Jivanti had $45 - x$ marbles. (Why?) After each loses 5 marbles, John has $x - 5$ and Jivanti has $45 - x - 5 = 40 - x$.

their product $= (x - 5)(40 - x) = 40x - x^2 - 200 + 5x = -x^2 + 45x - 200$

$-x^2 + 45x - 200 = 124$   (the product is 124)

$-x^2 + 45x - 324 = 0$, that is, $x^2 - 45x + 324 = 0$

So the number of marbles John had satisfies the quadratic equation $x^2 - 45x + 324 = 0$. This equation describes the problem mathematically.

(ii) Let the number of toys made that day be $x$. Then each toy cost $55 - x$ rupees to make, and the total cost that day was $x(55 - x)$ rupees.

$x(55 - x) = 750$

$55x - x^2 = 750$, that is, $-x^2 + 55x - 750 = 0$

$x^2 - 55x + 750 = 0$

So the quadratic equation $x^2 - 55x + 750 = 0$ is satisfied by the number of toys made that day.

Example 2

Check whether each of these is a quadratic equation.

  1. $(x - 2)^2 + 1 = 2x - 3$
  2. $x(x + 1) + 8 = (x + 2)(x - 2)$
  3. $x(2x + 3) = x^2 + 1$
  4. $(x + 2)^3 = x^3 - 4$
(i)The LHS is $(x - 2)^2 + 1 = x^2 - 4x + 5$, so the equation is $x^2 - 4x + 5 = 2x - 3$, that is, $x^2 - 6x + 8 = 0$. It has the form $ax^2 + bx + c = 0$, so it is a quadratic equation.
(ii)$x(x + 1) + 8 = x^2 + x + 8$ and $(x + 2)(x - 2) = x^2 - 4$, so $x^2 + x + 8 = x^2 - 4$, that is, $x + 12 = 0$. There is no $x^2$ term, so it is not a quadratic equation.
(iii)The LHS is $2x^2 + 3x$, so $2x^2 + 3x = x^2 + 1$, that is, $x^2 + 3x - 1 = 0$. It is a quadratic equation.
(iv)The LHS is $x^3 + 6x^2 + 12x + 8$, so $x^3 + 6x^2 + 12x + 8 = x^3 - 4$, that is, $6x^2 + 12x + 12 = 0$, or $x^2 + 2x + 2 = 0$. It is a quadratic equation.
