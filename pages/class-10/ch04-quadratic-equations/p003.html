Example 2

Check whether each of these is a quadratic equation.

  1. $(x - 2)^2 + 1 = 2x - 3$
  2. $x(x + 1) + 8 = (x + 2)(x - 2)$
  3. $x(2x + 3) = x^2 + 1$
  4. $(x + 2)^3 = x^3 - 4$

Solution.

Step 1 (i) the LHS is $(x - 2)^2 + 1 = x^2 - 4x + 5$, so $x^2 - 4x + 5 = 2x - 3$
Step 2 $x^2 - 6x + 8 = 0$ the form $ax^2 + bx + c = 0$
Step 3 (ii) $x(x + 1) + 8 = x^2 + x + 8$ and $(x + 2)(x - 2) = x^2 - 4$
Step 4 $x^2 + x + 8 = x^2 - 4$, that is, $x + 12 = 0$ no $x^2$ term
Step 5 (iii) the LHS is $2x^2 + 3x$, so $2x^2 + 3x = x^2 + 1$, that is, $x^2 + 3x - 1 = 0$
Step 6 (iv) the LHS is $x^3 + 6x^2 + 12x + 8$, so $x^3 + 6x^2 + 12x + 8 = x^3 - 4$
Step 7 $6x^2 + 12x + 12 = 0$, or $x^2 + 2x + 2 = 0$ the cubes cancel
Answer (i), (iii) and (iv) are quadratic equations; (ii) is not

Be careful. In (ii), the equation looks quadratic, but it is not. In (iv), the equation looks cubic, an equation of degree 3, but it turns out to be quadratic. So we often need to simplify an equation before we can decide whether it is quadratic.
