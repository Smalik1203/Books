Problem 3

Copies of which regular polygon can fit around a point with no gap and no overlap?

  1. a regular pentagon, each angle $108^\circ$
  2. a regular hexagon, each angle $120^\circ$
  3. a regular octagon, each angle $135^\circ$
  4. a regular decagon, each angle $144^\circ$
Solution

The angles at the point must add up to exactly $360^\circ$, so the angle must divide 360 exactly. $360 \div 120 = 3$, so three hexagons fit, and the answer is (b). For the others, $360 \div 108$, $360 \div 135$ and $360 \div 144$ are not counting numbers: three pentagons leave a gap of $36^\circ$, and two octagons leave $90^\circ$, less than another octagon needs. So of these four, only the regular hexagon can surround a point exactly, which is why a honeycomb can be built of hexagons.

Problem 4

One unit square is removed from a $7 \times 9$ grid. Which square could be removed, so that the rest can possibly be tiled with $2 \times 1$ tiles?

  1. the square in row 1, column 2
  2. the square in row 2, column 3
  3. a corner square
  4. any square at all
Solution

Colour the grid like a chessboard. It has 63 squares: 32 of the corner colour and 31 of the other. A tiling needs equal numbers, so the removed square must have the corner colour. In row 1, column 2 and in row 2, column 3 the square has the other colour, since the row and column numbers add up to an odd number. So the answer is (c), and (d) is wrong. A corner can in fact be removed: tile the rest of its row with 4 tiles across, and the remaining $6 \times 9$ grid with upright tiles.
