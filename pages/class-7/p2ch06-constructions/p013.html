We can construct a regular hexagon more directly if we can construct a $120^\circ$ angle. How do we do that? It is enough to construct a $60^\circ$ angle, because the angle beside it on a straight line is $180^\circ - 60^\circ = 120^\circ$. Each angle of a regular hexagon is $120^\circ$, so we could then build the hexagon one side at a time.

Constructing a $60^\circ$ angle

How do we construct a $60^\circ$ angle? An equilateral triangle has three $60^\circ$ angles, so constructing one gives us the angle. Suppose we need a $60^\circ$ angle at the point A on a segment AX.

  1. Draw an arc with centre A and any radius, cutting AX at B.
  2. With the same radius, draw an arc from B that meets the first arc. Name the meeting point C.
  3. Draw AC. Then $\angle CAX = 60^\circ$.

Why is $\angle CAX = 60^\circ$? Is there an equilateral triangle in the figure? Use these ideas to construct a regular hexagon with sides of 5 cm. Construct a $120^\circ$ angle at each corner in turn, and mark each new side 5 cm long. When you reach the sixth side, it should end exactly where you began. If it does not, the angles or the sides were not quite equal, and you can see how small errors add up as you go round.
