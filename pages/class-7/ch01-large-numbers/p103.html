Problem 2

The nearest ten lakh of 4,95,32,110 is

  1. 4,90,00,000
  2. 5,00,00,000
  3. 4,95,00,000
  4. 4,95,30,000
Solution

Find the two multiples of ten lakh on either side of the number, and the point halfway between them.

Below: 4,90,00,000   Above: 5,00,00,000

Halfway: 4,95,00,000

4,95,32,110 is past the halfway point, so it is nearer 5,00,00,000. The answer is (b). Option (a) rounds down only because the number starts with 4,9; it ignores the digits after. Option (c) is the nearest lakh, and option (d) is the nearest ten thousand.

The nearest ten lakh depends only on the digits below the ten-lakh place. Here they make 5,32,110, which is at least 5,00,000, so the number rounds up. Had they made 4,99,999 or less, it would round down to 4,90,00,000.

Problem 3

$125 \times 88$ is equal to

  1. 10,000
  2. 11,000
  3. 11,250
  4. 12,500
Solution

125 has a partner that makes 1000, and that partner is 8. So split 88 into 8 and 11.

$125 \times 88 = (125 \times 8) \times 11$

$= 1000 \times 11 = 11{,}000$

The answer is (b). The other options are $125 \times 80$, $125 \times 90$ and $125 \times 100$. Each is what you get by rounding 88 before multiplying, which changes the answer by a lot because 125 is large.

The same split works for any number that 8 goes into. For example, 96 is $8 \times 12$, so $125 \times 96 = 1000 \times 12 = 12{,}000$. In the same way, 25 pairs with 4 to make 100.
