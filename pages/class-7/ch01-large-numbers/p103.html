Example 3

3 billion is the same as

  1. 3 crore
  2. 30 crore
  3. 300 crore
  4. 3000 crore

Solution.

Step 1 1 billion = 1,000,000,000 = 1,00,00,00,000 = 100 crore
Step 2 3 billion $= 3 \times 100$ crore $= 300$ crore
Answer (c)

Example 4

Find the place value and the face value of 8 in 4,86,215, and the difference between them. Then write 4,86,215 in expanded form.

Solution.

Step 1 8 is in the ten thousands place.
Step 2 Place value $= 8 \times 10{,}000 = 80{,}000$; face value $= 8$
Step 3 $80{,}000 - 8 = 79{,}992$ difference
Step 4 $4{,}86{,}215 = 4{,}00{,}000 + 80{,}000 + 6{,}000 + 200 + 10 + 5$
Answer 80,000 and 8; the difference is 79,992
