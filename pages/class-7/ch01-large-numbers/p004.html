Example 2

Write 7,05,430 in words. Then write “forty lakh six thousand twenty” in figures.

The commas split 7,05,430 into 7 lakh, 05 thousand and 430.

So 7,05,430 is seven lakh five thousand four hundred thirty.

forty lakh $= 40{,}00{,}000$, six thousand $= 6{,}000$, twenty $= 20$

$40{,}00{,}000 + 6{,}000 + 20 = 40{,}06{,}020$

The number is 40,06,020.

Common mistake

Writing forty lakh six thousand twenty as 40,6,020. Every group between two commas has two digits, so six thousand fills its group as 06: the number is 40,06,020.

Each digit of a number has two values. Its face value is the digit itself. Its place value is the digit times the value of its place. In 3,52,076 the digit 5 is in the ten thousands place, so its face value is 5 and its place value is 50,000.

Adding the place values of all the digits gives the number back. A number written this way is in expanded form.

$3{,}52{,}076 = 3{,}00{,}000 + 50{,}000 + 2{,}000 + 70 + 6$

Place value and expanded form

The face value of a digit is the digit itself. Its place value is the digit times the value of its place. The expanded form of a number is the sum of the place values of its digits.

Example 3

Find the place value and the face value of 8 in 4,86,215, and the difference between them. Then write 4,86,215 in expanded form.

8 is in the ten thousands place.

Place value $= 8 \times 10{,}000 = 80{,}000$, and face value $= 8$

Difference $= 80{,}000 - 8 = 79{,}992$

$4{,}86{,}215 = 4{,}00{,}000 + 80{,}000 + 6{,}000 + 200 + 10 + 5$
