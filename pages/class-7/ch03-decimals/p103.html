Example 3 · Single correct

Which list is in increasing order?

Choose one correct option.

  1. 0.5, 0.45, 0.405, 0.054
  2. 0.054, 0.45, 0.405, 0.5
  3. 0.054, 0.405, 0.45, 0.5
  4. 0.5, 0.405, 0.45, 0.054

Solution.

Step 1Give each number three decimal places: 0.500, 0.450, 0.405 and 0.054.
Step 2Compare the thousandths as whole numbers: 54 < 405 < 450 < 500.
Answer(c) 0.054, 0.405, 0.45, 0.5
Example 4 · Single correct

7.2 − 3.45 is equal to

Choose one correct option.

  1. 4.25
  2. 3.85
  3. 4.75
  4. 3.75

Solution.

Step 1Write 7.2 as 7.20 so both numbers have hundredths.
Step 27.20 − 3.45 = 3.75. Check: 3.75 + 3.45 = 7.20.
Answer(d) 3.75
Example 5 · Single correct

A film lasts 2.75 hours. It starts at 3:00 in the afternoon. When does it end?

Choose one correct option.

  1. 6:15
  2. 5:45
  3. 5:42
  4. 5:07

Solution.

Step 10.75 hour = $\frac{75}{100}$ of 60 minutes = 45 minutes, since each tenth of an hour is 6 minutes and each hundredth is 0.6 minute.
Step 23:00 + 2 hours 45 minutes = 5:45.
Answer(b) 5:45
