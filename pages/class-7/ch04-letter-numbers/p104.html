Example 6 · Single correct

What is the value of $4m - 3(m - 2)$ when $m = 5$?

Choose one correct option.

  1. −1
  2. 11
  3. 5
  4. 17

Solution.

Step 1$4m - 3(m - 2) = 4m - 3m + 6 = m + 6$.
Step 2When $m = 5$ the value is $5 + 6 = 11$. Check: $20 - 3 \times 3 = 11$.
Answer(b) 11
Example 7 · Multiple correct

Which expressions are equal to $3(a - b)$ for every value of $a$ and $b$?

Select all correct options.

  1. $3a - 3b$
  2. $3a - b$
  3. $-3(b - a)$
  4. $a - b + 2a - 2b$

Solution.

Step 1$3(a - b) = 3a - 3b$, and $-3(b - a) = -3b + 3a$ is the same.
Step 2$a - b + 2a - 2b = 3a - 3b$. But $3a - b$ multiplies only $a$ by 3: with $a = 0$, $b = 1$ it gives −1, not −3.
Answer(a), (c), (d)
Example 8 · Multiple correct

Let $a = 2$ and $b = -5$. Which statements are correct?

Select all correct options.

  1. $3(a - b) = 21$
  2. $a + b = -3$
  3. $ab = 10$
  4. $2a - b = -1$

Solution.

Step 1$3(2 - (-5)) = 3 \times 7 = 21$ and $2 + (-5) = -3$.
Step 2$ab = 2 \times (-5) = -10$, and $2a - b = 4 + 5 = 9$.
Answer(a), (b)
