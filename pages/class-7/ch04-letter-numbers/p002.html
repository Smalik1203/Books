Letter-numbers

A letter such as $a$ or $s$ that stands for a number is called a letter-number. An expression that contains letter-numbers, such as $a + 3$, is called an algebraic expression.

We can go the other way too. Aftab is 3 years younger than Shabnam, so his age is 3 less than hers: $a = s - 3$. Use this to find Aftab’s age when Shabnam is 20. Then check your answer using the first expression, $s = a + 3$.

Example 2

How many matchsticks does Parthiv need for 5 Ls? For 7 Ls? For 45 Ls? Write an expression for the number of matchsticks.

Five Ls need $5 \times 2$ matchsticks, 7 Ls need $7 \times 2$, and 45 Ls need $45 \times 2$. Every time, the number of matchsticks is 2 times the number of Ls. If $n$ stands for the number of Ls, the number of matchsticks is

$2 \times n$

To use the expression, we replace $n$ by the number of Ls.

Example 3

Ketaki makes coconut-jaggery laddus. A coconut costs ₹35 and 1 kg of jaggery costs ₹60. How much does she pay for 10 coconuts and 5 kg of jaggery?

$10 \times 35 + 5 \times 60 = 350 + 300 = 650$

She pays ₹650.
