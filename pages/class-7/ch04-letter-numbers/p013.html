4.5Patterns and Relationships

Now we look for more relationships and patterns, and even explain why a pattern happens. It helps to describe a relationship in plain words, or to draw it, before writing it as an expression. Once we have an expression, we check it with a few numbers. Then we can use it to predict, and to show that a pattern holds for every number, not only for the ones we tried.

Formula detective

A number machine takes in two numbers, $a$ and $b$, and does the same operations on them every time. Table 4.15 shows one machine. Its rule is “two times the first number, minus the second number”, which is the expression $2a - b$. For the first pair, the machine works out $2 \times 5 - 2 = 8$. Check that the rule gives the output for every pair.
