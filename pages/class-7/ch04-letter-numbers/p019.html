What this chapter showed
  1. A letter that stands for a number is a letter-number, and an expression that contains letter-numbers is an algebraic expression.
  2. Algebraic expressions give formulas for patterns and for relationships between quantities, and we can use them to make predictions.
  3. An algebraic expression has a value once each letter-number is replaced by a number. $4n$ means $4 \times n$.
  4. The rules for arithmetic expressions work for algebraic expressions too: terms can be swapped and grouped, brackets removed, and the distributive property used.
  5. Like terms can be added into a single term, and unlike terms cannot. Using these rules, an expression can be reduced to its simplest form.
  6. Two expressions are equal only if they have the same value for every value of their letter-numbers. One value where they differ shows they are not equal.
  7. A relationship that takes many words to describe can often be written briefly with letter-numbers. This is one of the strengths of algebra.

When a pattern must hold for every number, let a letter stand for the number, write the pattern with it, and simplify.
