Here $n$ is a letter-number that stands for a position in the sequence.

Writing products

We usually shorten $4 \times n$ to $4n$, leaving out the multiplication sign. The number is written first, and then the letter. So $4n$ means $4 \times n$. In the same way, $pq$ means $p \times q$, and $3(m + 1)$ means $3 \times (m + 1)$.

To find the value of $7k$ when $k = 4$, we work out $7 \times 4 = 28$. And when $m = 2$, the expression $5m + 3$ has the value $5 \times 2 + 3 = 13$. A number written next to a bracket also means multiply: when $m = 2$, $3(m + 1) = 3 \times (2 + 1) = 9$.
