Remove the bracket: $2(n + 5) = 2n + 10$. Now compare $2n + 10$ with $2n + 5$. Both have $2n$, and the first adds 10 while the second adds only 5. So $2(n + 5)$ is larger by 5, for every value of $n$. Simplifying first turned a question about two different-looking expressions into a question about 10 and 5.

The sequence 7, 11, 15, 19, and so on goes up by 4 each time. Is 100 in the sequence? Is 99?

The $n$th term is $4n + 3$: the first term is $4 \times 1 + 3 = 7$, and each step adds 4. So every term is 3 more than a multiple of 4, and leaves remainder 3 when divided by 4. Now 100 is a multiple of 4, so it leaves remainder 0 and is not a term. And $99 = 4 \times 24 + 3$, so 99 is a term: the 24th. We did not need to write out the sequence as far as 100.

A pencil costs ₹$p$ and a notebook costs ₹$n$. Asha buys 4 pencils and 3 notebooks and pays with a ₹100 note. How much change does she get, in rupees?

Choose one correct option.

  1. $100 - 4p + 3n$
  2. $100 - (4p + 3n)$
  3. $100 - 7pn$
  4. $4p + 3n - 100$

Solution.

Step 1She spends $4p + 3n$ rupees altogether.
Step 2The whole cost is taken away from 100, so the bracket is needed: $100 - (4p + 3n)$.
Answer(b) $100 - (4p + 3n)$
