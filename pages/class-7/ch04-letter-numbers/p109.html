Assertion and reason

In Questions 22 to 25, choose (a) if both A and R are true and R explains A; (b) if both are true but R does not explain A; (c) if A is true but R is false; (d) if A is false but R is true.

  1. Assertion (A): $7ab$ and $-2ab$ are like terms.

    Reason (R): Like terms have the same letter-numbers.

  1. Assertion (A): The value of $4 + 2n$ when $n = 3$ is 18.

    Reason (R): In $4 + 2n$, the multiplication is worked out before the addition.

  1. Assertion (A): $4(m + 2) = 4m + 8$.

    Reason (R): A number in front of a bracket multiplies only the first term inside it.

  1. Assertion (A): $7(y - 1) = 7y - 7$ for every value of $y$.

    Reason (R): $7 \times 2 - 1 = 13$.
