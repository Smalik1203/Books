4.4Simplifying Algebraic Expressions

Now a formula for the perimeter of a rectangle. In words, it is length $+$ breadth $+$ length $+$ breadth. Let $l$ stand for the length, $b$ for the breadth and $p$ for the perimeter. Then $p = l + b + l + b$.

The letter-numbers stand for numbers, so the terms can be added in any order. And $l + l = 2 \times l = 2l$, and $b + b = 2b$.

$p = l + b + l + b = l + l + b + b = 2l + 2b$

The expressions $l + b + l + b$ and $2l + 2b$ look different, but they are equal. We got one from the other using only the rules we use for numbers, so they take the same value whatever numbers replace $l$ and $b$. For example, when $l = 3$ and $b = 4$:

$l + b + l + b = 3 + 4 + 3 + 4 = 14$

$2l + 2b = 2 \times 3 + 2 \times 4 = 14$

We call $2l + 2b$ the simplified form of $l + b + l + b$.

Example 5

Table 4.4 shows how many pencils and erasers a shop sold on three days. A pencil costs ₹$c$ and an eraser costs ₹$d$. Find the money the pencils earned.

On Day 1 the pencils earned $5c$ rupees, on Day 2 $3c$, and on Day 3 $10c$, so together they earned $5c + 3c + 10c$. This means $c$ is added $5 + 3 + 10$ times, which is the distributive property at work:

$5 \times c + 3 \times c + 10 \times c = (5 + 3 + 10) \times c = 18c$
