$p = l + b + l + b = l + l + b + b = 2l + 2b$

The expressions $l + b + l + b$ and $2l + 2b$ look different, but they are equal. We got one from the other using only the rules we use for numbers, so they take the same value whatever numbers replace $l$ and $b$. For example, when $l = 3$ and $b = 4$:

$l + b + l + b = 3 + 4 + 3 + 4 = 14$

$2l + 2b = 2 \times 3 + 2 \times 4 = 14$

We call $2l + 2b$ the simplified form of $l + b + l + b$.
