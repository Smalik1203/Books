Together, $\angle a$ and $\angle b$ make a straight angle, which is $180^\circ$. So if $\angle a$ is $120^\circ$, then $\angle b$ is $60^\circ$. In the same way, $\angle b$ and $\angle c$ make a straight angle, so $\angle c$ is $120^\circ$. And $\angle c$ and $\angle d$ make a straight angle, so $\angle d$ is $60^\circ$. So $\angle a = \angle c = 120^\circ$ and $\angle b = \angle d = 60^\circ$.

Is it always true that $\angle a = \angle c$ and $\angle b = \angle d$? Try other sizes for $\angle a$. Better still, we can reason without choosing a size at all. Each of these pairs makes a straight angle:

$\angle a + \angle b = 180^\circ$ and $\angle a + \angle d = 180^\circ$, so $\angle b = \angle d$.

$\angle b + \angle a = 180^\circ$ and $\angle b + \angle c = 180^\circ$, so $\angle a = \angle c$.

Linear pairs and vertically opposite angles

When two lines intersect, two angles next to each other, such as $\angle a$ and $\angle b$, form a linear pair. The angles of a linear pair add up to $180^\circ$. Two angles opposite each other, such as $\angle b$ and $\angle d$, are vertically opposite angles. Vertically opposite angles are always equal.

We showed that vertically opposite angles are equal by reasoning, for every pair of intersecting lines, not by measuring a few. A reason like this, which shows that something is always true, is called a proof.

Look at what the proof used: only the fact that a straight angle is $180^\circ$. It did not use the size of any angle, and nothing had to be measured. That is why it works for every pair of lines at once.
