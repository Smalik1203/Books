Marking parallel and perpendicular lines

In a drawing, we mark lines that are parallel with small arrowheads. If a drawing has more than one set of parallel lines, the first set gets one arrowhead each, the second set two, and so on. We mark perpendicular lines with a small square in the angle between them, as in Fig. 5.8. The marks tell the reader which lines are parallel, without any words beside the figure.
