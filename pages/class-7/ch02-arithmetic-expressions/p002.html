Example 2

Which is greater, $1023 + 125$ or $1022 + 128$?

Think of a story. Raja has 1023 marbles and gets 125 more, so he has $1023 + 125$. Joy has 1022 marbles and gets 128 more, so he has $1022 + 128$. Raja starts with 1 marble more than Joy. But Joy gets 3 marbles more than Raja. So Joy ends up with 2 marbles more, as Fig. 2.1 shows.

$1023 + 125 \lt 1022 + 128$

Example 3

Which is greater, $113 - 25$ or $112 - 24$?

This time Raja has 113 marbles and loses 25, so he has $113 - 25$ left. Joy has 112 marbles and loses 24, so he has $112 - 24$ left. Raja starts with 1 more, but he also loses 1 more. So they are left with the same number.

$113 - 25 = 112 - 24$
