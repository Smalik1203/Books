Example 6 · Single correct

Children stand in a line, and each calls out how many children in front are taller than them. In a line of 6 children, what is the greatest number the last child can call?

Choose one correct option.

  1. 6
  2. 5
  3. 4
  4. 0

Solution.

Step 1The last child has 5 children in front.
Step 2If all 5 are taller, the child calls 5; no more are possible.
Answer(b) 5
Example 7 · Multiple correct

In a line of 5 children, each calls out how many children in front are taller than them. Which of these could be the numbers called, from the front?

Select all correct options.

  1. 0, 1, 2, 3, 4
  2. 0, 0, 0, 0, 0
  3. 1, 0, 0, 0, 0
  4. 0, 1, 1, 4, 2

Solution.

Step 1The children in order of increasing height give 0, 0, 0, 0, 0; in order of decreasing height, 0, 1, 2, 3, 4.
Step 2The first child has nobody in front, so must call 0; the 4th child has only 3 in front, so cannot call 4.
Answer(a), (b)
Example 8 · Multiple correct

Which of these are always odd?

Select all correct options.

  1. The sum of 5 odd numbers
  2. The sum of 6 odd numbers
  3. The sum of 3 odd and 2 even numbers
  4. The product of two odd numbers, plus 1

Solution.

Step 1Odd numbers in pairs add to even numbers, so 5 odd numbers leave one odd number over and 6 leave none: odd, then even.
Step 23 odd and 2 even add to odd. An odd product plus 1 is even.
Answer(a), (c)
