Why the other options are wrong

B1 Ages a year apart are consecutive numbers, whose sum is odd, and 112 is even. So A is false and R is true. The answer is (d).
B3 Each of the three numbers in a row grows by 3, so the row sum grows by 9: $15 + 9 = 24$. The answer is (b). Option (a) adds 3 only once.
B7 M4 $+$ 4M is ${11 \times \mathrm{M} + 44}$, so ${11 \times \mathrm{M} = 77}$ and M $= 7$. Check: $74 + 47 = 121$. The answer is (c).
B8 The parities go odd, even, odd, odd, even, odd, …: the even numbers are in positions 2, 5, 8, and so on, 3 apart. Position 29 is even, so position 30 is odd. The answer is (b). Option (d) cannot be right, because two neighbours in the sequence are never equal after the start.
C2 A sheet carries two consecutive page numbers, so each sheet adds an odd amount. 25 sheets give 25 odd numbers, and their sum is odd. 5000 is even. The answer is (b).
C4 The second child has only one child in front, so can call only 0 or 1. List (c) has the second child calling 2. The answer is (c). In (d), the fifth child calls 4, which is allowed.
C5 After a long syllable 7 beats are left, and there are 21 rhythms of 7 beats. The answer is (c). Option (b) counts all 9-beat rhythms.
