Example 15 · Matching

Each entry in List I describes an isosceles triangle. Match it with the angle in List II.

List IList II
(P) Base angle, when the angle between the equal sides is 100°(1) 45°
(Q) Angle between the equal sides, when a base angle is 50°(2) 120°
(R) Base angle, when the angle between the equal sides is 90°(3) 40°
(S) Angle between the equal sides, when a base angle is 30°(4) 80°

Each entry has exactly one match.

Choose the correct combination.

  1. P–3, Q–1, R–4, S–2
  2. P–4, Q–3, R–1, S–2
  3. P–3, Q–4, R–1, S–2
  4. P–2, Q–4, R–1, S–3

Solution.

Step 1The two base angles are equal and the three angles add to 180°.
Step 2(180° − 100°) ÷ 2 = 40°; 180° − 2 × 50° = 80°; (180° − 90°) ÷ 2 = 45°; 180° − 2 × 30° = 120°.
Answer(c) P–3, Q–4, R–1, S–2
