  1. Each part gives some measurements of $\triangle ABC$ and $\triangle DEF$. In which parts must the triangles be congruent? Give the reason, and write the congruence whenever they are congruent.
    1. $AB = DE$, $BC = EF$, $CA = FD$
    2. $AB = EF$, $\angle A = \angle E$, $AC = ED$
    3. $AB = DF$, $\angle B = \angle D = 90^\circ$, $AC = FE$
    4. $\angle A = \angle D$, $\angle B = \angle E$, $AC = DF$
    5. $AB = DF$, $\angle B = \angle F$, $AC = DE$
