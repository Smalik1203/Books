When we check whether two figures are congruent, we are allowed to turn a figure round, or flip it over, before placing it on the other. So both pairs in Fig. 1.4 are congruent too.

Now go back to the signboard. Suppose there are two symbols that look alike, and we want to be sure that they are congruent. If both have the same arm lengths, is that enough? It is not: Fig. 1.2 shows that figures with the same arms can have different angles between them. Once the angle is fixed, the shape and the size are fixed. So if the two symbols have the same arm lengths and the same angle, they are congruent.
