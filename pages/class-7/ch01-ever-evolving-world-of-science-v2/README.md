All fifteen placed raster images are PNGs, including the contextual opener. The fourteen supporting assets now use genuine RGBA transparency in `figures/class-7/science/ch01-v2/cutouts/`. PDF verification requires real alpha in each asset and a transparency mask in each embedded supporting image.
