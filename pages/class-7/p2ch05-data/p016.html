All it takes is a minute

Have you ever missed watching a cricket match? You can catch up in a minute by looking at a graph like the one in Fig. 5.9.

The overs are numbered along the bottom, starting from 1, and the runs scored in each over are shown up the side, on the scale 1 unit for 5 runs. The graph is a double column graph, with one column for each team. We call the teams Team A and Team B.

Answer these questions using the graph.

  1. Can we tell which team batted first? Which team won the match?
  2. How many runs did Team A score in the 12th over?
  3. In which over did Team B score the fewest runs?
  4. Is it easy to tell the target that the team batting first set?
