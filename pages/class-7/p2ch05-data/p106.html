Example 12

Use Fig. 5.14. (a) In which month did the two classes borrow the most books together? (b) In that month, how many more books did Class 7 borrow than Class 6?

Solution.

Step 1 July $45 + 30 = 75$; August $60 + 55 = 115$ add each pair
Step 2 September $35 + 40 = 75$; October $50 + 70 = 120$
Step 3 October: $70 - 50 = 20$
Answer (a) October (b) 20 books

Example 14

Use Table 5.8. How did the average height of 16-year-olds change from 1989 to 2019?

Solution.

Step 1 Boys: $162.3 - 158.9 = 3.4$ cm 2019 minus 1989
Step 2 Girls: $153.8 - 150.1 = 3.7$ cm
Answer Both rose: boys by 3.4 cm, girls by 3.7 cm.
