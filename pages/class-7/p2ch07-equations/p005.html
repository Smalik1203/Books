7.2Solving Equations Systematically

How did you solve the equations in Section 7.1? One way is to try different values for the letter-number until one of them makes the LHS equal to the RHS. This way of solving is called the trial and error method. Table 7.8 tries it for $2n + 1 = 99$. Each row puts a value of $n$ into the LHS and compares the result with 99, and the next value to try depends on how far away the last one was.

So $n = 49$ is the solution of $2n + 1 = 99$. Can this equation have any other solution? Trial and error can take a long time. Try solving $5x - 4 = 7$ this way.

The same operation on both sides

With the weighing scales, we did not use trial and error. Some weights we could see straight away. For others, we took equal weights off both pans, and the scale stayed balanced. Do equations behave in the same way?

Take the true statement $15 + 8 = 23$. Add 10 to both sides. The LHS becomes $15 + 8 + 10 = 33$ and the RHS becomes $23 + 10 = 33$, so the two sides are still equal. Subtract 3 from both sides instead: the LHS becomes $15 + 8 - 3 = 20$ and the RHS becomes $23 - 3 = 20$. Multiplying both sides by 2 gives 46 on each side. Check what happens when you divide both sides by the same number, say by 23.

Keeping the balance

The two sides of an equation have the same value. So if we add the same number to both sides, subtract the same number from both sides, or multiply or divide both sides by the same number (not 0), the two sides stay equal. This is just like a balanced scale, which stays balanced when the same weight is added to both pans or taken off both pans.
