The same operation on both sides

With the weighing scales, we did not use trial and error. Some weights we could see straight away. For others, we took equal weights off both pans, and the scale stayed balanced. Do equations behave in the same way?

Take the true statement $15 + 8 = 23$. Add 10 to both sides. The LHS becomes $15 + 8 + 10 = 33$ and the RHS becomes $23 + 10 = 33$, so the two sides are still equal. Subtract 3 from both sides instead: the LHS becomes $15 + 8 - 3 = 20$ and the RHS becomes $23 - 3 = 20$. Multiplying both sides by 2 gives 46 on each side. Check what happens when you divide both sides by the same number, say by 23.

Keeping the balance

The two sides of an equation have the same value. So if we add the same number to both sides, subtract the same number from both sides, or multiply or divide both sides by the same number (not 0), the two sides stay equal. This is just like a balanced scale, which stays balanced when the same weight is added to both pans or taken off both pans.

On the scales, we took weights off both pans until the sacks were on one pan only, and that made the problem easy. We can use the same idea on an equation. First, let us try it on some arithmetic.

Example 1

We know that $14593 - 1459 + 145 - 14 + 88 = 13353$. What is the value of $14593 - 1459 + 145 - 14$?

Do we need to work the expression out, one term at a time? No. It is exactly the LHS without the term $+ 88$, and we already know the value of the LHS. Subtracting 88 from both sides removes that term from the LHS:

$14593 - 1459 + 145 - 14 + 88 - 88 = 13353 - 88$

So $14593 - 1459 + 145 - 14 = 13265$. This works because addition and subtraction are inverse operations: one undoes the other. Working the expression out term by term would have taken four calculations, and this took one.

Example 2

We know that $23 \times 41 \times 11 \times 8 \times 7 = 5{,}80{,}888$. What is the value of $23 \times 41 \times 11 \times 8$?

Multiplication and division are inverse operations: dividing by 7 undoes multiplying by 7. So we can simply divide $5{,}80{,}888$ by 7. This gives $23 \times 41 \times 11 \times 8 = 82{,}984$. We can check the answer: $82{,}984 \times 7 = 5{,}80{,}888$.

Is dividing $5{,}80{,}888$ by 7 the same as dividing both sides of the equation by 7, so that the factor 7 is removed from the LHS?
