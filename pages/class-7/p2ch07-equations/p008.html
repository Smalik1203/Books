Can you check that $y = 6$ is the correct solution?

Example 6

Solve $6y + 7 = 4y + 21$.

Both sides of this equation have a term with the unknown. How can we bring the unknown terms to one side? We subtract $4y$ from both sides.

$6y + 7 - 4y = 4y + 21 - 4y$

$2y + 7 = 21$

$2y + 7 - 7 = 21 - 7$   (subtracting 7 from both sides)

$2y = 14$

$2y \div 2 = 14 \div 2$   (dividing both sides by 2)

$y = 7$

It is always a good idea to check your solution.

A shorter way to write the steps

We can solve equations faster if we notice one thing. Look again at the first step for $11y + (-5) = 61$. We subtracted $-5$ from both sides, and this removed the term $-5$ from the LHS. So we could simply have written $11y = 61 - (-5)$. We could also have reached this line by using addition and subtraction as inverse operations, as in Example 1.
