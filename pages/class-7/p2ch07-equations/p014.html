Example 12

Ramesh and Suresh have 60 marbles between them. Ramesh has 30 more marbles than Suresh. How many marbles does each boy have?

This problem has two unknowns. If Ramesh has $x$ marbles and Suresh has $y$ marbles, what equations can we write? The total number of marbles is 60, so $x + y = 60$. Ramesh has 30 marbles more than Suresh, so $x = y + 30$. Fig. 7.14 shows this.

How do we find the unknowns from these equations? So far, we only know how to solve an equation with one unknown. To get such an equation, write the number of marbles Suresh has as $y$, and the number Ramesh has as $y + 30$. The total number of marbles is 60, so

$y + (y + 30) = 60$

$2y + 30 = 60$

Use this equation to find how many marbles each boy has.

Making equations from a solution

So far, we have solved equations to find the value of a letter-number. Can we go the other way, and write equations when we know the value of the letter-number?

Write some equations whose solution is $y = 5$. Share your equations with your classmates, and talk about the methods you used to make them.

Two such equations are $y + 1 = 6$ and $3y = 15$. Table 7.15 shows two chains of equations. In each chain, every equation comes from the one before it by doing the operation written above it on both sides.

Table 7.15 Two chains of equations
startstep 1step 2step 3
chain 1
$y + 1 = 6$		multiply by $-1$
$-y - 1 = -6$		add $y$
$-1 = -6 + y$		add 6
$5 = y$
chain 2
$3y = 15$		add 6
$3y + 6 = 21$		divide by 3
$y + 2 = 7$		subtract 2
$y = 5$
