A shorter way to write the steps

We can solve equations faster if we notice one thing. Look again at the first step for $11y + (-5) = 61$. We subtracted $-5$ from both sides, and this removed the term $-5$ from the LHS. So we could simply have written $11y = 61 - (-5)$. We could also have reached this line by using addition and subtraction as inverse operations, as in Example 1.

In the same way, when we had $11y = 66$, we divided both sides by 11 and the factor 11 left the LHS. So we could have written $y = 66 \div 11$ straight away, as in Example 2. Table 7.9 sets the two ways side by side, for this equation and for $6y + 7 = 4y + 21$. In each row, the shorter way writes down only the result of the step.

Look at Table 7.9 again. The shorter way keeps every equation that has a new RHS, and leaves out only the lines where the same operation is written on both sides. So the two ways do exactly the same steps; the shorter way just writes less. Use whichever way you find clearer, since both give the same solution.

What happens with an equation like $\frac{u}{15} = 6$? Here $u$ is divided by 15. Multiplying both sides by 15 undoes the division and leaves only $u$ on the LHS, so $u = 6 \times 15$, which gives $u = 90$. The divisor 15 has moved to the other side, where it multiplies. We can check this: $90 \div 15 = 6$.
