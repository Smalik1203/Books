Brahmagupta’s rule gives the solution of $Ax + B = Cx + D$ as $x = \dfrac{D - B}{A - C}$. What happens if we use it on $4x + 1 = 4x + 9$?

Here $A = C = 4$, so $A - C = 0$, and the rule asks us to divide by 0, which we cannot do. Look at the equation itself: subtracting $4x$ from both sides leaves $1 = 9$, so it has no solution. The rule works only when $A$ and $C$ are different, and the equation tells us why.

Example 1 · Single correct

What is the solution of $4(x - 2) = 2x + 6$?

Choose one correct option.

  1. 7
  2. 4
  3. −1
  4. 14

Solution.

Step 1Open the bracket: $4x - 8 = 2x + 6$, so $4x - 2x = 6 + 8$.
Step 2$2x = 14$, so $x = 7$. Check: $4 \times 5 = 20$ and $14 + 6 = 20$.
Answer(a) 7
Example 2 · Single correct

A pen costs ₹12 more than a pencil. Three pens and five pencils cost ₹84 in all. What does one pencil cost?

Choose one correct option.

  1. ₹18
  2. ₹9
  3. ₹6
  4. ₹10.50

Solution.

Step 1Let a pencil cost ₹$p$; a pen costs ₹$(p + 12)$. Then $3(p + 12) + 5p = 84$.
Step 2$8p + 36 = 84$, so $8p = 48$ and $p = 6$. Check: $3 \times 18 + 5 \times 6 = 84$.
Answer(c) ₹6
