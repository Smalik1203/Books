Example 6 · Single correct

Which equation says “4 more than three times a number is 19”?

Choose one correct option.

  1. $3n + 4 = 19$
  2. $3(n + 4) = 19$
  3. $4n + 3 = 19$
  4. $3n = 19 + 4$

Solution.

Step 1Three times the number is $3n$, and 4 more than that is $3n + 4$.
Step 2So $3n + 4 = 19$, whose solution is $n = 5$.
Answer(a) $3n + 4 = 19$

Example 8 · Multiple correct

Which equations have the same solution as $2x + 3 = 11$?

Select all correct options.

  1. $2x = 8$
  2. $x + 3 = 11$
  3. $4x + 6 = 22$
  4. $2x = 14$

Solution.

Step 1$2x + 3 = 11$ gives $2x = 8$ and $x = 4$; doubling both sides gives $4x + 6 = 22$, also true for $x = 4$.
Step 2$x + 3 = 11$ gives $x = 8$, and $2x = 14$ gives $x = 7$.
Answer(a), (c)
