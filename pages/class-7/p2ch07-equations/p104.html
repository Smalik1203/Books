Problem 4

Given that $7y - 3 = 25$, the value of $\frac{7y}{2} + 1$ is

  1. 15
  2. 12
  3. 29
  4. 14
Solution

Adding 3 to both sides gives $7y = 28$, so $\frac{7y}{2} = 14$ and $\frac{7y}{2} + 1 = 15$. We never needed $y$ itself. The answer is (a). Option (d) forgets to add 1, and (c) adds 1 to $7y$ without halving it. Option (b) subtracts 3 instead of adding it, taking $7y$ as 22 and getting $11 + 1$.

Problem 5

A pattern uses $5n + 2$ sticks at position $n$. Which of these numbers of sticks makes an arrangement in the pattern?

  1. 100
  2. 112
  3. 125
  4. 150
Solution

A number of sticks works only if $5n + 2$ can equal it for a counting number $n$. For 112, $5n = 110$ and $n = 22$, so the answer is (b). For 100, 125 and 150, the equation gives $5n = 98$, $123$ and $148$. None of these is a multiple of 5, so there is no position with that many sticks.
