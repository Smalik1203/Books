Example 11

Riyaz made up a maths trick and tried it on his friend Akash. He asked Akash to do these steps without saying the answer to any step until the end.

  1. Think of a number.
  2. Subtract 3 from the number.
  3. Multiply the result by 4.
  4. Add 8 to the product.
  5. Say the final answer.

Akash’s final answer was 24. From this, Riyaz found the number Akash had started with. What was it?

Try the steps with different starting numbers. Do you see a link between the starting number and the final answer?

We can find the answer by writing the steps in algebra. That is, we make an equation using an unknown. Let the starting number be $x$. Table 7.3 shows the expression after each step.

Table 7.3 Riyaz’s trick, step by step
stepexpression
Think of a number.$x$
Subtract 3 from the number.$x - 3$
Multiply the result by 4.$4(x - 3) = 4x - 12$
Add 8 to the product.$4x - 12 + 8 = 4x - 4$

Akash’s final answer was 24, so we have this equation.

$4x - 4 = 24$

$4(x - 1) = 24$

$x - 1 = 6$   (dividing both sides by 4)

$x = 7$   (adding 1 to both sides)

So Akash thought of the number 7. Can you think of a simple rule that gives the starting number from the final answer?
