Example 9 · Multiple correct

Kabir buys 3 pens at ₹$p$ each and a notebook for ₹12, and pays ₹42. He writes $3p + 12 = 42$, so $p + 12 = 14$, so $p = 2$. Which statements are correct?

Select all correct options.

  1. Kabir divided $3p$ by 3 but not the 12.
  2. A pen costs ₹10.
  3. With $p = 2$, the left side is 18, not 42.
  4. The correct next step is $3p = 54$.

Solution.

Step 1Subtract 12 first: $3p = 42 - 12 = 30$, so $p = 10$.
Step 2With $p = 2$: $3 \times 2 + 12 = 18$. Adding 12 instead of subtracting would give 54.
Answer(a), (b), (c)
Example 10 · Multiple correct

Brahmagupta’s rule solves $Ax + B = Cx + D$ as $x = (D - B) \div (A - C)$. Use it on $7x - 2 = 3x + 10$. Which statements are correct?

Select all correct options.

  1. $x = (10 - (-2)) \div (7 - 3)$
  2. $x = 3$
  3. $x = (10 + 2) \div (7 + 3)$
  4. When $x = 3$, both sides equal 19.

Solution.

Step 1Here $A = 7$, $B = -2$, $C = 3$ and $D = 10$, so $x = 12 \div 4 = 3$.
Step 2Check: $7 \times 3 - 2 = 19$ and $3 \times 3 + 10 = 19$. The denominator is $A - C$, not $A + C$.
Answer(a), (b), (d)
Example 11 · Numerical answer

Solve $\frac{w}{5} + 3 = 7$.

Enter the numerical value.

Solution.

Step 1Move 3 across: $\frac{w}{5} = 7 - 3 = 4$.
Step 2$w = 4 \times 5 = 20$. Check: $20 \div 5 + 3 = 7$.
