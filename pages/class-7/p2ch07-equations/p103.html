Problem 2

Rahul writes: $\frac{x}{3} - 2 = 5$, so $x - 2 = 15$, so $x = 17$. Which statement is true?

  1. Rahul’s solution is correct.
  2. His first step is wrong, and the solution is $x = 21$.
  3. His second step is wrong, and the solution is $x = 13$.
  4. Both steps are wrong, and the solution is $x = 7$.
Solution

Multiplying both sides by 3 must multiply every term on the LHS, so it gives $x - 6 = 15$, not $x - 2 = 15$. Rahul multiplied $\frac{x}{3}$ by 3 but not the 2. The correct working is

$\frac{x}{3} = 7$   (adding 2 to both sides)

$x = 21$   (multiplying both sides by 3)

The answer is (b). Rahul’s second step is correct for the line he wrote, so (c) is wrong, and (a) is wrong because the first step is not. Option (d) gives the value of $\frac{x}{3}$, not of $x$.

Problem 3

A pen costs ₹12 more than a pencil. Three pens and five pencils cost ₹84 in all. The cost of one pencil is

  1. ₹6
  2. ₹18
  3. ₹9
  4. ₹10.50
Solution

Let a pencil cost ₹$p$. Then a pen costs ₹$(p + 12)$, and

$3(p + 12) + 5p = 84$

$8p + 36 = 84$

$8p = 48$, so $p = 6$

The answer is (a). Option (b) is the cost of a pen. Option (c) comes from adding 12 only once, as $3p + 12 + 5p = 84$. Option (d) forgets the extra ₹12 on each pen and solves $8p = 84$.
