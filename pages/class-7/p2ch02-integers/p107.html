In Questions 14 to 17, choose (a) if both A and R are true and R explains A; (b) if both are true but R does not explain A; (c) if A is true but R is false; (d) if A is false but R is true.

  1. Assertion (A): $(-9) \times (-4) = 36$.

    Reason (R): The product of two negative integers is positive.

  1. Assertion (A): $0 \times (-17) = -17$.

    Reason (R): The product of 0 and any integer is 0.

  1. Assertion (A): $(-8) \times (-5) \times 0 \times (-3) = 0$.

    Reason (R): A product with an odd number of negative factors is always negative.
