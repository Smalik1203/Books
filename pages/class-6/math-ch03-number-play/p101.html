Beyond the Book

The chapter gave you supercells, digit sums, palindromes, the Kaprekar steps, the Collatz rule and the game of 21. Every question below uses only those ideas, but no question tells you which one. Try each question before you read what follows it.

A table has 7 cells in a row, and no number is used twice. What is the largest number of supercells it can have?

Two cells next to each other can never both be supercells. Each would have to be bigger than the other, and that cannot happen. So the supercells must have at least one ordinary cell between them. In 7 cells, the most you can fit is cells 1, 3, 5 and 7. The table 9, 1, 8, 2, 7, 3, 6 has exactly these 4 supercells. Notice that we did not try every way of filling the table. One fact about neighbours was enough.

A grid has 2 rows and 2 columns, and no number is used twice. What is the largest number of supercells it can have?

In this grid each cell has two neighbours: the cell beside it and the cell above or below it. The cell on the slant is not a neighbour. So the two cells on a slant can both be supercells. The grid with 4 and 1 in the top row and 2 and 3 in the bottom row has two supercells, 4 and 3. Three supercells are not possible, because any three cells include two that are neighbours. So the largest number is 2.

Without writing out all the 2-digit numbers, find how many of them have a digit sum of 5.

Think about the tens digit first. It can be 1, 2, 3, 4 or 5, but not 0, or the number would not have 2 digits. Once the tens digit is chosen, the units digit must make the total up to 5. So the numbers are 14, 23, 32, 41 and 50. There are 5 of them, one for each choice of tens digit.

How many 3-digit palindromes are there altogether?

A 3-digit palindrome is fixed by its first two digits, because the last digit must match the first. The first digit can be any of 1 to 9, which is 9 choices. The middle digit can be any of 0 to 9, which is 10 choices. So there are $9 \times 10 = 90$ palindromes, from 101 up to 999.
