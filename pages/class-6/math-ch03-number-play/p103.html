Problem 1

Starting from 1000, the number of Kaprekar rounds needed to reach 6174 is

  1. 3
  2. 4
  3. 5
  4. never
Solution

Remember to keep every number at 4 digits by writing zeros in front. Each line below is one round: A, then B, then C.

$1000 - 0001 = 0999$

$9990 - 0999 = 8991$

$9981 - 1899 = 8082$

$8820 - 0288 = 8532$

$8532 - 2358 = 6174$

The answer is 5 rounds, option (c). Option (d) comes from reading 0999 as the 3-digit number 999: then A and B are both 999, C is 0, and the steps stop. Options (a) and (b) stop counting too soon.

Problem 2

The grid has rows 5, 9, 2 and 8, 1, 7 and 3, 6, 4. How many of its cells are supercells?

  1. 1
  2. 2
  3. 4
  4. 5
Solution

Check each cell against the cells just left, right, above and below it. A corner cell has 2 neighbours, an edge cell 3 and the centre cell 4.

9 beats 5, 2 and 1, so it is a supercell.

8 beats 5, 1 and 3, so it is a supercell.

7 beats 2, 1 and 4, so it is a supercell.

6 beats 1, 3 and 4, so it is a supercell.

No other cell beats all its neighbours, so the answer is 4, option (c). Option (a) counts the cells on the slant as neighbours too; then only 9 is a supercell. Option (d) forgets that 5 has a bigger neighbour, 9. The cells 5, 2, 1, 3 and 4 each have at least one bigger neighbour.
