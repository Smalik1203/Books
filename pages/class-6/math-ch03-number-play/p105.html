Example 7 · Multiple correct

Which statements about the number 50,406 are correct?

Select all correct options.

  1. Its digit sum is 15.
  2. The digit 4 has place value 400.
  3. It is a palindrome.
  4. Its digit 5 has place value 50,000.

Solution.

Step 1The digit sum is 5 + 0 + 4 + 0 + 6 = 15.
Step 2The 4 is in the hundreds place and the 5 in the ten-thousands place. Reversing the digits does not give the original number.
Answer(a), (b), (d)
Example 8 · Multiple correct

Which numbers are palindromes when written as shown?

Select all correct options.

  1. 12021
  2. 30403
  3. 12321
  4. 12231

Solution.

Step 1A palindrome reads the same in either direction.
Step 212021, 30403 and 12321 have matching outside pairs; 12231 reverses to 13221.
Answer(a), (b), (c)
Example 9 · Multiple correct

Which statements follow from the Collatz rule: even n becomes n ÷ 2; odd n becomes 3n + 1?

Select all correct options.

  1. Any positive odd number gives an even number next.
  2. Any positive even number gives an odd number next.
  3. Starting at 12 reaches 3 after two steps.
  4. Starting at 5 reaches 16 after one step.

Solution.

Step 1For odd n, 3n is odd, so 3n + 1 is even. But 8 halves to 4, which is still even.
Step 212 → 6 → 3 and 5 → 16 establish the other two statements.
Answer(a), (c), (d)
