3.10An Unsolved Mystery: the Collatz Conjecture

Look at these four sequences. The same rule makes every one of them.

(a) $12,\ 6,\ 3,\ 10,\ 5,\ 16,\ 8,\ 4,\ 2,\ 1$

(b) $17,\ 52,\ 26,\ 13,\ 40,\ 20,\ 10,\ 5,\ 16,\ 8,\ 4,\ 2,\ 1$

(c) $21,\ 64,\ 32,\ 16,\ 8,\ 4,\ 2,\ 1$

(d) $22,\ 11,\ 34,\ 17,\ 52,\ 26,\ 13,\ 40,\ 20,\ 10,\ 5,\ 16,\ 8,\ 4,\ 2,\ 1$

Can you see the rule? Try to find it before you read on.

The Collatz rule

Start with any counting number. If the number is even, take half of it. If the number is odd, multiply it by 3 and add 1. Do the same to the new number, and keep going.

Check the rule on sequence (a). 12 is even, so the next number is half of 12, which is 6. 6 is even, so the next number is 3. 3 is odd, so the next number is $3 \times 3 + 1 = 10$. Then 10 gives 5, and 5 gives $3 \times 5 + 1 = 16$.

All four sequences above end at 1. In 1937 a German mathematician, Lothar Collatz, guessed that this always happens: whatever counting number you start with, you reach 1 in the end. A guess like this, which nobody has yet shown to be true, is called a conjecture.
