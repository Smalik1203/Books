What this chapter showed
  1. Numbers can carry information. Each child in the line said how many taller neighbours they had.
  2. A supercell holds a number bigger than the numbers in all the cells next to it. The largest number in a table is always in a supercell.
  3. The digit sum of a number is the total of its digits. Many different numbers share the same digit sum.
  4. A palindrome reads the same from both ends. Reversing and adding always turns a 2-digit number into a palindrome in the end.
  5. The Kaprekar steps take every 4-digit number whose digits are not all the same to 6174, the Kaprekar constant.
  6. An estimate is a rough idea of a number, used when the exact number is not known or not needed.
  7. Following a fixed set of steps to work with numbers is called computational thinking. It helps you find patterns, solve puzzles and win games.
  8. Some problems about numbers are easy to state but very hard to solve. Collatz’s conjecture is still unsolved.

When a number puzzle asks what is always possible, try the smallest cases first: a table of 2 cells, then 3, then 4. A pattern in the small cases often shows you the answer for the big ones.
