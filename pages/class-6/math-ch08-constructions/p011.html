Breaking rectangles

Construct a rectangle that can be divided into 3 identical squares, as in Fig. 8.19.

If this seems hard, start with an easier problem. How would you construct a rectangle that can be divided into two identical squares? Try it first.

It helps to plan before you construct. One way to plan is to draw a rough diagram of the finished figure, as in Fig. 8.20. A rough diagram does not need correct lengths. It only needs to show how the parts fit together.

What does the rough diagram tell you? The two squares are identical, so $AB = BC$ and $FE = ED$. Also, $ABEF$ and $BCDE$ are squares, so all the sides of each square are equal:

$AF = AB = BE = FE$

$BE = BC = CD = ED$

So all seven short lines are equal. To show that sides are equal in a drawing, we put the same small mark on each of them.
