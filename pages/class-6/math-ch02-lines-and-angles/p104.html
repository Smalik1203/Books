Problem 4

A wheel has 12 spokes, spaced equally. The biggest acute angle between two of its spokes is

  1. $30^\circ$
  2. $60^\circ$
  3. $90^\circ$
  4. $89^\circ$
Solution

The spokes cut the full turn into 12 equal angles. Every angle between two spokes is made of some of these parts, so it is a multiple of the smallest one.

smallest angle: $360^\circ \div 12 = 30^\circ$

angles between spokes: $30^\circ$, $60^\circ$, $90^\circ$, $120^\circ$, and so on

acute means less than $90^\circ$: so $30^\circ$ or $60^\circ$

The answer is $60^\circ$, option (b). Option (a) is the smallest angle, not the biggest. Option (c) is a right angle, and a right angle is not acute. Option (d) is acute, but it is not a multiple of $30^\circ$, so no two spokes make it.

A wheel with 8 equal spokes works the same way. Each angle is $360^\circ \div 8 = 45^\circ$, so the angles between its spokes are $45^\circ$, $90^\circ$, $135^\circ$ and $180^\circ$. The only acute one is $45^\circ$.

Problem 5

An acute angle is a whole number of degrees. Three times the angle is obtuse, and four times the angle is less than $180^\circ$. The angle could be

  1. $25^\circ$
  2. $35^\circ$
  3. $45^\circ$
  4. $50^\circ$
Solution

Test each condition on each option. An obtuse angle is more than $90^\circ$ and less than $180^\circ$.

$25^\circ$: $3 \times 25^\circ = 75^\circ$, acute, so no

$35^\circ$: $3 \times 35^\circ = 105^\circ$, obtuse; $4 \times 35^\circ = 140^\circ$, less than $180^\circ$, so yes

$45^\circ$: $4 \times 45^\circ = 180^\circ$, not less than $180^\circ$, so no

$50^\circ$: $4 \times 50^\circ = 200^\circ$, so no

The answer is $35^\circ$, option (b). Option (c) fails only just: four times $45^\circ$ is exactly a straight angle. Option (d) passes the first test, since $150^\circ$ is obtuse, but fails the second.

An angle changes its type at $90^\circ$ and at $180^\circ$. Just below $90^\circ$ it is acute, at $90^\circ$ it is right, and just above it is obtuse. So in a question like this, check most carefully the options that land exactly on $90^\circ$ or $180^\circ$, as option (c) did.
