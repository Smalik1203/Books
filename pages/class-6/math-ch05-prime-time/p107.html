Type 6 · Prime puzzles

Example 15

Solve the prime puzzle in Fig. 5.14. Fill each empty square with a prime, so that each row multiplies to the number on its right and each column to the number below it.

Solution.

Step 1 $99 = 3 \times 3 \times 11$ and $110 = 2 \times 5 \times 11$, so 11 goes at the bottom of the last column only they hold 11
Step 2 $28 = 2 \times 2 \times 7$ has no 5, so the last column is 5, 2, 11 from the top
Step 3 the bottom row is 3, 3, 11; the middle column, $18 = 2 \times 3 \times 3$, needs one more 3 and a 2, and 28 has no 3 3 goes in the top row
Step 4 first squares: $30 \div (3 \times 5) = 2$ and $28 \div (2 \times 2) = 7$
Answer rows 2, 3, 5; 7, 2, 2; 3, 3, 11

Check the first column: $2 \times 7 \times 3 = 42$.
