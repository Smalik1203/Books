Subtracting fractions with different denominators

Example 7

Find $\frac{3}{4} - \frac{2}{3}$.

Solution.

Step 1 $\dfrac{3}{4} = \dfrac{3 \times 3}{4 \times 3} = \dfrac{9}{12}, \quad \dfrac{2}{3} = \dfrac{2 \times 4}{3 \times 4} = \dfrac{8}{12}$ same denominators first
Step 2 $\dfrac{3}{4} - \dfrac{2}{3} = \dfrac{9}{12} - \dfrac{8}{12} = \dfrac{1}{12}$ subtract the numerators
Answer $\dfrac{1}{12}$

Brahmagupta’s method for subtracting fractions

Step 1. Write the fractions as equivalent fractions with the same denominator.

Step 2. Subtract the numerators, and keep the denominator.

Step 3. Write the answer in lowest terms if you need to.

Example 8

Find $2\frac{1}{3} - \frac{3}{4}$.

Solution.

Step 1 $2\frac{1}{3} = \frac{7}{3}$ mixed number as a fraction
Step 2 $\dfrac{7}{3} - \dfrac{3}{4} = \dfrac{28}{12} - \dfrac{9}{12}$ write in twelfths
Step 3 $\dfrac{28}{12} - \dfrac{9}{12} = \dfrac{19}{12} = 1\dfrac{7}{12}$
Answer $1\dfrac{7}{12}$

Check by adding back: $\frac{19}{12} + \frac{9}{12} = \frac{28}{12} = 2\frac{4}{12} = 2\frac{1}{3}$, which is where we started.
