Example 3

Which of these are correct?

  1. $\frac{1}{3} + \frac{1}{6} = \frac{1}{2}$
  2. $\frac{3}{4} - \frac{1}{8} = \frac{5}{8}$
  3. $\frac{2}{5} + \frac{1}{5} = \frac{3}{10}$
  4. $\frac{7}{6} = 1 + \frac{1}{6}$

Solution.

Step 1$\frac{1}{3} + \frac{1}{6} = \frac{2}{6} + \frac{1}{6} = \frac{3}{6} = \frac{1}{2}$, and $\frac{3}{4} - \frac{1}{8} = \frac{6}{8} - \frac{1}{8} = \frac{5}{8}$.
Step 2$\frac{2}{5} + \frac{1}{5} = \frac{3}{5}$, not $\frac{3}{10}$. Both fractions count fifths, so only the numerators are added and the denominator stays 5.
Step 3$\frac{7}{6} = \frac{6}{6} + \frac{1}{6} = 1 + \frac{1}{6}$.
CheckTake away what was added in (a): $\frac{1}{2} - \frac{1}{6} = \frac{3}{6} - \frac{1}{6} = \frac{2}{6} = \frac{1}{3}$, which is where the sum began.
Answer(a), (b), (d)
