Problem 2

$\frac{2}{3} + \frac{3}{4} - \frac{5}{6}$ is equal to

  1. $0$
  2. $\dfrac{7}{12}$
  3. $\dfrac{17}{12}$
  4. $\dfrac{5}{6}$
Solution

12 is a common multiple of 3, 4 and 6, so write every fraction in twelfths.

$\dfrac{2}{3} + \dfrac{3}{4} - \dfrac{5}{6} = \dfrac{8}{12} + \dfrac{9}{12} - \dfrac{10}{12} = \dfrac{7}{12}$

The answer is $\frac{7}{12}$, option (b). Option (a) comes from adding and subtracting the numerators $2 + 3 - 5$ as if the units were the same. Option (c) is only $\frac{2}{3} + \frac{3}{4}$, with nothing taken away. Option (d) is the part taken away, not what is left.

You can also judge the size of the answer before working it out. $\frac{2}{3} + \frac{3}{4}$ is a little less than $1\frac{1}{2}$, and $\frac{5}{6}$ is a little less than 1. So the answer should be near $\frac{1}{2}$. Of the four options, $\frac{7}{12}$ is the one closest to $\frac{1}{2}$. An estimate cannot give the exact answer, but it quickly rules out 0 and $\frac{17}{12}$.

Problem 3

Which list is in order from the smallest to the largest?

  1. $\dfrac{3}{5}$, $\dfrac{5}{8}$, $\dfrac{2}{3}$
  2. $\dfrac{5}{8}$, $\dfrac{3}{5}$, $\dfrac{2}{3}$
  3. $\dfrac{2}{3}$, $\dfrac{5}{8}$, $\dfrac{3}{5}$
  4. $\dfrac{3}{5}$, $\dfrac{2}{3}$, $\dfrac{5}{8}$
Solution

The denominators are 5, 8 and 3. Their product, 120, is a common multiple, so write each fraction in hundred-and-twentieths.

$\dfrac{3}{5} = \dfrac{72}{120}, \quad \dfrac{5}{8} = \dfrac{75}{120}, \quad \dfrac{2}{3} = \dfrac{80}{120}$

$72 < 75 < 80$

The answer is option (a). Option (b) swaps the two smaller fractions. Option (c) is the right order read backwards, from the largest. Option (d) puts $\frac{2}{3}$ in the middle, but it is the largest of the three.

There is a second way to see the order. Each fraction is a little more than $\frac{1}{2}$: $\frac{3}{5}$ is $\frac{1}{10}$ more, $\frac{5}{8}$ is $\frac{1}{8}$ more, and $\frac{2}{3}$ is $\frac{1}{6}$ more. Since $\frac{1}{10} < \frac{1}{8} < \frac{1}{6}$, the order is the same. Comparing each fraction with $\frac{1}{2}$ turned the question into comparing fractional units.
