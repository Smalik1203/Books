Fractions

When some things are shared equally, a fraction tells you how big each share is.

Share one roti equally between 2 children. Each child gets half a roti. We write one half as $\frac{1}{2}$. We also read it as one upon two. Now share one roti equally among 4 children. Each child gets $\frac{1}{4}$ roti.

Which share is bigger, $\frac{1}{2}$ roti or $\frac{1}{4}$ roti? In the second group, more children share the same one roti. So each child gets a smaller share, as Fig. 7.1 shows. This means $\frac{1}{2} > \frac{1}{4}$.

7.1Fractional Units and Equal Shares

Beni asks Arvin, “Which is greater, $\frac{1}{5}$ or $\frac{1}{9}$?” Arvin says, “9 is bigger than 5, so $\frac{1}{9}$ must be greater.” This is a common mistake.

Think of the fractions as shares. If one roti is shared among 5 children, each gets $\frac{1}{5}$ roti. If the same roti is shared among 9 children, each gets $\frac{1}{9}$ roti. More children means a smaller share. So $\frac{1}{9} < \frac{1}{5}$. In the same way, $\frac{1}{100}$ is bigger than $\frac{1}{200}$.

As the denominator grows, the fractional unit gets smaller: $\frac{1}{2} > \frac{1}{3} > \frac{1}{4} > \frac{1}{5}$, and so on. A fractional unit is always less than one whole.

Fractional units

When one unit is cut into equal parts, each part is a fractional unit. Fractional units are also called unit fractions. Here are some of them:

$\frac{1}{2},\ \frac{1}{3},\ \frac{1}{4},\ \frac{1}{5},\ \frac{1}{6},\ \ldots,\ \frac{1}{10},\ \ldots,\ \frac{1}{100},\ \ldots$

Fractions have been used and named in India for a very long time. The Rig Veda calls the fraction $\frac{3}{4}$ tri-pada. Many Indian languages still use a word with the same meaning. In Hindi, people say teen paav, and in Tamil they say mukkaal.
