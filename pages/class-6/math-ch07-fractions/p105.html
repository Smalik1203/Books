Example 9 · Multiple correct

Which equalities are correct?

Select all correct options.

  1. $\frac{1}{3}$ + $\frac{1}{6}$ = $\frac{1}{2}$
  2. $\frac{3}{4}$ − $\frac{1}{8}$ = $\frac{5}{8}$
  3. $\frac{2}{5}$ + $\frac{1}{5}$ = $\frac{3}{10}$
  4. $\frac{7}{6}$ = 1 + $\frac{1}{6}$

Solution.

Step 1$\frac{1}{3}$ + $\frac{1}{6}$ = $\frac{2}{6}$ + $\frac{1}{6}$ = $\frac{3}{6}$ = $\frac{1}{2}$; $\frac{3}{4}$ − $\frac{1}{8}$ = $\frac{6}{8}$ − $\frac{1}{8}$ = $\frac{5}{8}$.
Step 2$\frac{2}{5}$ + $\frac{1}{5}$ = $\frac{3}{5}$, not $\frac{3}{10}$. Also, $\frac{7}{6}$ = $\frac{6}{6}$ + $\frac{1}{6}$ = 1 + $\frac{1}{6}$.
Answer(a), (b), (d)
Example 10 · Multiple correct

A number line from 0 to 1 is divided into 12 equal intervals. Which statements are correct?

Select all correct options.

  1. The third division point after 0 represents $\frac{1}{4}$.
  2. The eighth division point represents $\frac{2}{3}$.
  3. The tenth division point represents $\frac{5}{6}$.
  4. The sixth division point represents $\frac{1}{6}$.

Solution.

Step 1The three stated positions are $\frac{3}{12}$ = $\frac{1}{4}$, $\frac{8}{12}$ = $\frac{2}{3}$ and $\frac{10}{12}$ = $\frac{5}{6}$.
Step 2The sixth point is $\frac{6}{12}$ = $\frac{1}{2}$, not $\frac{1}{6}$.
Answer(a), (b), (c)
