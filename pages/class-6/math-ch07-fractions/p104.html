Problem 4

A jug holds $2\frac{1}{4}$ litres of milk. Meera pours out $\frac{3}{4}$ litre, and then $\frac{2}{3}$ litre more. How much milk is left in the jug?

  1. $1\dfrac{1}{2}$ litres
  2. $\dfrac{5}{6}$ litre
  3. $1\dfrac{5}{12}$ litres
  4. $2\dfrac{1}{6}$ litres
Solution

Write the mixed number as a fraction, and take away one amount at a time.

$2\dfrac{1}{4} - \dfrac{3}{4} = \dfrac{9}{4} - \dfrac{3}{4} = \dfrac{6}{4} = \dfrac{3}{2}$

$\dfrac{3}{2} - \dfrac{2}{3} = \dfrac{9}{6} - \dfrac{4}{6} = \dfrac{5}{6}$

The answer is $\frac{5}{6}$ litre, option (b). Option (a) stops after the first pour. Option (c) is the total poured out, $\frac{17}{12}$ litres, not what is left. Option (d) adds the second pour back instead of taking it away.

Check the answer by working backwards. Pour all the milk back into the jug: $\frac{5}{6} + \frac{2}{3} + \frac{3}{4}$. In twelfths this is $\frac{10}{12} + \frac{8}{12} + \frac{9}{12} = \frac{27}{12}$, and $\frac{27}{12} = 2\frac{3}{12} = 2\frac{1}{4}$ litres. That is what the jug held at the start.

Problem 5

Which sum of different fractional units is equal to 1?

  1. $\dfrac{1}{2} + \dfrac{1}{4} + \dfrac{1}{6} + \dfrac{1}{12}$
  2. $\dfrac{1}{2} + \dfrac{1}{3} + \dfrac{1}{4}$
  3. $\dfrac{1}{2} + \dfrac{1}{4} + \dfrac{1}{8} + \dfrac{1}{16}$
  4. $\dfrac{1}{3} + \dfrac{1}{4} + \dfrac{1}{5} + \dfrac{1}{6}$
Solution

For each sum, choose a common denominator and add.

$\dfrac{6}{12} + \dfrac{3}{12} + \dfrac{2}{12} + \dfrac{1}{12} = \dfrac{12}{12} = 1$

$\dfrac{6}{12} + \dfrac{4}{12} + \dfrac{3}{12} = \dfrac{13}{12}$

$\dfrac{8}{16} + \dfrac{4}{16} + \dfrac{2}{16} + \dfrac{1}{16} = \dfrac{15}{16}$

$\dfrac{20}{60} + \dfrac{15}{60} + \dfrac{12}{60} + \dfrac{10}{60} = \dfrac{57}{60}$

The answer is option (a), one of the six ways from the chapter’s puzzle. Option (b) goes past 1. Option (c) always falls short: each unit fills half of the gap that is left, so $\frac{1}{16}$ is still missing. Option (d) starts from $\frac{1}{3}$, so all four units are small and the sum is less than 1.
