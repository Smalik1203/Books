Example 6

Three of these have the same value. Which one has a different value?

  1. $(-6) - (-10)$
  2. $(-6) + (+10)$
  3. $(+10) - (+6)$
  4. $(-10) - (-6)$

Solution.

Step 1 (a) $(-6) - (-10) = (-6) + (+10) = +4$ add the inverse
Step 2 (b) $(-6) + (+10) = +4$
Step 3 (c) $(+10) - (+6) = (+10) + (-6) = +4$ add the inverse
Step 4 (d) $(-10) - (-6) = (-10) + (+6) = -4$ add the inverse
Answer (d), whose value is $-4$

Option (d) is option (a) with the two numbers swapped. Swapping the two numbers in a subtraction gives the inverse of the answer.

Example 7

Find $(-45) - (+28) - (-60)$.

Solution.

Step 1 $(-45) - (+28) - (-60) = (-45) + (-28) + (+60)$ add the inverses
Step 2 $(-45) + (-28) = -73$ both negative
Step 3 $(-73) + (+60) = -13$ the larger is negative
Answer $-13$

Example 8

Use tokens to work out $(+2) - (+5)$.

Solution.

Step 1 Put down 2 positive tokens
Step 2 5 positive tokens must go, so put down 3 zero pairs the value does not change
Step 3 Now there are 5 positive and 3 negative tokens
Step 4 Take away the 5 positive tokens
Answer 3 negative tokens are left, so $(+2) - (+5) = -3$
