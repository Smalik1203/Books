Problem 4

In Leh, the temperature was $-5$ °C at 6 a.m. and $13$ °C at 2 p.m. By how many degrees did it rise?

  1. 8
  2. 18
  3. $-18$
  4. $-8$
Solution

The rise is the movement needed from the starting temperature to the target temperature.

Target $-$ Starting $=$ Movement needed

$13 - (-5) = 13 + (+5) = 18$

It rose by 18 degrees, option (b). On a thermometer, it rises 5 degrees to reach 0 °C and 13 more after that. Option (a) works out $13 - 5$, forgetting that the start was below zero. Option (c) subtracts the wrong way round, $(-5) - 13$, which is the movement for a fall from 13 °C to $-5$ °C. Option (d) is $(-13) - (-5)$, with the sign of 13 changed as well.

Problem 5

The amazing grid game from Section 10.4 is played on a grid with rows $2, -1, 4$ and $-3, -6, -1$ and $5, 2, 7$. Every game on this grid gives the same sum. That sum is

  1. 5
  2. 3
  3. 4
  4. 9
Solution

Play the game once. Any choice will do, because every game gives the same sum. Circle the numbers on the diagonal from the top left.

circle 2, strike out row 1 and column 1

circle $-6$, strike out row 2 and column 2

circle 7, the only number left

$2 + (-6) + 7 = 3$

The sum is 3, option (b). A game circles exactly one number in each row and one in each column. Option (a) adds the whole top row, which circles three numbers in one row. Option (c) adds the whole first column. Option (d) adds all nine numbers in the grid.

Why does every game give 3? Each row of this grid is the top row with the same number added to every entry: the second row is the top row plus $-5$, and the third row is the top row plus 3. A game takes one number from each column of the top row, which always adds to $2 + (-1) + 4 = 5$, and one of each added number, $0 + (-5) + 3 = -2$. So every game gives $5 + (-2) = 3$. The grids in Fig. 10.18 are built the same way.
