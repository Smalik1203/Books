Example 3 · Single correct

Which expression has the greatest value?

Choose one correct option.

  1. −8 + 3
  2. −8 − 3
  3. 3 − (−8)
  4. −3 − (−8)

Solution.

Step 1The four values are −5, −11, 11 and 5.
Step 2Their greatest is 11, obtained from 3 − (−8).
Answer(c) 3 − (−8)
Example 4 · Single correct

A bag contains 7 positive tokens and 11 negative tokens, each worth +1 or −1. Five zero pairs are added. What is the bag’s total value now?

Choose one correct option.

  1. −4
  2. 4
  3. 6
  4. −14

Solution.

Step 1The initial value is 7 − 11 = −4.
Step 2Each zero pair contains one +1 and one −1 token and changes the total by 0.
Answer(a) −4
Example 5 · Single correct

Which integer is exactly halfway between −14 and 8 on a number line?

Choose one correct option.

  1. −11
  2. −3
  3. 3
  4. 11

Solution.

Step 1The distance between the endpoints is 22 units.
Step 2Move 11 units right from −14: −14 + 11 = −3.
Answer(b) −3
