Problem 2

Three of these have the same value. Which one has a different value?

  1. $(-6) - (-10)$
  2. $(-6) + (+10)$
  3. $(+10) - (+6)$
  4. $(-10) - (-6)$
Solution

Change each subtraction into an addition by adding the inverse, and then work it out.

(a) $(-6) - (-10) = (-6) + (+10) = +4$

(b) $(-6) + (+10) = +4$

(c) $(+10) - (+6) = (+10) + (-6) = +4$

(d) $(-10) - (-6) = (-10) + (+6) = -4$

The odd one out is (d), whose value is $-4$. It looks like (a) with the two numbers swapped, and swapping the numbers in a subtraction gives the inverse of the answer. Options (a), (b) and (c) are three ways of writing the same movement, from $-6$ up to $+4$ or from $+6$ up to $+10$, and all come to $+4$.

Problem 3

In a hollow grid, the top left corner is $5$, the top right corner is $-2$ and the bottom left corner is $-6$. The border sum is $+1$. The middle number of the top row and the middle number of the left column are

  1. $-2$ and $+2$
  2. $+2$ and $-2$
  3. $-2$ and $-2$
  4. $-6$ and $-10$
Solution

The top row and the left column each have two numbers you know, and each must add up to the border sum.

top row: $5 + {?} + (-2) = +1$, and $5 + (-2) = 3$, so $? = 1 - 3 = -2$

left column: $5 + {?} + (-6) = +1$, and $5 + (-6) = -1$, so $? = 1 - (-1) = +2$

The answer is option (a). Option (b) has each sign the wrong way round. Option (c) gets the top row right, but in the left column it subtracts the wrong way round: $(-1) - 1 = -2$. Option (d) reads the corners without their signs, as $5$, $2$ and $6$.
