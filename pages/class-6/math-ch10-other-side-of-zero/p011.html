Using an unmarked number line

You can add and subtract large numbers the same way, by imagining a number line that goes on for ever. You do not need to mark every number on it. Draw a line and mark only 0. This is an unmarked number line. You then show, or just imagine, where the other numbers are.

The first line in Fig. 10.7 shows $85 + (-60)$. Start at 85 and jump 60 to the left. You land on 25, so $85 + (-60) = 25$.

The second line shows $(-100) - (+250)$. It asks for the movement needed to go from $+250$ to $-100$, which is the same question as $250 + {?} = -100$. The jump goes 250 to the left to reach 0, and then 100 further. So $? = -350$.

Think and Reflect
  1. On an unmarked number line, which is further from 0, $-250$ or $+100$? On which side of 0 is each one?
  2. A jump starts at $-70$ and lands on $+30$. How long is the jump, and which way does it go?
