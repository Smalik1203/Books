Example 1

Find the button to press in each case, and write the subtraction.

  1. Target Floor $-1$, Starting Floor $-2$
  2. Target Floor $-1$, Starting Floor $+3$
  3. Target Floor $+2$, Starting Floor $-2$

Solution.

Step 1 (a) You go one floor up, so press $+1$:  $(-1) - (-2) = +1$ target minus start
Step 2 (b) You go four floors down, so press $-4$:  $(-1) - (+3) = -4$ target minus start
Step 3 (c) You go four floors up, so press $+4$:  $(+2) - (-2) = +4$ target minus start
Answer (a) press $+1$   (b) press $-4$   (c) press $+4$
