Integers in daily life
  • A credit is a positive number, a debit is a negative number, and the balance is their total.
  • Heights below sea level and temperatures below 0 °C are negative numbers.

10.4Explorations with Integers

A hollow integer grid

Each grid in Fig. 10.18 has 3 rows and 3 columns, with the middle square left empty. There is something special about the numbers in these grids. Here are four sums for the first grid.

Top row:  $4 + (-1) + (-3) = 0$

Bottom row:  $(-1) + (-1) + 2 = 0$

Left column:  $4 + (-3) + (-1) = 0$

Right column:  $(-3) + 1 + 2 = 0$

The top row, the bottom row, the left column and the right column all add up to the same number. We call this number the border sum. The border sum of the first grid is 0.

Border sum
  • A hollow grid has a border sum when its four sides all add up to the same number.
  • Each corner number is in one row and one column, so it is in two of the four sums.
