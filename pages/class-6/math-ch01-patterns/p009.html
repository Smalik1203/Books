Exercise Set 1.4
  1. Find a picture of dots that explains why adding the counting numbers up and then down gives the square numbers.
  1. Find $1 + 2 + 3 + \cdots + 99 + 100 + 99 + \cdots + 3 + 2 + 1$. Imagine a large version of your picture, or draw part of it.
  1. Add up the All 1s sequence: $1$, then $1 + 1$, then $1 + 1 + 1$, and so on. Which sequence do you get? Now add the All 1s up and then down. Which sequence do you get this time?
  1. Add up the counting numbers: $1$, then $1 + 2$, then $1 + 2 + 3$, and so on. Which sequence do you get? Draw a picture to show why.
  1. Add each triangular number to the one after it: $1 + 3$, then $3 + 6$, then $6 + 10$, then $10 + 15$, and so on. Which sequence do you get? Draw a picture to show why.
  1. Add up the powers of 2, starting from 1: $1$, then $1 + 2$, then $1 + 2 + 4$, and so on. Now add 1 to each answer. What numbers do you get? Why does this happen?
  1. Multiply each triangular number by 6, and then add 1. Which sequence do you get? Draw a picture to show why.
  1. The sequence 1, 7, 19, 37, … from Exercise Set 1.3, Question 4, is called the hexagonal numbers. Add them up: $1$, then $1 + 7$, then $1 + 7 + 19$, and so on. Which sequence do you get? Use Fig. 1.7 to explain why.
  1. Add up the cube numbers: $1$, then $1 + 8$, then $1 + 8 + 27$, and so on. Which sequence do you get? Compare them with the square and triangular numbers.
  1. Find a pattern of your own in the sequences of Table 1.1, or a connection between two of them. Can you explain it with a picture, or in some other way?
