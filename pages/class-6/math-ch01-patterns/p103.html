Problem 2

Which of these numbers is both a triangular number and a square number?

  1. 16
  2. 21
  3. 36
  4. 45
Solution

Write out both sequences, and look for a number that is in both. There is no need to go past 45, because 45 is the largest of the options.

Triangular numbers: 1, 3, 6, 10, 15, 21, 28, 36, 45

Square numbers: 1, 4, 9, 16, 25, 36

In both lists: 1 and 36

The answer is 36, option (c). The number 1 is in both lists as well, but it is not one of the options.

16 is a square number but not a triangular number. 21 and 45 are triangular numbers but not square numbers.

Is there a number bigger than 36 that is both a triangular number and a square number? There is, but it is a long way off. The next one is 1225. It is the 49th triangular number, and it is also $35 \times 35$.

Problem 3

In the stacked triangles, the shape with 5 rows is made of how many small triangles?

  1. 10
  2. 15
  3. 25
  4. 16
Solution

Count the small triangles row by row, from the top. Each row has 2 more triangles than the row above it.

Rows: $1,\ 3,\ 5,\ 7,\ 9$

$1 + 3 + 5 + 7 + 9 = 25$

The answer is 25, option (c). The rows are the odd numbers, so the total is a square number. Look at how the triangles point. In each row, the triangles pointing up number 1, 2, 3, 4, 5, and add up to 15, option (b). The triangles pointing down number 0, 1, 2, 3, 4, and add up to 10, option (a). Each of those options counts only one kind, and together they make 25. Option (d) is the shape with 4 rows.

Options (a) and (b) are not chance wrong answers. 10 and 15 are triangular numbers that sit next to each other, and $10 + 15 = 25$. This is the connection from Exercise Set 1.4, Question 5: two triangular numbers next to each other always add up to a square number. The up and down triangles in the stacked triangles are a picture of it.
