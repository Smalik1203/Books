Problem 4

How many lines are there in the complete graph with 7 points?

  1. 7
  2. 14
  3. 21
  4. 49
Solution

Each point is joined to every other point. From one point, 6 lines go out, one to each of the other 6 points.

7 points, 6 lines from each: $7 \times 6 = 42$

but every line has 2 ends, so each line was counted twice

$42 \div 2 = 21$

The answer is 21, option (c). The counts for 2, 3, 4, 5, 6 and 7 points are 1, 3, 6, 10, 15, 21, the triangular numbers. Option (a) gives each point one line, and option (b) gives each point two lines. Option (d) is $7 \times 7$, which joins each point to itself as well.

Problem 5

Work out $1 + 2 + 4 + 8 + 16 + 32$, and then add 1. The answer is

  1. 63
  2. 64
  3. 65
  4. 128
Solution

Add the 1 first, and watch what happens as you go along the sum.

$1 + 1 = 2$

$2 + 2 = 4$

$4 + 4 = 8$

$8 + 8 = 16$

$16 + 16 = 32$

$32 + 32 = 64$

The answer is 64, option (b). Each time, the total so far equals the next power of 2, so adding it doubles the total. Option (a) is the sum before the extra 1 is added. Option (c) adds 2 instead of 1, and option (d) doubles one time too many.

This works because each power of 2 is exactly 1 more than all the powers of 2 before it added together. Try the same thing with the powers of 3: $1 + 3 + 9 + 27 = 40$, and $40 + 1 = 41$, which is not a power of 3. Each power of 3 is much bigger than all the ones before it added together, so the trick does not work for them.
