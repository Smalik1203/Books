If seed anatomy identifies a plant as a monocot, you can predict that it is likely to have parallel venation and fibrous roots. Check those features before claiming the prediction is correct.

Suppose a leaf pattern is clear but the roots have broken during handling. Record the venation as observed and the root type as uncertain. A prediction belongs in a separate column until you can inspect an intact root system. Otherwise, the table would seem to confirm an idea that you had not actually tested.

2.2.2 Grouping Animals

Animals vary as much as plants do. So the same question comes up. Which feature should we use to group them?

Colour or size may be useful for some questions. To compare movement, we need to record how an animal moves and which body parts it uses.
