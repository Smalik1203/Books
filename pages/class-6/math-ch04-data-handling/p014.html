Example 3

Draw a bar graph of the data in Table 4.9.

Draw a line across and a line going up. Mark the items along the line across, equally spaced. Give every bar the same width, with equal gaps between the bars. For the line going up, take 1 unit of length for ₹200, and mark ₹200, ₹400, and so on. Then work out the height of each bar.

House rent: $3000 \div 200 = 15$ units

Food: $3400 \div 200 = 17$ units

Education: $800 \div 200 = 4$ units

Electricity: $400 \div 200 = 2$ units

Transport: $600 \div 200 = 3$ units

Other items: $1200 \div 200 = 6$ units
