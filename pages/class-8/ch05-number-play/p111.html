  1. A six-digit number uses each of the digits $1, 2, 3, 4, 5, 6$ once, in any order. Is it always, sometimes or never divisible by $3$? By $9$? By $11$? Explain each answer.
Case-based questions

  1. A library gives every book a five-digit code, and a code is valid only if it is divisible by $11$. The clerk has written these codes.

    BookCode
    A35728
    B47219
    C80916
    1. Which of the three codes are valid?
    2. A new code starts $6190$. What must its last digit be?
    3. The clerk copies a valid code but swaps two neighbouring digits that are different. Show that the new code cannot be valid.
