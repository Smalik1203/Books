Beyond the Book

The chapter gave you a small set of facts. An odd number and an even number can never be equal, and parity follows fixed rules under $+$ and $-$. A multiple of a number, added to or taken from another multiple of it, gives a multiple of it again. Every place value is one more than a multiple of $9$, and alternately one more and one less than a multiple of $11$. And a number written in digits can be taken apart into its place values with algebra.

Each question below can be answered from those facts. Try each one before you read the explanation that follows it.

Nine cards carry the numbers $1$ to $9$. Can you split them into two piles with the same total? What if there are only eight cards, $1$ to $8$?

Two piles with the same total make a grand total that is that total twice, so the grand total would have to be even. The nine cards add up to $1 + 2 + \cdots + 9 = 45$, which is odd. So it cannot be done, however the cards are chosen.

The eight cards add up to $36$, which is even, so parity does not rule it out. Each pile must hold $18$, and one way is

$1 + 2 + 4 + 5 + 6 = 18 \qquad 3 + 7 + 8 = 18$

Parity answered the first question without trying a single split. For the second it could only say maybe, and an example was still needed.

A number is written with the digit $4$ repeated $36$ times. Is it divisible by $9$? By $11$? By $12$?

Its digit sum is $36 \times 4 = 144$, and $144 = 9 \times 16$, so the number is divisible by $9$.

For $11$, add and subtract the digits in turn from the units digit: $4 - 4 + 4 - 4 + \cdots$ There are $36$ digits, an even number, so they cancel in pairs and the result is $0$. The number is divisible by $11$.

For $12$, check $4$ and $3$, since $12 = 4 \times 3$ and $4$ and $3$ share no factor. The last two digits make $44 = 4 \times 11$, so it is divisible by $4$. Its digit sum $144$ is a multiple of $3$, so it is divisible by $3$. So it is divisible by $12$.
