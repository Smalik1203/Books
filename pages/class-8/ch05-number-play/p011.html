5.2Quick Tests for Divisibility

You already know quick tests for whether a number is divisible by $2$, $4$, $5$, $8$ and $10$. Algebra shows why they work.

We can write any number using letters for its digits. A number $\ldots dcba$ has units digit $a$, tens digit $b$, hundreds digit $c$, thousands digit $d$, and so on. As a sum of place values it is

$\ldots + 1000d + 100c + 10b + a$

For example, in $6038$ we have $d = 6$, $c = 0$, $b = 3$ and $a = 8$. A five-digit number $edcba$ stands for $10000e + 1000d + 100c + 10b + a$.

The test for 10. Every place value except the units is a multiple of $10$. So $10b$, $100c$, $1000d, \ldots$ are all multiples of $10$, and the whole number is a multiple of $10$ exactly when $a$ is. A digit is a multiple of $10$ only if it is $0$. So a number is divisible by $10$ if and only if its units digit is $0$.

The test for 2. Every place value from $10$ up is even, so $10b + 100c + 1000d + \cdots$ is even. So the number is even exactly when its units digit $a$ is even.

In the same way, use the general form to explain the tests for $5$, $4$ and $8$. Next we find tests for some other numbers, and see why they work.

A Test for 9

Without dividing, can you tell which of these are divisible by $9$: $99$, $909$, $9090$, $9909$, $90$? All of them are.

Any number made only of the digits $0$ and $9$ is divisible by $9$. Each term of its general form is $9$ times a place value, or $0$. For example,

$90909 = 9 \times 10000 + 0 \times 1000 + 9 \times 100 + 0 \times 10 + 9 \times 1$

But most multiples of $9$ have other digits, and the units digit alone cannot tell us. The numbers $29$ and $99$ both end in $9$, but only $99$ is divisible by $9$.

So look at what each place value leaves when divided by $9$. Ten is $9 + 1$, so a number of tens is that many more than a multiple of $9$: $50 = 45 + 5$ and $80 = 72 + 8$. A hundred is $99 + 1$, so a number of hundreds is also that many more than a multiple of $9$: $600 = 594 + 6$. In the same way, $4000 = 3996 + 4$. Use this to find the remainder when $538$ is divided by $9$.
