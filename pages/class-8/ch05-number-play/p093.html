Case-based questions

  1. Number games are popular at school fairs. At a maths fair in Bhopal, Tanmay runs one such game. Each visitor writes the numbers $1, 2, 3, 4, 5$ and $6$ in a row and puts a $+$ or a $-$ sign in each gap between them. Then the visitor works out the value. A value of $0$ wins a prize.

    Based on the above information, answer the following questions.

    1. In how many different ways can the signs be placed?
    2. Find the value of $1 - 2 + 3 + 4 - 5 - 6$.
    3. Can any visitor win the prize? Justify your answer.

  1. Many libraries give each book a code, so that it can be found quickly. A school library in Pune gives every book a five-digit code, and a code is valid only if it is divisible by $11$. This catches many copying mistakes. Meenal, the librarian, has written the codes of three new books: A is $35728$, B is $47219$ and C is $80916$.

    Based on the above information, answer the following questions.

    1. Which of the three codes are valid?
    2. The code of a fourth book begins $6190$. Find its last digit.
    3. Meenal copies a valid code but swaps two neighbouring digits that are different. Show that the new code cannot be valid.

  1. Bus tickets often carry a number that can be checked quickly. A bus company in Chennai prints a five-digit number on each ticket, and a ticket is genuine only if its number is divisible by $9$. Selvi, a conductor, checks three tickets during one trip. Their numbers are shown in the table.
