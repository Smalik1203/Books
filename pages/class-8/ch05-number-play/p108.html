Example 9

A locker opens with a five-digit code $4a7b2$, where $a$ and $b$ are digits. The owner remembers only that the code is divisible by $4$ and by $9$.

  1. Which of these could be $b$?
    1. $2$
    2. $3$
    3. $4$
    4. $6$
  2. Numerical answer. How many codes are possible?
  3. Numerical answer. What is the largest possible code?

Solution.

Step 1For $4$, the last two digits $b2$ must be a multiple of $4$: $12, 32, 52, 72, 92$. So $b$ is odd, and of the options only $3$ is odd.
Step 2For $9$, the digit sum $13 + a + b$ must be $18$ or $27$, so $a + b = 5$ or $14$.
Step 3With $b$ odd, the pairs $(a, b)$ are $(4, 1), (2, 3), (0, 5), (9, 5), (7, 7), (5, 9)$. There are $6$ codes in all.
Step 4The largest has the largest $a$: $a = 9$, $b = 5$, giving $49752 = 36 \times 1382$.
Answer(i) (b) $3$; (ii) $6$; (iii) $49752$
