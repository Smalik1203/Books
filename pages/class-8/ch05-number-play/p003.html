$(a + b - c - d) - (a - b - c - d)$
$= a + b - c - d - a + b + c + d$ each sign in the second bracket changes
$= 2b$ an even number

If two numbers differ by an even number, can they have different parities? No. Either both are even or both are odd.

Now see what happens when a $-$ sign is switched to a $+$ sign. Replace any $-$ sign in $a + b - c - d$ with a $+$ sign, and find the difference between the two values. What do you conclude?

Starting from any one expression, you can reach the other seven by switching one or more signs. So all eight expressions have the same parity.

Explanation 2. We know the rules for parity:

$\text{odd} \pm \text{odd} = \text{even}$

$\text{even} \pm \text{even} = \text{even}$

$\text{odd} \pm \text{even} = \text{odd}$

So $a + b$ and $a - b$ have the same parity, whatever the parities of $a$ and $b$. In short, $a \pm b$ has one parity. By the same argument, $a \pm b + c$ and $a \pm b - c$ have the same parity. Going one step further, all the expressions $a \pm b \pm c \pm d$ have the same parity.

Explanation 3. This can also be explained with the positive and negative tokens you used in the chapter on integers. Try to see how. Fig. 5.3 shows the eight expressions for $a$, $b$, $c$ and $d$.

There are infinitely many ways to choose four numbers $a, b, c, d$ and combine them with $+$ and $-$ signs. Reasoning proves that every combination $a \pm b \pm c \pm d$ has the same parity, without going through them one by one.
