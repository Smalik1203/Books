$(p + q - r - s) - (p - q - r - s)$
$= p + q - r - s - p + q + r + s$ each sign in the second bracket changes
$= 2q$ an even number

Two numbers that differ by an even number have the same parity. So changing one sign never changes the parity of the value. Check that the same is true when a $-$ sign is changed to a $+$ sign. Any one expression can be turned into any other by changing signs one at a time, so all eight have the same parity.

Explanation 2. Recall how parity behaves when two numbers are added or subtracted:

$\text{odd} \pm \text{odd} = \text{even}$

$\text{even} \pm \text{even} = \text{even}$

$\text{odd} \pm \text{even} = \text{odd}$

In each line, the sum and the difference have the same parity. So $p + q$ and $p - q$ always have the same parity. By the same rule, $p \pm q + r$ and $p \pm q - r$ have the same parity, and so do the two ways of bringing in $s$. So every expression $p \pm q \pm r \pm s$ has the same parity.

For four consecutive numbers the sum is $n + (n + 1) + (n + 2) + (n + 3) = 4n + 6$, which is even. So all eight values are even. For $3, 8, 10$ and $15$ the sum is $36$, so all eight values are even there too. For $3, 8, 10$ and $14$ the sum is $35$, so all eight are odd.

Parity of sums and differences
  • Odd $\pm$ odd and even $\pm$ even are even; odd $\pm$ even is odd.
  • So $p \pm q \pm r \pm s$ has the same parity for every choice of signs.

Does the same happen with five numbers, or with ten? A guess like this, made from examples and not yet proved, is called a conjecture. Making a conjecture and then testing it is as much a part of mathematics as solving problems.
