5.3Puzzles With Hidden Digits

In a cryptarithm, letters hide the digits of a calculation. The same letter always stands for the same digit, different letters stand for different digits, and no number begins with $0$. The task is to find every digit, and to be sure that no other answer works. Solve the four sums in Fig. 5.13.

Start each one with the units column. In (i), the units digits give $3 + \text{A} = 7$, so A is $4$. Then check the tens column: $4 + 3 = 7$, as it should be. In (iii), the units digits give $3 \times \text{L}$, which must end in L. Only two digits do that. Which are they?

Cryptarithms with multiplication need the same reasoning, with a little more care. Nisha solved this one.
