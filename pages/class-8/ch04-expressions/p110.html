Type 11 · Making a square

Example 17

Find the smallest value of $x^2 + 10x + 32$, and the value of $x$ that gives it.

Solution.

Step 1 $(x + 5)^2 = x^2 + 10x + 25$ half of $10$ is $5$
Step 2 $x^2 + 10x + 32 = (x + 5)^2 + 7$ $32 = 25 + 7$
Step 3 $(x + 5)^2$ is never negative, and is $0$ when $x = -5$
Answer The smallest value is $7$, when $x = -5$
