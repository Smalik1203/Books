4.7.3 An identity is not an equation to solve

One distinction is worth making before the exercises, because it causes more confusion than anything else in this chapter. $2x = 6$ is an equation. It is a question, it is true for one value of $x$ and false for every other, and the thing to do with it is solve it. $(a+b)^2 = a^2 + 2ab + b^2$ is an identity. It is not a question, asking what $a$ is makes no sense, and the thing to do with it is use it.

The test is quick. Put in two or three values of your own choosing. If every one works, you are almost certainly looking at an identity; if only some do, it is an equation. The two sit on the page looking alike — two expressions with an equals sign between them — and trying a value is what tells them apart.
