Example 3 · Single correct

If $2.5 : x :: 10 : 36$, what is $x$?

Choose one correct option.

  1. $14.4$
  2. $90$
  3. $9$
  4. $4$

Solution.

Step 1Cross multiply: $2.5 \times 36 = x \times 10$.
Step 2$90 = 10x$, so $x = 9$.
Answer(c) $9$
Example 4 · Single correct

A machine caps 360 bottles in 15 minutes. Working at the same rate, how many bottles does it cap in $1\tfrac{1}{4}$ hours?

Choose one correct option.

  1. 30
  2. 450
  3. 1500
  4. 1800

Solution.

Step 1$1\tfrac{1}{4}$ hours is 75 minutes, so the proportion is $15 : 360 :: 75 : x$.
Step 2$15x = 360 \times 75$, so $x = 1800$.
Answer(d) 1800
Example 5 · Single correct

₹5,600 is divided between two sisters in the ratio $3 : 4$. How much more does the second sister get than the first?

Choose one correct option.

  1. ₹800
  2. ₹1,400
  3. ₹2,400
  4. ₹3,200

Solution.

Step 1$3 + 4 = 7$ parts, so one part is $5600 \div 7 = 800$ rupees.
Step 2The shares are ₹2,400 and ₹3,200, which differ by one part, ₹800.
Answer(a) ₹800
