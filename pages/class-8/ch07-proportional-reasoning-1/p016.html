7.6Unit Conversions

Two ratios can be compared only when their terms are in the same units. In Example 9 the time was given in minutes and in hours, so the hours were changed to minutes. In Example 10 the weight was given in grams and in kilograms, so the kilograms were changed to grams. A problem of proportion often needs a change of units like this before anything else is done. Table 7.9 gives some useful conversions.

Table 7.9 Some unit conversions
QuantityConversion
Length1 metre = 3.281 feet
Area1 square metre = 10.764 square feet
Area1 acre = 43,560 square feet
Area1 hectare = 10,000 square metres
Area1 hectare = 2.471 acres
Volume1 millilitre (mL) = 1 cubic centimetre (cc)
Volume1 litre = 1,000 mL = 1,000 cc

Notice that $1$ square metre is not $3.281$ square feet. A square $1$ m on each side is $3.281$ ft on each side, so its area is $3.281 \times 3.281$, about $10.764$ square feet.

Changing a temperature between degrees Celsius (°C) and degrees Fahrenheit (°F) takes one more step, because the two scales do not start at the same place: water freezes at $0$ °C, which is $32$ °F. If $C$ is a temperature in degrees Celsius and $F$ is the same temperature in degrees Fahrenheit, then

$F = \dfrac{9}{5} \times C + 32 \qquad \text{and} \qquad C = \dfrac{5}{9} \times (F - 32)$

For example, $35$ °C is $\frac{9}{5} \times 35 + 32 = 63 + 32 = 95$ °F. Because of the $32$ that is added, a Fahrenheit reading is not proportional to the Celsius reading.

Units first
  • Before two ratios are compared, write both terms of each in the same unit.
  • Temperatures change by $F = \frac{9}{5} \times C + 32$, which is not a proportion.
