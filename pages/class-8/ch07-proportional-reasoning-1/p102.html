Can $50$ marbles be shared between two children in the ratio $3 : 2$ without breaking a marble? In the ratio $3 : 4$?

Sharing in the ratio $3 : 2$ means cutting the whole into $3 + 2 = 5$ equal groups. $50 \div 5 = 10$, so the shares are $30$ and $20$ marbles.

Sharing in the ratio $3 : 4$ means $3 + 4 = 7$ equal groups. But $50$ is not a multiple of $7$: $7 \times 7 = 49$ and $7 \times 8 = 56$. A group would hold $7\frac{1}{7}$ marbles, so the sharing cannot be done with whole marbles.

So a number of whole objects can be shared exactly in the ratio $m : n$, written in its simplest form, only when the number is a multiple of $m + n$. That is worth checking before any sharing starts.

Yesterday the temperature was $15$ °C. Today it is $30$ °C. Is today twice as hot as yesterday when the temperatures are read in degrees Fahrenheit?

yesterday $\frac{9}{5} \times 15 + 32 = 27 + 32 = 59$ °F
today $\frac{9}{5} \times 30 + 32 = 54 + 32 = 86$ °F
twice yesterday $2 \times 59 = 118$ not $86$

No. In Celsius the ratio is $15 : 30 = 1 : 2$, but in Fahrenheit it is $59 : 86$, which is not $1 : 2$. The two scales are not proportional, because of the $32$ that is added. It is the same thing that happened to Neelima's age in Example 6: adding the same number to both terms changes a ratio.

The two scales do agree at one temperature. If $F = C$, then $\frac{9}{5} \times C + 32 = C$, so $\frac{4}{5} \times C = -32$ and $C = -40$. At $-40$ degrees, Celsius and Fahrenheit read the same.
