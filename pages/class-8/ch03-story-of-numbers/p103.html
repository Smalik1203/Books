The smallest base that works is $2$, and it is the one every computer uses. What is left if you insist on base one is the tally system of § 3.2 — which is a perfectly good way of recording a number, and is not a place value system, and never was.

Both of those explanations were of the same kind, and neither could have been reached by calculating. The first showed that a numeral fails to name a single number; the second that a proposed system cannot exist. In each case the work was done by taking the definition seriously and following it until it broke — which is a move you will use far more often than any of the arithmetic in this chapter.

The numeral $10$ means ten because our base is ten. What does the numeral $10$ stand for in base $2$, in base $5$ and in base $9$? What does $11$ stand for in each? In which base does the numeral $11$ stand for seven?

Write each numeral in expanded form, with the base written as a letter $n$. The question then answers itself.

$10$ in base $n$ $= 1 \times n + 0 = n$
$11$ in base $n$ $= 1 \times n + 1 = n + 1$
bases 2, 5, 9 $10$ stands for $2$, $5$, $9$;   $11$ for $3$, $6$, $10$
seven $n + 1 = 7$, so base $6$

In every base the numeral $10$ is the base itself — one of the second landmark and none of the first. That is why no base has a single symbol for its own base: the moment a count reaches it, it is written with two.

A dozen is $12$ and a gross is $12$ dozen. An order is for $3$ gross, $5$ dozen and $7$ eggs. How many eggs is that, and how would it be written in base $12$? What base-$12$ numeral stands for one egg more than $3$ gross, $11$ dozen and $11$ eggs?

Dozens and grosses are the landmarks of base $12$: $1$, $12$ and $144$. So the order is already written in places, and only the eggs need counting.

the order $3 \times 144 + 5 \times 12 + 7 = 432 + 60 + 7 = 499$
in base 12 $357$, since each count is less than $12$
one egg more $11$ eggs and $1$ make a dozen; $11$ dozen and $1$ make a gross
so $4$ gross and nothing else: $400$, which is $4 \times 144 = 576$
