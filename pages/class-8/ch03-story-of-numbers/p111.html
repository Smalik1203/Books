Type 10 · Zero and expanded form

Example 17

Write 50 207 in expanded form, and say what each zero in it does.

Solution.

Step 1 $50\,207 = 5 \times 10^4 + 0 \times 10^3 + 2 \times 10^2 + 0 \times 10^1 + 7 \times 10^0$
Step 2 the zeros stand in the thousands place and the tens place empty places
Step 3 without them the digits would read $527$ what they prevent
Answer Each zero marks an empty place and keeps the 5 and the 2 where they belong
Example 18

Write $7 \times 10^5 + 3 \times 10^2 + 9$ as an ordinary numeral.

Solution.

Step 1 the places run $10^5, 10^4, 10^3, 10^2, 10^1, 10^0$ six places
Step 2 digits $7, 0, 0, 3, 0, 9$ a zero where nothing is given
Answer $700\,309$

Type 11 · Comparing the systems

Example 19

Write 2764 in the Roman, Egyptian and Hindu systems, and count the symbols each one uses.

Solution.

Step 1 Roman: MM DCC LX IV, that is MMDCCLXIV, which is $2 + 3 + 2 + 2 = 9$ symbols
Step 2 Egyptian: 2 lotuses, 7 coils, 6 arches, 4 strokes, which is $2 + 7 + 6 + 4 = 19$ one per unit of each
Step 3 Hindu: $2764$, which is 4 digits one per place
Answer Hindu 4, Roman 9, Egyptian 19

The Egyptian count is the sum of the digits, and the Roman count depends on how each digit breaks into landmarks. Ours is one symbol a place, whatever the digit.
