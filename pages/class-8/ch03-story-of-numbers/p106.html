Example 3 · Single correct

A number system has the landmarks 1, 9, 81 and 729. What is its next landmark?

Choose one correct option.

  1. 810
  2. 1458
  3. 6561
  4. 5832

Solution.

Step 1Each landmark is 9 times the one before, so the base is 9.
Step 2The next landmark is $729 \times 9 = 6561$.
Answer(c) 6561
Example 4 · Single correct

What number does the base-5 numeral $3042_{5}$ stand for?

Choose one correct option.

  1. 392
  2. 407
  3. 3042
  4. 397

Solution.

Step 1With the places 125, 25, 5, 1: $3 \times 125 + 0 \times 25 + 4 \times 5 + 2 = 397$.
Answer(d) 397
Example 5 · Single correct

What number does the binary numeral $110101_{2}$ stand for?

Choose one correct option.

  1. 53
  2. 43
  3. 101
  4. 27

Solution.

Step 1The places are 32, 16, 8, 4, 2, 1, so $110101_{2} = 32 + 16 + 4 + 1 = 53$.
Answer(a) 53
Example 6 · Single correct

How is 100 written in base 3?

Choose one correct option.

  1. $10102_{3}$
  2. $10201_{3}$
  3. $1021_{3}$
  4. $11001_{3}$

Solution.

Step 1With the landmarks 81, 27, 9, 3, 1: $100 = 1 \times 81 + 0 \times 27 + 2 \times 9 + 0 \times 3 + 1$.
Answer(b) $10201_{3}$
