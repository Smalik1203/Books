Example 8

Each trick in List I starts from a number you think of. Match it with its result. Each entry has exactly one match.

List IList II
(P) Multiply by 2, add 10, divide by 2, subtract the number(1) 0
(Q) Multiply by 3, add 12, divide by 3, subtract the number(2) 6
(R) Multiply by 5, add 30, divide by 5, subtract the number(3) 5
(S) Add 7, multiply by 2, subtract 14, divide by 2, subtract the number(4) 4
  1. P–4, Q–3, R–2, S–1
  2. P–3, Q–4, R–2, S–1
  3. P–3, Q–2, R–4, S–1
  4. P–1, Q–4, R–2, S–3

Solution.

Step 1In the first three the result is the number added, divided by the multiplier: $\frac{10}{2} = 5$, $\frac{12}{3} = 4$ and $\frac{30}{5} = 6$.
Step 2In the last, $\frac{2(n + 7) - 14}{2} - n = 0$.
CheckTry (Q) with the number 1. It gives 3, then 15, then 5, and $5 - 1 = 4$ is the result in List II.
Answer(b) P–3, Q–4, R–2, S–1
