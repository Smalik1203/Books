Example 1

A trick runs: think of a number, multiply by 4, add $k$, divide by 2, and subtract twice the number. What must $k$ be for the answer always to be 7?

  1. 7
  2. 14
  3. 28
  4. 3.5

Solution.

Step 1$\frac{4n + k}{2} - 2n = 2n + \frac{k}{2} - 2n = \frac{k}{2}$.
Step 2$\frac{k}{2} = 7$, so $k = 14$.
Answer(b) 14
Example 2

The digits of a two-digit number add to 12. Reversing the digits gives a number 18 less. What is the number?

  1. 75
  2. 57
  3. 84
  4. 66

Solution.

Step 1With digits $a$ and $b$: $(10a + b) - (10b + a) = 9(a - b) = 18$, so $a - b = 2$ and the digits differ by 2.
Step 2Put $b = 12 - a$ into $a - b = 2$: $2a - 12 = 2$, so $a = 7$ and $b = 5$. The number is 75.
Check$7 + 5 = 12$ and $75 - 57 = 18$.
Answer(a) 75
