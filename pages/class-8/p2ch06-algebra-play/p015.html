Example 7

A two-digit number plus its reverse is $110$. The number minus its reverse is $54$. Find the number.

Solution. Let the digits be $a$ and $b$, with $a$ the tens digit.

Step 1 $11(a + b) = 110$, so $a + b = 10$
Step 2 $9(a - b) = 54$, so $a - b = 6$
Step 3 put $b = 10 - a$ into $a - b = 6$: $2a - 10 = 6$, so $a = 8$ and $b = 2$
Answer $82$. Check: $82 + 28 = 110$ and $82 - 28 = 54$

Three digits give more patterns. Take any three-digit number $abc$. Make two more numbers by moving the digits round, $bca$ and $cab$. Then add all three.

written out $(100a + 10b + c) + (100b + 10c + a) + (100c + 10a + b)$
collecting $111a + 111b + 111c$
factorising $111(a + b + c)$

Each digit takes each place once, so each is counted $111$ times. Since $111 = 3 \times 37$, the total is always divisible by $3$ and by $37$.

Example 8

Write a three-digit number twice to make a six-digit number: $736$ becomes $736736$. Divide it by $7$, then by $11$, then by $13$. Why is there never a remainder, and what is left at the end?

Solution.

Step 1 $736736 = 736 \times 1000 + 736 = 736 \times 1001$ what writing twice does
Step 2 $1001 = 7 \times 11 \times 13$ three primes
Step 3 the three divisions undo the multiplication by $1001$
Answer Each division is exact, and $736$ is left: the number you started with
