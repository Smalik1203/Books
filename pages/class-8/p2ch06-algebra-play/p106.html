Problem Sets
Three sets of multiple-choice questions, each a little harder than the last.
Set A · One idea each
  1. In a think-of-a-number trick, the letter-number stands for
    1. the answer the trick lands on
    2. one particular number chosen in advance
    3. any number the audience might think of
    4. the number of steps in the trick
  1. Mukta's trick ends at $2$ because the constant added along the way was
    1. $4$
    2. $2$
    3. $8$
    4. $1$
  1. In a number pyramid, each entry is
    1. the sum of the two below it
    2. the product of the two below it
    3. the difference of the two below it
    4. twice the one below it
  1. The top of a three-row pyramid with bottom row $a$, $b$, $c$ is
    1. $a + b + c$
    2. $a + 2b + c$
    3. $2a + b + 2c$
    4. $a + 3b + c$
  1. On a calendar page, the date directly below $a$ is
    1. $a + 7$
    2. $a + 1$
    3. $a + 5$
    4. $a + 30$
  1. The four dates of a $2 \times 2$ calendar square add to
    1. $4a + 8$
    2. $4a + 7$
    3. $2a + 16$
    4. $4a + 16$
  1. Written out in full, the two-digit number with digits $a$ and $b$ is
    1. $a \times b$
    2. $a + b$
    3. $10a + b$
    4. $10b + a$
