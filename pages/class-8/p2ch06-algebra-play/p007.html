6.4What the Top Counts

You can find the top of a pyramid without filling in the middle. Put letter-numbers along the bottom row and work up.

So the top comes straight from the bottom row. For the bottom row $5$, $12$, $6$, the top is $5 + 24 + 6 = 35$. Work up one more row, and a bottom row $a$, $b$, $c$, $d$ gives the top $a + 3b + 3c + d$. So the bottom row $3$, $10$, $7$, $9$ has the top $3 + 30 + 21 + 9 = 63$.

Now look at the multipliers. One row gives $1$. Two rows give $1$, $1$. Three rows give $1$, $2$, $1$. Four rows give $1$, $3$, $3$, $1$. Each row is made from the row before by adding neighbours in pairs, just as the pyramid is.

There is a reason for these numbers. A multiplier counts the routes from a bottom box up to the top. Each route carries the number into the total once more. In a three-row pyramid, the middle box can go up-left or up-right and still reach the top, so it is counted twice. Each end box has only one route.

The top of a pyramid
  • With three rows, the bottom row $a$, $b$, $c$ gives the top $a + 2b + c$.
  • With four rows, the bottom row $a$, $b$, $c$, $d$ gives the top $a + 3b + 3c + d$.
