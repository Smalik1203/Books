6.5What the Top Counts

A pyramid can be climbed without filling in any of the middle. Put letter-numbers along the bottom row and work upwards.

So the top comes straight from the bottom row, with no pyramid drawn: for a bottom row of $4$, $13$, $8$ it is $4 + 26 + 8 = 38$. Carry the same working up one more row and the four bottom entries $a$, $b$, $c$, $d$ give a top of $a + 3b + 3c + d$ — so a bottom row of $8$, $19$, $21$, $13$ has $8 + 57 + 63 + 13 = 141$ at its peak.

The interesting part is the run of multipliers. One row gives $1$; two give $1$, $1$; three give $1$, $2$, $1$; four give $1$, $3$, $3$, $1$. Each of those rows is built from the one before it in exactly the way the pyramid is — by adding neighbours in pairs.

There is a reason those numbers count what they count. A multiplier says how many separate routes lead from that bottom box up to the peak, because every route carries the number once more into the total. In a three-row pyramid the middle box can go up-left or up-right and still arrive, so it is counted twice; the two end boxes have one route each.
