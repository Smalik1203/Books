Example 6

In parallelogram $ABCD$, $AB = 3x + 4$ and $CD = 5x - 6$ centimetres. Find $x$ and the length of $AB$.

$AB$ and $CD$ are opposite sides, so they are equal.

set equal $3x + 4 = 5x - 6$
gather $10 = 2x$,   $x = 5$
so $AB = 3(5) + 4 = 19$ cm

Both expressions must give the same length, and $5(5) - 6 = 19$ as well. An answer that does not survive that check is an answer with an arithmetic slip in it.
