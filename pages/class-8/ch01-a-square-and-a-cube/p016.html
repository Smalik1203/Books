Each row takes up the odd numbers where the last row left off, and the $n$th row has $n$ of them. Squares used the odd numbers from 1 every time; cubes use each odd number exactly once, in runs of growing length. Later in the series comes the row

$91 + 93 + 95 + 97 + 99 + 101 + 103 + 105 + 107 + 109$

Can you tell what this sum is without doing the addition? Count the terms: there are ten, so this is the tenth row, and its sum is $10^3 = 1000$ — the ten numbers are centred on 100.

The odd numbers build the squares and the cubes both — the same bricks, stacked in two different ways.

1.5Cube Roots

We know that $8 = 2^3$. We call 2 the cube root of 8, and write $\sqrt[3]{8} = 2$. Cubing takes 2 to 8; the cube root brings it back.

Cube root

If $y = x^3$, then $x$ is the cube root of $y$, written $x = \sqrt[3]{y}$. So $\sqrt[3]{27} = \sqrt[3]{3^3} = 3$, $\sqrt[3]{1000} = \sqrt[3]{10^3} = 10$, and in general $\sqrt[3]{n^3} = n$.

There is one difference from square roots. The square roots of 64 were $8$ and $-8$, because both square to 64. But $(-2)^3 = -8$, not 8, so $-2$ is not a cube root of 8: it is the cube root of $-8$. Every number has exactly one cube root, and a negative number's cube root is negative — $\sqrt[3]{-8} = -2$ and $\sqrt[3]{-216} = -6$.
