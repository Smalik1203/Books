Using What You Know
The chapter's facts, in questions that do not say which one to use.

The chapter ended with a short list of facts. A square has an odd number of factors. A square ends in $0, 1, 4, 5, 6$ or $9$, and in an even number of zeros. The sum of the first $n$ odd numbers is $n^2$. A number is a square when its primes pair off, and a cube when they come in triplets. Every question below can be answered with those alone. What is new is that the question no longer says which one to use. Try each before reading on.

Try it first

How many factors does $7^2 \times 11^4$ have? Is it a perfect square? Is it a perfect cube?

A factor of $7^2 \times 11^4$ is $7^a \times 11^b$ with $a$ anything from $0$ to $2$ and $b$ anything from $0$ to $4$. That is $3$ choices for $a$ and $5$ for $b$, so $15$ factors. The count is odd, which by the locker argument means the number is a square — and so it is, because both exponents are even: $7^2 \times 11^4 = \left(7 \times 11^2\right)^2 = 847^2$. It is not a cube: $2$ is not a multiple of $3$, so the $7$s cannot be split into three groups. Notice that we never multiplied the number out. The exponents alone answered all three questions.

Try it first

The sum of the first $n$ odd numbers is $2025$. Find $n$, and then find the largest of the numbers added.

The sum of the first $n$ odd numbers is $n^2$, so $n^2 = 2025$ and $n = \sqrt{2025}$. The number is between $40^2 = 1600$ and $50^2 = 2500$, and it ends in $5$, so its root ends in $5$: the root is $45$. The largest number added is the $45$th odd number, $2 \times 45 - 1 = 89$. So $1 + 3 + 5 + \cdots + 89 = 2025$. The chapter's two facts about squares did the whole of this — one to turn the sum into a square, one to find the root without dividing.
