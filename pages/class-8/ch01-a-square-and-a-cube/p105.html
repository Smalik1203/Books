Solution 4

Start with the last digit, which is free. $1447$ ends in $7$, and no square does, so (b) goes at once. That leaves three.

All three lie between $1369 = 37^2$ and $1521 = 39^2$, so the only square available in the range is $38^2$. A number ending in $4$ has a root ending in $2$ or $8$, and $38$ ends in $8$ — which points at (a). Confirm it:

$38^2 = (40 - 2)^2 = 1600 - 160 + 4 = 1444$

So (a) is the answer. Option (c) ends in $0$ but has only one zero, and a square must end in an even number of them; (d) is $2^2 \times 3 \times 11^2$, whose lone $3$ has no partner.

Problem 5 · Try it first

The smallest number that is both a perfect square and a perfect cube, other than $1$, is

  1. $8$
  2. $36$
  3. $64$
  4. $216$
Solution 5

A square needs every prime to occur an even number of times; a cube needs every prime to occur a multiple of three times. To be both, every prime must occur a number of times that is a multiple of $2$ and of $3$ — so a multiple of $6$.

the smallest is one prime six times over: $2^6 = 64 = 8^2 = 4^3$

So the answer is (c). Option (a) is a cube but not a square; (b) is a square but not a cube; (d) is $6^3$, a cube, and its primes occur three times each, which is odd, so it is not a square. The next such number is $3^6 = 729$, and after that $2^{12} = 4096$: they are exactly the sixth powers.
