The first sum is a triangular number. Two consecutive triangular numbers add to a square, but one on its own need not be. Pair the terms from the ends — $1 + 100$, $2 + 99$, and so on — and there are fifty pairs, each adding to $101$, so the sum is $50 \times 101 = 5050$. That ends in $0$, and a square ending in $0$ must end in an even number of zeros. $5050$ has one. So it is not a square, settled by the last two digits alone.

For the second, a cube needs every exponent to be a multiple of three. Here $15$ is, and $10$ is not. So $2^{10} \times 3^{15}$ is not a cube. It is worth asking what would make it one: multiplying by $2^2$ gives $2^{12} \times 3^{15}$, whose cube root is $2^4 \times 3^5 = 3888$. Dividing by $2$ would work as well. The exponents say not only whether a number is a cube, but exactly how far from being one it is.

Try it first

Show that no perfect square is one less than a multiple of four. Then decide: can $n^2 + 2$ ever be a perfect square?

Every whole number is either even or odd. If $n$ is even, say $n = 2k$, then $n^2 = 4k^2$, a multiple of four. If $n$ is odd, say $n = 2k + 1$, then $n^2 = 4k^2 + 4k + 1$, which is one more than a multiple of four. So a square is either a multiple of four or one more than one — never one less. A number like $2023$ or $4507$ can be ruled out at a glance, and this test catches numbers the units digit misses.

The second question uses the chapter's other picture. Consecutive squares are $2n + 1$ apart, and past $n = 1$ that gap is bigger than $2$. So if $n^2 + 2$ were a square, it would have to be $n^2$ itself, which it is not. The only case left to check is $n = 0$, where $n^2 + 2 = 2$, and $2$ is not a square either. Nothing here needed a single square root. The gaps between the squares did the work.

Try it first

A square number has exactly three factors. What can you say about it? Give the three smallest such numbers.

Suppose the number is $N$. Its factors include $1$ and $N$, so the third factor is some $d$ with $1 < d < N$. Since $N$ is a square, its factors pair off around its root, and the only unpaired one is the root itself — so $d = \sqrt{N}$, and $N = d^2$. Now $d$ can have no factor of its own besides $1$ and $d$, or that factor would divide $N$ too and make a fourth. So $d$ is prime, and $N$ is the square of a prime: $4$, $9$, $25$, then $49$ and $121$. A number with exactly three factors is a prime squared, and there is no other kind (Fig. 1B.1).
