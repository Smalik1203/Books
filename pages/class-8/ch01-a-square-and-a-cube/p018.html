The last-digit table on page 12 gives a shortcut for a cube root when you already know the number is a perfect cube: the last digit of the number fixes the last digit of the root, and a bracket between two cubes you know fixes the rest.

Example 11

You are told that 12167 is a perfect cube. Find its cube root without factorising.

last digit 12167 ends in 7, and only a number ending in 3 has a cube ending in 7 ends in 3
bracket $20^3 = 8000 < 12167 < 27000 = 30^3$, so the root lies between 20 and 30 23

Check: $23^3 = 23 \times 23 \times 23 = 529 \times 23 = 12167$.
