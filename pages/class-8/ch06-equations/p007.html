Example 4

Solve $3x + 2 = x + 8$.

given $3x + 2 = x + 8$
$-x$ $2x + 2 = 8$
$-2$ $2x = 6$
$\div 2$ $x = 3$
check $11 = 11$  true

Which side you gather the letters onto is your choice, and both choices give the same answer. There is a reason to prefer one of them.

Gather the letters on the side that already has more of them, and the coefficient comes out positive. In $2x + 1 = 5x - 8$, taking $2x$ from both sides gives $1 = 3x - 8$; taking $5x$ instead gives $-3x + 1 = -8$, which is the same equation with an extra minus sign to carry. Both are right; one has fewer places to go wrong.

Example 5

Solve $2x + 1 = 5x - 8$.

The right side has more $x$s, so gather there.

given $2x + 1 = 5x - 8$
$-2x$ $1 = 3x - 8$
$+8$ $9 = 3x$
$\div 3$ $3 = x$
check $7 = 7$  true

The answer arrives as $3 = x$ rather than $x = 3$, and those say the same thing. An equation read backwards is the same equation; there is nothing to correct.

One warning about the check. Substitute into the equation you were given, not into a line you wrote. If a sign was lost at the second step, every line after it carries the loss, and your answer will check perfectly against the wrong equation.
