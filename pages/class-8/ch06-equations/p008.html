Exercise Set 6.3
  1. Solve.
    1. $5x = 2x + 12$
    2. $7y - 3 = 4y$
    3. $8m = 3m + 20$
    4. $6t + 1 = t + 21$
  1. Solve.
    1. $4x + 3 = 2x + 11$
    2. $9y - 5 = 3y + 7$
    3. $2m + 9 = 5m - 6$
    4. $7 - t = 3t - 1$
  1. Solve $3x - 4 = 8x + 11$ twice — once gathering the letters on the left, once on the right. Say which was easier and why.
  1. Solve.
    1. $5 - 2x = 3 - x$
    2. $4y + 7 = 7y - 8$
    3. $10 - 3m = m - 6$
    4. $2t - 9 = 5 - 5t$
  1. Find the value of $x$ for which $4x + 1$ and $2x + 9$ are equal. What is that common value?
  1. Two rectangles have the same perimeter. One is $x$ by $7$, the other $2x$ by $3$. Find $x$.
  1. Priya writes: $6x - 4 = 2x + 8$, so $4x - 4 = 8$, so $4x = 4$, so $x = 1$. One step is wrong. Find it, and give the correct answer.
  1. For what value of $x$ is $5x - 2$ three times $x + 2$? Write the equation first, then solve it.
  1. Solve $ax + b = cx + d$ for $x$ in letters. Which of the four letters must not be equal to which, and what does the balance say goes wrong if they are?

An equation in letters is worth doing once even where a numerical one would have served. It answers not one question but the whole family the question came from, and it puts the awkward cases on the page instead of leaving them to be found by accident later.

That is the difference between solving and knowing how to solve. Six numerical examples show that a method worked six times; one lettered one shows what the method needs in order to work at all.
