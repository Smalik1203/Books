That is an identity, which is exactly what Chapter 4 was about, and the distinction its last section drew now has a use. An identity dressed up with an equals sign is not a question with an answer. Treating it as one is what leads a reader to write down $x = 0$, or to think the working has failed.

Both cases are recognised by the same thing happening: the letter disappears. What you do next depends only on whether what is left is true.

letter survives one solution — the ordinary case
letter goes, statement false no solution
letter goes, statement true every number is a solution

Nothing is wrong when a letter cancels, and it is worth saying because the instinct is to hunt for the mistake. There is no mistake. The equation has been solved, and the answer is one of the two unusual ones.

Think and Reflect

Find a value of $k$ for which $3x + 7 = 3x + k$ has no solution, and the one value of $k$ for which it has every number as a solution.

Now try $kx + 7 = 3x + 7$. This time there is one value of $k$ that makes every number a solution — and for every other $k$ there is exactly one solution. What is it?

These two cases are not something invented for a textbook. When two prices, two journeys or two plans are compared by setting their expressions equal, no solution means the two never meet, and every solution means they were the same plan under two names. Both of those are answers a person might actually want.
