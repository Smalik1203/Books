6.2.1 Which equations this chapter is about

An equation is linear in one variable when it has one letter in it, that letter appears only to the first power, and it is nowhere in a denominator. All three conditions do work, and each rules out equations that behave quite differently.

$4x - 7 = 9$ linear in one variable
$x^2 = 16$ not linear — and it has two solutions
$2x + y = 5$ two variables — and endlessly many solutions
$\dfrac{6}{x} = 3$ the letter is in a denominator

The first kind is the tidy one, and its tidiness is worth stating: a linear equation in one variable has exactly one solution, no more and no less. The last section of this chapter is about the two ways that promise can be broken, and both of them turn out to be interesting.

Exercise Set 6.1
  1. Write down the left side and the right side of each equation.
    1. $5x = 30$
    2. $2y - 1 = 7$
    3. $9 = 4 + m$
    4. $3t + 2 = t - 6$
  1. Check whether the given value is a solution.
    1. $x = 4$ in $3x - 5 = 7$
    2. $y = -2$ in $5y + 1 = -9$
    3. $m = 6$ in $2m + 3 = 4m - 9$
  1. Which of these are linear equations in one variable? For each that is not, say which condition it breaks.
    1. $7x + 2 = 16$
    2. $x^2 - 4 = 0$
    3. $3a + b = 10$
    4. $\dfrac{5}{n} = 1$
  1. Find, by trying whole numbers, the solution of each.
    1. $x + 7 = 12$
    2. $4x = 28$
    3. $x - 3 = 0$
    4. $2x + 1 = 11$
  1. Show that $x = 3$ is not a solution of $4x - 1 = 12$, and say whether the solution is bigger or smaller than $3$.
  1. Write an equation for each sentence. Do not solve them.
    1. Five more than a number is nineteen.
    2. Three times a number, less four, is twenty.
    3. A number shared between seven people gives each six.
