Example 17

For what value of $k$ is $4(x + k) = 4x + 12$ true for every number? What happens when $k = 1$?

Solution.

Step 1 $4x + 4k = 4x + 12$ expand
Step 2 $4k = 12$ take $4x$ from both
Step 3 this is true only when $k = 3$
Step 4 $k = 1$:   $4 = 12$, which is false
Answer $k = 3$ gives every number; $k = 1$ gives no solution
