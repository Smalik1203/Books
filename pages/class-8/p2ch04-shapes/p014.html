Isometric paper is ruled in exactly these three directions. Drawing on it is counting: so many units along the length, so many along the depth, and so many up. Every edge is drawn at its true length, so the drawing can be measured. But it cannot show which corner is nearer, so an outline of a cube may seem to flip. Shading one face settles it.
