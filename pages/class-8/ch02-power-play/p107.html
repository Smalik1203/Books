Example 3

Which of these are equal to $2^{12}$?

  1. $(2^3)^4$
  2. $2^3 \times 2^4$
  3. $4^6$
  4. $8^4$

Solution.

Step 1$(2^3)^4 = 2^{12}$, $4^6 = (2^2)^6 = 2^{12}$ and $8^4 = (2^3)^4 = 2^{12}$.
Step 2$2^3 \times 2^4 = 2^7$: exponents add when powers are multiplied.
Check$8^4 = 4096 = 2^{12}$, while $2^7 = 128$.
Answer(a), (c), (d)
Example 4

Which statements are true for every number $x \ne 0$?

  1. $x^0 = 1$
  2. $x^{-2} = \frac{1}{x^2}$
  3. $\frac{(x^{-2})^3 \times x^4}{x^{-5}} = x^3$
  4. $x^2 \times x^3 = x^6$

Solution.

Step 1$x^0 = 1$ and $x^{-2} = \frac{1}{x^2}$ by definition. In (c) the exponents give $-6 + 4 - (-5) = 3$, so (c) is true.
Step 2$x^2 \times x^3 = x^5$, not $x^6$.
CheckPut $x = 2$ in (c): $\frac{2^{-6} \times 2^4}{2^{-5}} = 2^{3} = 8$.
Answer(a), (b), (c)
