Example 5 · Single correct

What is the last digit of $3^{25} + 7^{25}$?

Choose one correct option.

  1. 0
  2. 4
  3. 6
  4. 8

Solution.

Step 1The last digits of the powers of 3 repeat 3, 9, 7, 1, and of 7 repeat 7, 9, 3, 1: every 4 powers.
Step 2$25 = 4 \times 6 + 1$, so $3^{25}$ ends in 3 and $7^{25}$ in 7; $3 + 7 = 10$ ends in 0.
Answer(a) 0
Example 6 · Single correct

A quiz has 6 questions, each with 3 options. In how many ways can the answer sheet be filled in, with one option per question?

Choose one correct option.

  1. 18
  2. 729
  3. 216
  4. 36

Solution.

Step 1Each question can be answered in 3 ways, independently of the others.
Step 2$3 \times 3 \times 3 \times 3 \times 3 \times 3 = 3^6 = 729$.
Answer(b) 729
Example 7 · Multiple correct

Which of these are equal to $2^{12}$?

Select all correct options.

  1. $(2^3)^4$
  2. $2^3 \times 2^4$
  3. $4^6$
  4. $8^4$

Solution.

Step 1$(2^3)^4 = 2^{12}$, $4^6 = (2^2)^6 = 2^{12}$ and $8^4 = (2^3)^4 = 2^{12}$.
Step 2$2^3 \times 2^4 = 2^7$: exponents add when powers are multiplied.
Answer(a), (c), (d)
