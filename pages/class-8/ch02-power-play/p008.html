Example 3

Find $2^5 \times 5^5$.

Evaluating $32 \times 3125$ would work. Noticing the shared exponent is quicker.

$2^5 \times 5^5$ $= (2 \times 5)^5 = 10^5$ $100000$

Whenever a pair of bases multiplies to something convenient — and $2$ and $5$ almost always do, because they make $10$ — this is the law to look for.

There is a matching law for division, which we shall be able to state properly in a moment: $\dfrac{m^a}{n^a} = \left(\dfrac{m}{n}\right)^a$, on the same argument with the pairs written as fractions.

2.3.3 Dividing

A line is $16$ units long — that is $2^4$ — and half of it is rubbed out. What is left is $2^4 \div 2$, and it is easiest to see written as a fraction with the cancelling shown:

$\dfrac{2^4}{2^1} = \dfrac{2 \times 2 \times 2 \times 2}{2} = 2 \times 2 \times 2 = 2^3 = 8$

Rub out half of what is left, twice more, and the same cancelling happens each time:

$2^4 \div 2^2$ $= 2^2 = 4$
$2^4 \div 2^3$ $= 2^1 = 2$

Every factor on the bottom cancels one on the top, so the exponents subtract. That is the third law, and it is the first law run backwards — which it has to be, since division undoes multiplication.

Dividing powers of the same base

$n^a \div n^b = n^{a-b}$, for any $n$ other than $0$. Multiplying adds the exponents, so dividing subtracts them.

The exclusion of $n = 0$ is not fussiness. Dividing by $0^b$ would be dividing by zero, which is not defined, so the law has nothing to say there.
