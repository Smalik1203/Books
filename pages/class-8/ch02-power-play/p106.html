Example 2 · Single correct

If $(2^3)^n \times 2^2 = 2^{14}$, what is $n$?

Choose one correct option.

  1. 3
  2. 4
  3. 5
  4. 6

Solution.

Step 1$(2^3)^n \times 2^2 = 2^{3n} \times 2^2 = 2^{3n + 2}$.
Step 2$3n + 2 = 14$, so $n = 4$.
Answer(b) 4
Example 3 · Single correct

$27^4 \times 9^3$, written as a single power of 3, is

Choose one correct option.

  1. $3^{36}$
  2. $3^{24}$
  3. $3^{18}$
  4. $3^{12}$

Solution.

Step 1$27^4 = (3^3)^4 = 3^{12}$ and $9^3 = (3^2)^3 = 3^6$.
Step 2$3^{12} \times 3^6 = 3^{18}$.
Answer(c) $3^{18}$
Example 4 · Single correct

What is $\left(3^{-1} + 4^{-1}\right)^{-1}$?

Choose one correct option.

  1. $\frac{7}{12}$
  2. 7
  3. $\frac{1}{7}$
  4. $\frac{12}{7}$

Solution.

Step 1$3^{-1} + 4^{-1} = \frac{1}{3} + \frac{1}{4} = \frac{7}{12}$.
Step 2The power $-1$ takes the reciprocal: $\frac{12}{7}$.
Answer(d) $\frac{12}{7}$
