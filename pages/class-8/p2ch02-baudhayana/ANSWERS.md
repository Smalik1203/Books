## 2.3 Halving a Square

### Exercise Set 2.1

1. Square on the diagonal: $2 \times 36 = 72$ cm². Square joining the
   midpoints: $36 \div 2 = 18$ cm².

2. Each square has twice the area of the one before: **2, 4, 8, 16**.

3. Tripling the side multiplies the area by $3 \times 3 = 9$. Halving it
   multiplies the area by $\tfrac12 \times \tfrac12 = \tfrac14$.

4. The square on the diagonal of a square of side 5 has area
   $2 \times 25 = 50$; a square of side 7 has area $7^2 = 49$. **The square on
   the diagonal is larger, by 1.**

5. Folding the corners in to the centre makes the midpoint square:
   $64 \div 2 = 32$ cm². Folding the new corners in halves it again:
   $32 \div 2 = 16$ cm².

6. The areas are $10^2 = 100$ cm², $2 \times 100 = 200$ cm² and
   $2 \times 200 = 400$ cm². The first square has side 10 cm and the third has
   side $\sqrt{400} = 20$ cm, both whole numbers. The middle one has side
   $\sqrt{200}$, which is not a whole number and has no exact decimal: it lies
   between 14.1 and 14.2, since $14.1^2 = 198.81$ and $14.2^2 = 201.64$.
   **The first and the third.** (Answers that give $\sqrt{200}$ as an exact
   value of the middle side are also right; what matters is that it has no
   exact decimal.)

## 2.6 Finding a Side You Cannot Reach

### Exercise Set 2.2

1. (a) $6^2 + 8^2 = 36 + 64 = 100$, so **10**.
   (b) $5^2 + 12^2 = 25 + 144 = 169$, so **13**.
   (c) $9^2 + 40^2 = 81 + 1600 = 1681$, so **41**.
   (d) $1^2 + 1^2 = 2$, so **$\sqrt2$**.

2. (a) $10^2 - 6^2 = 100 - 36 = 64$, so **8**.
   (b) $25^2 - 7^2 = 625 - 49 = 576$, so **24**.
   (c) $17^2 - 15^2 = 289 - 225 = 64$, so **8**.

3. Square: $d^2 = 5^2 + 5^2 = 50$, so $d = \sqrt{50}$ cm, a little over 7 cm
   ($7.07^2 = 49.9849$ and $7.08^2 = 50.1264$). Rectangle:
   $d^2 = 9^2 + 12^2 = 81 + 144 = 225$, so **15 cm**.

4. Foot 5 m out: $13^2 - 5^2 = 169 - 25 = 144$, so it reaches **12 m** up.
   Foot 12 m out: $169 - 144 = 25$, so it reaches **5 m** up.

5. **Yes.** $c^2 = a^2 + b^2$, and $b^2$ is more than 0, so $c^2$ is more than
   $a^2$, and $c$ is longer than $a$. In the same way $c$ is longer than $b$.

6. (a) $8^2 + 15^2 = 64 + 225 = 289 = 17^2$: **right-angled**, hypotenuse 17.
   (b) $7^2 + 8^2 = 49 + 64 = 113$, but $11^2 = 121$: **not right-angled**.
   The hypotenuse would have been 11.
   (c) $20^2 + 21^2 = 400 + 441 = 841 = 29^2$: **right-angled**, hypotenuse 29.
   (d) $4^2 + 5^2 = 16 + 25 = 41$, but $6^2 = 36$: **not right-angled**.
   The hypotenuse would have been 6.

## 2.7 Triples

### Exercise Set 2.3

1. (a) $81 + 144 = 225 = 15^2$: **a triple**.
   (b) $16 + 25 = 41$, but $6^2 = 36$: **not a triple**.
   (c) $400 + 441 = 841 = 29^2$: **a triple**.
   (d) $100 + 576 = 676 = 26^2$: **a triple**.

2. **(3, 4, 5), (6, 8, 10), (5, 12, 13), (9, 12, 15), (8, 15, 17),
   (12, 16, 20).** The primitive ones are **(3, 4, 5), (5, 12, 13) and
   (8, 15, 17)**; the other three are 2, 3 and 4 times (3, 4, 5).

3. $m = 5$, $n = 2$: $25 - 4 = 21$, $2 \times 5 \times 2 = 20$,
   $25 + 4 = 29$, so **(21, 20, 29)**. Check: $441 + 400 = 841 = 29^2$.
   $m = 5$, $n = 4$: $25 - 16 = 9$, $2 \times 5 \times 4 = 40$,
   $25 + 16 = 41$, so **(9, 40, 41)**. Check: $81 + 1600 = 1681 = 41^2$.

4. **There is none.** The square of an odd number is odd, and two odd
   numbers add to an even number. So if $a$ and $b$ are both odd, $a^2 + b^2$
   is even; then $c^2$ is even, and so $c$ is even. If $a$ and $b$ are not both
   odd, one of them is already even. Either way, one of the three is even.
   A worked instance: $3$ and $5$ are odd, $9 + 25 = 34$ is even, and 34 is not
   a square anyway.

## 2.8 One Question, Three Hundred Years

### Think and Reflect

A single example would have been enough to show that such numbers exist. But
there are endlessly many whole numbers to try, and a search, however long,
only ever checks some of them. Not finding an example in three hundred years
says nothing about the numbers nobody tried, so only a proof that covers
every case could settle it — which is what Wiles gave in 1994.
