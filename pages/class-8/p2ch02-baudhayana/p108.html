Type 7 · Multiples of a triple

Example 13

Is $(27, 36, 45)$ a Baudhāyana triple? Is it primitive?

Solution.

Step 1 $27^2 + 36^2 = 729 + 1296 = 2025 = 45^2$ it is a triple
Step 2 $27$, $36$ and $45$ are all multiples of $9$ a common factor
Answer Yes, it is a triple, but not primitive: it is $9$ times $(3, 4, 5)$
Example 14

Find the multiple of the triple $(12, 35, 37)$ whose largest number is $111$.

Solution.

Step 1 $k = 111 \div 37 = 3$ compare largest numbers
Step 2 $(3 \times 12, 3 \times 35, 3 \times 37)$ multiply each number
Step 3 $36^2 + 105^2 = 1296 + 11025 = 12321 = 111^2$ check
Answer $(36, 105, 111)$

Type 8 · The triple machine

Example 15

Use the machine $m^2 - n^2$, $2mn$, $m^2 + n^2$ with $m = 8$ and $n = 3$, and check the triple it makes.

Solution.

Step 1 $m^2 - n^2 = 64 - 9 = 55$
Step 2 $2mn = 2 \times 8 \times 3 = 48$
Step 3 $m^2 + n^2 = 64 + 9 = 73$
Step 4 $55^2 + 48^2 = 3025 + 2304 = 5329 = 73^2$ check
Answer $(55, 48, 73)$
