Example 14

In triangle $ABC$, the point $D$ lies on $BC$ and $AD$ is perpendicular to $BC$. If $AD = 24$, $AB = 51$ and $AC = 40$, find $BC$.

Solution.

Step 1 $BD^2 = 51^2 - 24^2 = 2601 - 576 = 2025$, so $BD = 45$ triangle $ABD$
Step 2 $CD^2 = 40^2 - 24^2 = 1600 - 576 = 1024$, so $CD = 32$ triangle $ACD$
Step 3 $BC = BD + CD = 45 + 32$ $D$ is between $B$ and $C$
Answer $BC = 77$

The perpendicular $AD$ made two right-angled triangles out of one that has none.

Type 8 · Multiples of a triple

Example 15

Is $(27, 36, 45)$ a Baudhāyana triple? Is it primitive?

Solution.

Step 1 $27^2 + 36^2 = 729 + 1296 = 2025 = 45^2$ it is a triple
Step 2 $27$, $36$ and $45$ are all multiples of $9$ a common factor
Answer Yes, it is a triple, but not primitive: it is $9$ times $(3, 4, 5)$
Example 16

Find the multiple of the triple $(12, 35, 37)$ whose largest number is $111$.

Solution.

Step 1 $k = 111 \div 37 = 3$ compare largest numbers
Step 2 $(3 \times 12, 3 \times 35, 3 \times 37)$ multiply each number
Step 3 $36^2 + 105^2 = 1296 + 11025 = 12321 = 111^2$ check
Answer $(36, 105, 111)$
