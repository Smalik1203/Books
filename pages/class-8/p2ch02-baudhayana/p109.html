Type 9 · The triple machine

Example 17

Use the machine $m^2 - n^2$, $2mn$, $m^2 + n^2$ with $m = 8$ and $n = 3$, and check the triple it makes.

Solution.

Step 1 $m^2 - n^2 = 64 - 9 = 55$
Step 2 $2mn = 2 \times 8 \times 3 = 48$
Step 3 $m^2 + n^2 = 64 + 9 = 73$
Step 4 $55^2 + 48^2 = 3025 + 2304 = 5329 = 73^2$ check
Answer $(55, 48, 73)$
Example 18

Which whole numbers $m$ and $n$ make the machine give the triple $(13, 84, 85)$?

Solution.

Step 1 $2mn = 84$, so $mn = 42$ the even number
Step 2 $42 = 42 \times 1 = 21 \times 2 = 14 \times 3 = 7 \times 6$ list the pairs
Step 3 $7^2 + 6^2 = 49 + 36 = 85$ only this pair gives $85$
Step 4 $7^2 - 6^2 = 49 - 36 = 13$ check
Answer $m = 7$, $n = 6$
