The pattern appears to be $a^2 - b^2 = (a + b) \times (a - b)$. Is this a true identity? Using the distributive property,

$(a + b) \times (a - b) = a^2 - ab + ba - b^2$

The like terms $-ab$ and $ba$ add to $0$, so the pattern does always hold.

$$\text{Identity 1C}\qquad (a + b) \times (a - b) = a^2 - b^2$$

Sridharacharya (750 CE) gave a neat way of squaring numbers quickly with Identity 1C. He used it in a rearranged form:

$a^2 = (a + b)(a - b) + b^2$

Why is this identity true? It lets us choose $b$ so that one of $a + b$ and $a - b$ is a round number. For example, $31^2$ can be found by taking $a = 31$ and $b = 1$, and $197^2$ by taking $a = 197$ and $b = 3$.

$31^2$ $= (31 + 1)(31 - 1) + 1^2$
$= 32 \times 30 + 1 = 961$
$197^2$ $= (197 + 3)(197 - 3) + 3^2$
$= 200 \times 194 + 9 = 38809$
