Example 6 · Single correct

$(y - 7)(y + 3)$ is equal to

Choose one correct option.

  1. $y^2 + 4y - 21$
  2. $y^2 - 4y + 21$
  3. $y^2 - 4y - 21$
  4. $y^2 - 10y - 21$

Solution.

Step 1The four products are $y^2$, $3y$, $-7y$ and $-21$.
Step 2$3y - 7y = -4y$, so the result is $y^2 - 4y - 21$.
Answer(c) $y^2 - 4y - 21$
Example 7 · Multiple correct

Which of these are identities, true for every value of $x$?

Select all correct options.

  1. $(x - 2)^2 = x^2 - 4x + 4$
  2. $(x - 2)(x + 2) = x^2 - 4$
  3. $(x + 3)^2 = x^2 + 9$
  4. $x + 3 = 7$

Solution.

Step 1(a) is Identity 1B and (b) is Identity 1C, each with $a = x$ and $b = 2$.
Step 2$(x + 3)^2 = x^2 + 6x + 9$, so (c) fails for $x = 1$; $x + 3 = 7$ is true only for $x = 4$.
Answer(a), (b)
Example 8 · Multiple correct

Which of these are equal to $9a^2 - 30ab + 25b^2$?

Select all correct options.

  1. $(3a - 5b)^2$
  2. $(5b - 3a)^2$
  3. $(3a + 5b)^2 - 60ab$
  4. $(3a - 5b)(3a + 5b)$

Solution.

Step 1$(3a - 5b)^2 = 9a^2 - 30ab + 25b^2$, and $(5b - 3a)^2$ is the same square. $(3a + 5b)^2 - 60ab = 9a^2 + 30ab + 25b^2 - 60ab$.
Step 2$(3a - 5b)(3a + 5b) = 9a^2 - 25b^2$.
Answer(a), (b), (c)
