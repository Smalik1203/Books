Example 3

Which of these are equal to $9a^2 - 30ab + 25b^2$?

  1. $(3a - 5b)^2$
  2. $(5b - 3a)^2$
  3. $(3a + 5b)^2 - 60ab$
  4. $(3a - 5b)(3a + 5b)$

Solution.

Step 1$(3a - 5b)^2 = (5b - 3a)^2 = 9a^2 - 30ab + 25b^2$.
Step 2$(3a + 5b)^2 - 60ab = 9a^2 + 30ab + 25b^2 - 60ab$, the same.
Step 3$(3a - 5b)(3a + 5b) = 9a^2 - 25b^2$, which differs.
Answer(a), (b), (c)
Example 4

Two positive numbers $a$ and $b$ have $a - b = 3$ and $ab = 28$. Which of these statements are correct?

  1. $a^2 + b^2 = 65$
  2. $(a + b)^2 = 121$
  3. $a + b = 11$
  4. $a = 4$

Solution.

Step 1$a^2 + b^2 = 9 + 56 = 65$, and $(a + b)^2 = 65 + 56 = 121$.
Step 2$a + b = 11$, as it is positive; so $a = 7$, $b = 4$.
Answer(a), (b), (c)
