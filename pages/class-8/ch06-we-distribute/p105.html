Example 3 · Single correct

Using an identity, $59^2$ is

Choose one correct option.

  1. 3421
  2. 3541
  3. 3419
  4. 3481

Solution.

Step 1$59^2 = (60 - 1)^2 = 60^2 - 2 \times 60 + 1$.
Step 2$= 3600 - 120 + 1 = 3481$.
Answer(d) 3481
Example 4 · Single correct

If $x + y = 8$ and $x^2 + y^2 = 34$, what is $xy$?

Choose one correct option.

  1. 15
  2. 30
  3. 17
  4. 13

Solution.

Step 1$(x + y)^2 = x^2 + y^2 + 2xy$, so $64 = 34 + 2xy$.
Step 2$2xy = 30$ and $xy = 15$.
Answer(a) 15
Example 5 · Single correct

What is $6384 \times 11$?

Choose one correct option.

  1. 70214
  2. 70224
  3. 71224
  4. 70124

Solution.

Step 1$6384 \times 11 = 63840 + 6384$: each digit is added to the digit on its right. From the right: 4; $8 + 4 = 12$, write 2 and carry 1; $3 + 8 + 1 = 12$, write 2 and carry 1; $6 + 3 + 1 = 10$, write 0 and carry 1; $6 + 1 = 7$.
Step 2Reading the digits from the left: 70224.
Answer(b) 70224
