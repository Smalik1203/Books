We can do the same in general and find the product $(a + u)(b - v)$:

$(a + u)(b - v)$ $= (a + u)b - (a + u)v$
$= ab + ub - (av + uv)$
$= ab + ub - av - uv$

This is Identity 1 with $m = u$ and $n = -v$, using the usual rules for signs. In the same way,

$(a - u)(b + v) = ab - ub + av - uv$

$(a - u)(b - v) = ab - ub - av + uv$

The number outside a bracket multiplies every term inside, however many there are.

Example 1

Expand $\dfrac{2x}{3}\left(x + 3y - \dfrac{1}{4}\right)$.

Solution.

Step 1 $\frac{2x}{3}\left(x + 3y - \frac{1}{4}\right) = \left(\frac{2x}{3} \times x\right) + \left(\frac{2x}{3} \times 3y\right) - \left(\frac{2x}{3} \times \frac{1}{4}\right)$
Step 2 $\frac{2x}{3} \times x = \frac{2}{3} \times (x \times x) = \frac{2}{3}x^2$ exponent notation
Step 3 $\frac{2x}{3} \times 3y = \left(\frac{2}{3} \times 3\right) \times (x \times y) = 2xy$
Step 4 $\frac{2x}{3} \times \frac{1}{4} = \left(\frac{2}{3} \times \frac{1}{4}\right)x = \frac{1}{6}x$
Answer $\frac{2}{3}x^2 + 2xy - \frac{1}{6}x$

Can any two of these terms be added to make a single term? Can $\frac{2}{3}x^2$ and $\frac{1}{6}x$ be added, for instance? Terms with exactly the same variables, each raised to the same power, are called like terms, and only like terms can be added into one. No two of the terms here are like terms, so the expression cannot be simplified further.

Example 2

Expand $(x + y)(x + y)$.

Solution.

Step 1 $(x + y)(x + y) = (x + y)x + (x + y)y$ $(x + y)$ as one term
Step 2 $= x \times x + y \times x + x \times y + y \times y = x^2 + yx + xy + y^2$
Step 3 $yx + xy = xy + xy = 2xy$ like terms, since $yx = xy$
Answer $(x + y)(x + y) = x^2 + 2xy + y^2$
