When a three-digit number is multiplied by $11$, the product is $5357$. Find the number without dividing.

Section 6.1.2 showed that a three-digit number $cba$ times $11$ is written $c$, $(b + c)$, $(a + b)$, $a$, with carrying from the right. So read the product from the right and undo one digit at a time.

units $a = 7$
tens $a + b$ ends in $5$, so $a + b = 15$: $b = 8$, carry $1$
hundreds $b + c + 1$ ends in $3$, so $b + c + 1 = 13$: $c = 4$, carry $1$
thousands $c + 1 = 5$, which agrees

The number is $487$, and $4870 + 487 = 5357$. The tens digit could not have been $a + b = 5$, because that would make $b$ negative.

Show that $x^2 - 6x + 10$ is greater than zero for every value of $x$, including the negative ones and the fractions.

Trying values will not settle this, because there are too many to try. What settles it is finding a square, because the square of a number is never negative. The first two terms, $x^2 - 6x$, are the start of $(x - 3)^2 = x^2 - 6x + 9$, so write the $10$ as $9 + 1$.

rewrite $x^2 - 6x + 10 = (x^2 - 6x + 9) + 1$
as a square $= (x - 3)^2 + 1$

Whatever $x$ is, $(x - 3)^2$ is zero or more, so the whole expression is $1$ or more, and it is never zero. The original form does not show this at all; the square does.

Multiply four consecutive whole numbers and add $1$. Try it with $3, 4, 5, 6$ and then with $7, 8, 9, 10$. Then show that the answer is always a perfect square.

The arithmetic first: $3 \times 4 \times 5 \times 6 = 360$, and $361 = 19^2$. Then $7 \times 8 \times 9 \times 10 = 5040$, and $5041 = 71^2$. Two cases are not a proof. Call the numbers $n$, $n + 1$, $n + 2$ and $n + 3$, and multiply the outer two and the inner two.

outer pair $n(n + 3) = n^2 + 3n$
inner pair $(n + 1)(n + 2) = n^2 + 3n + 2$

The two products differ by exactly $2$. Write $m$ for $n^2 + 3n$. The product of all four is $m(m + 2)$, and adding $1$ gives $m^2 + 2m + 1$, which is $(m + 1)^2$, that is, $(n^2 + 3n + 1)^2$. Check it at $n = 3$: $9 + 9 + 1 = 19$, and $19^2 = 361$. Paired the other way, the two products differ by $3$, and nothing tidy happens.
