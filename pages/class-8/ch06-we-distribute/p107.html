Example 9 · Multiple correct

Which statements are correct?

Select all correct options.

  1. $64^2 - 36^2 = (64 - 36)(64 + 36)$
  2. $64^2 - 36^2 = 2800$
  3. $6.4^2 - 3.6^2 = 2.8$
  4. $64^2 - 36^2 = 100 \times 28$

Solution.

Step 1$a^2 - b^2 = (a - b)(a + b)$ gives $28 \times 100 = 2800$.
Step 2$6.4^2 - 3.6^2 = 2.8 \times 10 = 28$, not 2.8.
Answer(a), (b), (d)
Example 10 · Multiple correct

Two positive numbers $a$ and $b$ have $a - b = 3$ and $ab = 28$. Which statements are correct?

Select all correct options.

  1. $a^2 + b^2 = 65$
  2. $(a + b)^2 = 121$
  3. $a + b = 11$
  4. $a = 4$

Solution.

Step 1$a^2 + b^2 = (a - b)^2 + 2ab = 9 + 56 = 65$, and $(a + b)^2 = 65 + 56 = 121$.
Step 2$a + b$ is positive, so it is 11; then $a = 7$ and $b = 4$.
Answer(a), (b), (c)
