Example 7

Match List I with List II. Each entry in List I has exactly one match in List II.

List IList II
(P) $(2m - 1)^2$(1) $4m^2 + 4m - 3$
(Q) $(2m + 1)(2m - 1)$(2) $4m^2 - 1$
(R) $(2m + 1)^2$(3) $4m^2 - 4m + 1$
(S) $(2m + 3)(2m - 1)$(4) $4m^2 + 4m + 1$
  1. P–2, Q–3, R–4, S–1
  2. P–3, Q–2, R–4, S–1
  3. P–3, Q–4, R–2, S–1
  4. P–1, Q–2, R–4, S–3

Solution.

Step 1By Identity 1B, $(2m - 1)^2 = 4m^2 - 4m + 1$, so P–3.
Step 2By Identity 1C, $(2m + 1)(2m - 1) = 4m^2 - 1$, so Q–2.
Step 3By Identity 1A, $(2m + 1)^2 = 4m^2 + 4m + 1$, so R–4.
Step 4$(2m + 3)(2m - 1) = 4m^2 - 2m + 6m - 3 = 4m^2 + 4m - 3$, so S–1.
CheckAt $m = 1$: (P) is $1$ and (3) is $4 - 4 + 1 = 1$; (S) is $5 \times 1 = 5$ and (1) is $4 + 4 - 3 = 5$ too.
Answer(b) P–3, Q–2, R–4, S–1
