Why the other options are wrong

Set A, 1. Option (a) — half the values below — describes the median, not the mean, and the two are different points in almost every collection. Option (b) is what a mean is often assumed to promise and never does: a single distant value can hold up a whole crowd of near ones, and then most of the data sits nowhere near the mean.

Set A, 5. Option (c), $+6n$, is the change to the sum. There are $n$ values and each gained $6$, so the total gained $6n$ — and $6n$ shared among $n$ values is $6$ each, which is the change to the mean.

Set B, 3. Option (c), $70$, is the new sum and not the new mean. Doubling every value doubles the sum and leaves the count alone, so the mean doubles too: from $7$ to $14$.

Set B, 7. Option (a), $15$, assumes that an extra value leaves the mean where it was. Only a value equal to the mean does that, and $25$ is not $15$ — it is $10$ above, and that $10$ shared among the ten values now present lifts the mean by exactly $1$.

Set C, 4. Options (a) and (b) both assume the newcomers must shift something. They need not: $12$ and $28$ have a mean of $20$ themselves, so one falls as far short of the balance point as the other overshoots, and the fulcrum does not move.

Set B, 6. Options (b) and (c) both come from taking the wrong pair of middle values. Sixteen values put the middle at the eighth and ninth, and both of those are $41$ — the repeated value is what makes the answer a whole number rather than a half.

Set B, 12. Option (c), dishonest in every case, goes too far and option (b) not far enough. Each bar still stands against a correctly labelled axis, so every value can be read off correctly. What is lost is the comparison between them, which is the one thing a reader takes from a bar graph without looking.

Set C, 6. Option (c) has the two the wrong way round. The median asks each value only which side of the middle it is on, so a value far out counts the same as a value just out. The mean asks how far, so a value far out counts heavily.

Set C, 9. Option (a), true, is the tempting one and it is a guess. Three consecutive readings did rise, and nothing at all was measured in the hours between them — the temperature could have dipped and recovered twice over and the graph would look the same.

Read down that list and a shape appears. Hardly any of the wrong options come from arithmetic. They come from answering a neighbouring question: the median's description given for the mean, the change to the sum given as the change to the mean, a guess about the hours between two readings given as a reading.
