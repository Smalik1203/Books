Add a fixed number $c$ to every one of them and work out the new mean.

the new sum $(x_1 + c) + (x_2 + c) + \cdots + (x_n + c) = x_1 + \cdots + x_n + nc$
divide by n $\dfrac{x_1 + \cdots + x_n}{n} + \dfrac{nc}{n}$
which is $a + c$

There were $n$ values and each gained $c$, so the total gained $nc$ — and $nc$ shared among $n$ values is $c$ each. Multiplying instead of adding goes the same way. If every value is multiplied by $k$, the new sum is $k$ times the old sum by the distributive property, and dividing by $n$ gives $ka$.

$$\text{add } c \text{ to every value} \to \text{mean } a + c; \qquad \text{multiply every value by } k \to \text{mean } ka.$$
Example 3

Shreyas measures the heights of all $24$ students in his class and reports an average of $150.2$ cm. His teacher then notices that everyone was wearing the school shoes, which add $1$ cm. Must all $24$ be measured again?

Solution.

Step 1 every height was recorded $1$ cm too large the same error for all
Step 2 so the mean is $1$ cm too large as well a shift moves the mean
Step 3 $150.2 - 1 = 149.2$ cm
Answer No. The true average is $149.2$ cm

Nobody need be measured again, and the twenty-four individual heights need not even be known. A fixed error in every reading becomes the same fixed error in the mean, and can be taken off at the end.

The warning inside that is worth stating. It works because the error was the same for everybody. Had some students been in shoes and some barefoot, nothing could be recovered from the average alone, and the measuring would have to be done again.

5.5The Middle Value

The median answers a different question about the same pile of numbers. Sort them, and the median is the one in the middle — the value with as many below it as above. An even count has no single middle, so the median is taken as the average of the two that share the position.

Take $3$, $6$, $8$, $9$, $14$. There are five values, the third is $8$, and two lie on either side of it, so the median is $8$. Now include $11$. Sorted, the collection reads $3$, $6$, $8$, $9$, $11$, $14$, the two middle values are $8$ and $9$, and the median is $8.5$.
