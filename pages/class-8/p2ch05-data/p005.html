Every dot moved $10$ places to the right. The distances between the dots did not change, so the point that balanced them still balances them. It has also moved $10$ places, from $6$ to $16$.

Algebra shows that this always happens. Let the values be $x_1, x_2, \ldots, x_n$ and their mean be $a$. Then

$$\frac{x_1 + x_2 + \cdots + x_n}{n} = a.$$

Add the same number $c$ to every value, and find the new mean.

the new sum $(x_1 + c) + (x_2 + c) + \cdots + (x_n + c) = x_1 + \cdots + x_n + nc$
divide by n $\dfrac{x_1 + \cdots + x_n}{n} + \dfrac{nc}{n}$
which is $a + c$

There were $n$ values and each one gained $c$, so the total gained $nc$. Shared among $n$ values, that is $c$ each. Multiplying works in the same way. If every value is multiplied by $k$, the new sum is $k$ times the old sum, by the distributive property. Dividing by $n$ gives a new mean of $ka$, which is $k$ times the old mean.

$$\text{add } c \text{ to every value} \to \text{mean } a + c; \qquad \text{multiply every value by } k \to \text{mean } ka.$$
Example 3

Farida times $12$ runners in a race and finds a mean time of $58.5$ seconds. Later she finds that her stopwatch started $1.5$ seconds late for every runner, so every time she wrote down is $1.5$ seconds too short. Must all $12$ runners run again?

Solution.

Step 1 Every time is $1.5$ s too short the same error for all
Step 2 So the mean is also $1.5$ s too short
Step 3 $58.5 + 1.5 = 60$ seconds
Answer No. The true mean time is $60$ seconds

Nobody needs to run again, and we do not even need the twelve times. The same error in every value becomes the same error in the mean, and it can be put right at the end.

This works only because the error was the same for every runner. If the stopwatch had been late for some runners and not for others, the mean alone could not be corrected. The race would have to be timed again.
