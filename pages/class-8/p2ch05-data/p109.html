Example 15 · Matching

A set of data has mean 20. Match each change in List I with the new mean in List II. Each entry has exactly one match.

List IList II
(P) 5 is added to every value(1) 12
(Q) Every value is multiplied by 3(2) 44
(R) Every value is doubled and then 4 is added(3) 25
(S) 8 is taken from every value(4) 60

Choose the correct combination.

  1. P–3, Q–4, R–2, S–1
  2. P–4, Q–3, R–2, S–1
  3. P–3, Q–2, R–4, S–1
  4. P–1, Q–4, R–2, S–3

Solution.

Step 1The mean changes as each value does: $20 + 5 = 25$, $20 \times 3 = 60$, $20 \times 2 + 4 = 44$, $20 - 8 = 12$.
Answer(a) P–3, Q–4, R–2, S–1
