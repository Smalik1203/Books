5.2Counting What You Have

Start by asking what different answers there are. In the list above they run from $3$ to $8$, which is six possibilities for thirty students, so the list must repeat itself a great deal. How often each answer appears is called its frequency, and a table of those counts is a frequency table.

The counting is done in one pass. Read the list from the beginning, and for each number put a stroke against its row. Every fifth stroke is laid across the four before it, so the marks arrive in bundles of five and the row can be counted in fives at the end instead of one at a time. Going through the list once is the whole method; going through it six times, once looking for threes and once for fours, is six chances to lose your place.

A frequency table keeps counts and loses order

The table says that nine students live in a house of five. It does not say which nine, and it does not say who answered first. That loss is not a fault — it is the reason the table can be read. Every step in this chapter throws away something in order to show something, and it is worth knowing at each step which is which.

One row is worth putting in even when there is nothing to put in it. Nobody in this class lives alone, and a table that simply leaves that row out gives a reader no way to tell whether the answer was never given or never asked for. A row with $0$ against it says which — and it also keeps the rows evenly spaced, which matters as soon as the table is drawn.
