Check first, then explain. $1, 9, 25, 49, 81$ divided by $8$ leave $1, 1, 1, 1, 1$. It is not a coincidence and the reason is one line of algebra.

Every odd number can be written $2k + 1$. Square it:

$(2k+1)^2$ $= 4k^2 + 4k + 1 = 4k(k+1) + 1$

Now $k$ and $k+1$ are consecutive, so one of them is even, so $k(k+1)$ is even. Write it as $2m$. Then the square is $8m + 1$ — a multiple of $8$, plus one.

The useful part is the test it gives you. A number that leaves any remainder but $1$ on division by $8$ cannot be an odd square: $2019$ leaves $3$, so it is out, and no factorisation was needed to say so.

How many digits can the square of a two-digit number have? Give an example of each length that is possible.

The two-digit numbers run from $10$ to $99$, and squaring keeps the order — a bigger number has a bigger square — so the shortest and longest answers come from the two ends.

smallest $10^2 = 100$ 3 digits
largest $99^2 = 9801$ 4 digits

So every answer has $3$ or $4$ digits, and both lengths occur: $10^2 = 100$ has three, $99^2 = 9801$ has four. The change comes at $32^2$, since $31^2 = 961$ still has three.

There is a pattern hiding here that is worth noticing. Squaring a number roughly doubles its count of digits, so the digits of a square, marked off in pairs from the right, tell you how many digits its root has: $98\,|\,01$ is two pairs, and $99$ has two digits.

$1729$ is the smallest number that is a sum of two cubes in two different ways. What is the smallest number that is a sum of two squares in two different ways? You can search by hand if you organise it.

The answer is $50$, and the way to find it is to organise the search so that it finishes rather than wanders.

$50$ $= 1^2 + 7^2 = 1 + 49$
$= 5^2 + 5^2 = 25 + 25$
