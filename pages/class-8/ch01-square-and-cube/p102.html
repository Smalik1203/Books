Find $51 + 53 + 55 + \cdots + 99$ without adding more than two numbers together.

The sum runs over odd numbers, so reach for $1 + 3 + \cdots + (2n-1) = n^2$. It does not start at $1$, but that is easily arranged: add the missing front and take it away again.

$1 + 3 + \cdots + 99$ $= 50^2 = 2500$ since $99 = 2 \times 50 - 1$
$1 + 3 + \cdots + 49$ $= 25^2 = 625$ since $49 = 2 \times 25 - 1$
the difference $= 2500 - 625$ $1875$

Twenty-five numbers added by subtracting two you already knew. The general move is worth keeping: a run that starts in the wrong place becomes two runs that both start in the right one.

Notice that the second solution never added a single one of the twenty-five numbers it was asked about. It found a formula that covered a longer run, another that covered the unwanted front of it, and subtracted. That move — solve a bigger problem you can handle, then remove the part you did not want — turns up everywhere in mathematics, and it is worth recognising as a move rather than meeting it fresh each time.

Show that $n^2 + n$ is never a perfect square, for any natural number $n$.

No calculation will settle this, because there are infinitely many cases. What settles it is showing that $n^2 + n$ always falls in a place where no square can be.

Take any natural number $n$ and put $n^2 + n$ between the two squares nearest it. Since $n \ge 1$, it is certainly bigger than $n^2$. And it is smaller than the next square up:

$(n+1)^2$ $= n^2 + 2n + 1$
so $n^2 \;\lt\; n^2 + n \;\lt\; n^2 + 2n + 1$

So $n^2 + n$ sits strictly between two consecutive squares — and § 1.2.2 established that there is nothing but ordinary numbers in that gap. A square would have to be one of the two ends, and it is neither.

Try it once: $n = 12$ gives $156$, which lies between $144$ and $169$. The argument says that will happen every time, without a further case checked.
