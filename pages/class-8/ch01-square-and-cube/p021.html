Example 12

Given that $10\,648$ is a perfect cube, find $\sqrt[3]{10\,648}$ without factorising.

Solution.

Step 1 $10\,648$ ends in $8$, so the root ends in $2$ the units digit
Step 2 strike out the last three digits to leave $10$; $2^3 = 8$ fits in it and $3^3 = 27$ does not the tens digit is $2$
Step 3 $22^3 = 10\,648$ check
Answer $\sqrt[3]{10\,648} = 22$

Striking out three digits divides by $1000 = 10^3$, so it finds the tens part of the root. Try it on two more. $29\,791$ ends in $1$, so the root ends in $1$. Strike three digits to leave $29$, and $3^3 = 27$ fits where $4^3 = 64$ does not, so the root is $31$. And $110\,592$ ends in $2$, so the root ends in $8$. Here $110$ leaves $4^3 = 64$ as the largest cube that fits, so the root is $48$. Given $8200$, which is not a cube, the method would wrongly answer $20$: it finds a root, but it does not test for one.
