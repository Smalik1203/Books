1.5.1 Reading a cube root off the digits

For a cube of up to six digits there is a method that needs no factorising at all, and it uses the two facts we have. It works because a two-digit root has a cube of at most six digits, so the answer's two digits can be found one at a time — the units digit from the end of the number, the tens digit from the front.

Example 12

Given that $4913$ is a perfect cube, find $\sqrt[3]{4913}$ without factorising.

The units digit, from the last digit. $4913$ ends in $3$, and a cube ends in $3$ only when its root ends in $7$. So the root ends in $7$.

The tens digit, from what is left. Strike out the last three digits and $4$ remains. Find the largest cube not exceeding it: $1^3 = 1$ fits and $2^3 = 8$ does not, so the tens digit is $1$.

$\sqrt[3]{4913}$ $17$

Check: $17^3 = 4913$.

Striking out three digits is not a trick. It divides by $1000$, and $1000 = 10^3$, so it is really asking which cube the tens part of the root must be — exactly the same question one size down.

Run it on the rest and it is quick: $12\,167$ ends in $7$, so the root ends in $3$; strike three digits to leave $12$, and $2^3 = 8$ fits where $3^3 = 27$ does not, so the root is $23$. And $32\,768$ ends in $8$, so the root ends in $2$; $32$ leaves $3^3 = 27$ as the largest cube that fits, so the root is $32$.

The method assumes it has been given a perfect cube. Fed $4900$ it would answer $10$ and be wrong, since $4900$ is not a cube at all. It finds a root; it does not test for one.
