## 1.1 Introduction

### Think and Reflect (the board of light switches)

Answered in the running text that follows it. A switch is pressed once for
each factor of its number, and only a square has an odd number of factors.
The lights left on are the twelve squares up to 150: $1, 4, 9, \ldots, 144$.

### Exercise Set 1.1

1. $20$: $1 \times 20$, $2 \times 10$, $4 \times 5$ — six factors, off.
   $36$: $1 \times 36$, $2 \times 18$, $3 \times 12$, $4 \times 9$, $6 \times 6$ — nine factors, on.
   $42$: $1 \times 42$, $2 \times 21$, $3 \times 14$, $6 \times 7$ — eight factors, off.
   $81$: $1 \times 81$, $3 \times 27$, $9 \times 9$ — five factors, on.
2. **Student 15**, since $90 \div 6 = 15$: the partner of a factor is the
   number divided by it.
3. **17.** The lights on are the squares up to 300: $17^2 = 289$ and
   $18^2 = 324$.
4. **64 and 81**, the only squares between 60 and 90.

## 1.2 Square Numbers

### Exercise Set 1.2

1. $5287$ ends in 7 and $7438$ ends in 8, so neither is a square. $3490$ ends
   in one zero, an odd run, so it is not a square. $2116$ cannot be ruled out
   (in fact $2116 = 46^2$).
2. *Answers will vary.* For example $5002$, $5013$, $5117$, $5998$.
3. **3 or 7**, since $3^2 = 9$ and $7^2 = 49$.
4. **Eight.** $50\,000$ ends in four zeros, and squaring doubles them:
   $(50\,000)^2 = 2\,500\,000\,000$.
5. $1296$ is even, so its root is even (it is $36$). An odd number has an odd
   square, so an even square cannot come from an odd number.
6. $52^2$ and $118^2$, whose roots end in 2 and 8. ($52^2 = 2704$,
   $118^2 = 13\,924$; $77^2 = 5929$ and $43^2 = 1849$ end in 9.)

### Think and Reflect (after Fig. 1.4)

1. $55 + 66 = 121$, the 10th and 11th triangular numbers.
2. $(n + 2)^2 - n^2 = 4n + 4$ tiles.

### Exercise Set 1.3

1. Add the 86th odd number, $2 \times 86 - 1 = 171$: $86^2 = 7225 + 171 = 7396$.
2. $64$: zero after 8 subtractions, so $64 = 8^2$. $72$: $71, 68, 63, 56, 47,
   36, 23, 8$, then $-9$, so not a square. $121$: zero after 11
   subtractions, so $121 = 11^2$.
3. $24$, $70$, $150$ (that is, $2 \times 12$, $2 \times 35$, $2 \times 75$).
4. $1, 3, 6, 10, 15, 21, 28, 36, 45, 55, 66, 78$. Squares greater than 50,
   for example: $28 + 36 = 64$, $36 + 45 = 81$, $45 + 55 = 100$,
   $55 + 66 = 121$.
5. $9^2 + 40^2 = 41^2$. The two larger numbers are consecutive and add up to
   the square of the first: $40 + 41 = 81$.

## 1.3 Square Roots

### Think and Reflect (after Example 7)

Divide by **5**: $3920 \div 5 = 784 = 28^2$. It is the same number as the
multiplier, as it must be when there is a single stray prime: multiplying
gives it a partner, dividing removes it.

### Exercise Set 1.4

1. $18$, $36$, $45$, $66$ ($324 = 2^2 \times 3^4$, $1296 = 2^4 \times 3^4$,
   $2025 = 3^4 \times 5^2$, $4356 = 2^2 \times 3^2 \times 11^2$).
2. $2450 = 2 \times 5^2 \times 7^2$; the 2 is alone. Multiply by **2**:
   $4900 = 70^2$.
3. $2178 = 2 \times 3^2 \times 11^2$. Divide by **2**: $1089 = 33^2$, root 33.
4. **900.** LCM $= 180 = 2^2 \times 3^2 \times 5$; multiply by 5.
5. $\sqrt{60} \approx 8$ (between $49$ and $64$); $\sqrt{180} \approx 13$
   (between $169$ and $196$); $\sqrt{700} \approx 26$ (between $676$ and $729$).
6. **73.** The root is between 70 and 80 and ends in 3 or 7;
   $75^2 = 5625$ is more than $5329$, so it is 73.
7. The side is $\sqrt{1225} = 35$ m, so **140 m** of fencing.

## 1.4 Cubic Numbers

### Think and Reflect (after the taxicab story)

1. $6^3 - 5^3 = 216 - 125 = 91$.
2. $1 + 8 = 9$, $1 + 27 = 28$, $8 + 27 = 35$, $1 + 64 = 65$, $8 + 64 = 72$,
   $27 + 64 = 91$. None of them is a sum of two cubes in two ways.

## 1.5 Cube Roots

### Exercise Set 1.5

1. $7$, $12$, $40$, $13$.
2. $1080 = 2^3 \times 3^3 \times 5$. Multiply by $5^2 = 25$:
   $27\,000 = 30^3$, cube root 30.
3. $6750 = 2 \times 3^3 \times 5^3$. Divide by **2**: $3375 = 15^3$.
4. (i) False: an even number has an even cube. (ii) True: $3^3 = 27$.
   (iii) False: $999^3 = 997\,002\,999$ has nine digits. (iv) False: $64 = 4^3$
   has the seven factors 1, 2, 4, 8, 16, 32, 64.
5. $331$ and $271$. Yes: of two consecutive numbers one is odd and one is
   even, so one cube is odd and the other even, and their difference is odd.

### Think and Reflect (after §1.5.2)

1. Differences $6, 10, 14, 18, 22$, then $4, 4, 4, 4$: flat after two rounds,
   so the list behaves like a square (it is $2n^2$).
2. Twice the cubes: $2, 16, 54, 128, 250$ give $14, 38, 74, 122$, then
   $24, 36, 48$, then $12, 12$.

## 1.6 Where the Words Came From

### Think and Reflect

1. The sixth power; $2^6 = 64$.
2. $13^2 = 169$; $13^3 = 2197$.

### Exercise Set 1.6

1. $121 = 11^2$, a square. $343 = 7^3$, a cube. $729 = 27^2 = 9^3$, both.
   $1500$ neither: it ends in two zeros, so it is not a cube, and
   $1500 = 2^2 \times 3 \times 5^3$ has a lone 3, so it is not a square.
2. Edge $\sqrt[3]{2197} = 13$; face $13^2 = 169$ square units.
3. $24$, $34$, $47$.
4. Three squares ($225$, $256$, $289$). Twelve cubes, $10^3$ to $21^3$.
5. Twelve 2s make six pairs, so it is a square, $2^6 = 64$ squared; they make
   four groups of three, so it is a cube, $2^4 = 16$ cubed.
6. $3456 = 2^7 \times 3^3$. Divide by **2**: $1728 = 12^3$, cube root 12.
7. The area is $1200$ m², and $1200 = 2^4 \times 3 \times 5^2$ has a lone 3,
   so the side is not a whole number. $34^2 = 1156$ and $35^2 = 1225$, so
   the nearest whole number is **35 m**.
8. (i) impossible: a square ends in an even number of zeros. (ii) possible:
   $2^3 = 8$. (iii) impossible: a cube ends in a multiple of three zeros.
   (iv) impossible: an odd number has an odd square.
9. $7, 19, 37, 61, 91$; then $12, 18, 24, 30$; then $6, 6, 6$. Three rounds,
   so the numbers behave like cubes: they are $n^3 - 1$.
10. Edge $7$ m, base $49$ m², five faces $5 \times 49 = 245$ m².
