The sum of the odd numbers

The first $n$ odd numbers add up to $n^2$: $1 + 3 + 5 + \cdots + (2n-1) = n^2$. The $n$th odd number is $2n - 1$.

Keep both the picture and the formula. The picture is what convinces; the formula is what calculates. Asked for $1 + 3 + 5 + \cdots + 99$, you do not want to draw anything — you want to notice that $99 = 2 \times 50 - 1$, so this is the first fifty odd numbers, so the answer is $50^2 = 2500$. Fifty numbers added in one line, because you saw the shape of the sum instead of doing the sum.

That single fact does two jobs. The first is a test. If every square is $1 + 3 + 5 + \cdots$, then subtracting the odd numbers in order from a square must land exactly on zero — and from anything else it must overshoot.

Example 2

Is $25$ a perfect square? Is $38$?

Subtract $1$, then $3$, then $5$, and keep going.

Solution.

Step 1 from 25: $24,\ 21,\ 16,\ 9,\ 0$ zero after $5$ steps
Step 2 $25 = 1+3+5+7+9$, so $25 = 5^2$
Step 3 from 38: $37,\ 34,\ 29,\ 22,\ 13,\ 2,\ -11$ overshot, from $2$ to $-11$
Step 4 $6^2 = 36$ and $7^2 = 49$, and $38$ is stuck between them no square between
Answer $25$ is a perfect square; $38$ is not

The count of steps is the root, which is a useful extra: the method does not only say yes, it says five.

The second job is arithmetic. If you already know one square, the next one is a single addition away.

Example 3

Given that $35^2 = 1225$, find $36^2$ without multiplying.

Solution.

Step 1 $1225$ is the sum of the first $35$ odd numbers
Step 2 36th odd number $= 2 \times 36 - 1 = 71$
Step 3 $36^2 = 1225 + 71$ sum of the first $36$
Answer $36^2 = 1296$

The same step run the other way is just as useful: the $35$th odd number is $69$, so $34^2 = 1225 - 69$.
