So far, we can only solve an equation with one unknown. So write the number of marbles Suresh has as $y$, and the number Ramesh has as $y + 30$. The total is 60, so

$y + (y + 30) = 60$

$2y + 30 = 60$

Use this equation to find how many marbles each boy has.

Making equations from a solution

So far, we have solved equations to find the value of a letter-number. Can we go the other way, and write equations when we know the value of the letter-number?

Write some equations whose solution is $y = 5$. Share your equations with your classmates, and talk about the methods you used to make them.

Two such equations are $y + 1 = 6$ and $3y = 15$. Table 7.15 shows two chains of equations. In each chain, every equation comes from the one before it by doing the operation written above it on both sides.

chain 1

Can you make a chain that goes from the last equation back to the first one? Compare the operations used going forwards with the operations used going back.

Without working anything out, can you say what the unknown is in each equation of the two chains? (Hint: a value that makes an equation true also makes true the new equation we get by doing the same operation on both sides.)

Example 9

Think of a real-life situation that the equation $100x + 75 = 250$ could describe.

Think of the numbers as amounts of money, with ₹250 in all. The LHS has two terms. The term 75 is fixed, while the value of $100x$ changes with $x$. So 75 could be a fixed charge, and $100x$ could be a charge of ₹100 for each unit of something. For example, a plumber may charge ₹75 to visit a house and ₹100 for each hour of work. If the bill comes to ₹250, then $x$ is the number of hours the plumber worked.
