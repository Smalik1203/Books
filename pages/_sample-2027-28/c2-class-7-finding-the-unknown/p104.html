Enter the numerical value.

Solution.

Step 1$5x - 2x = 25 - 7$, so $3x = 18$.

Example 7 · Matching

Match List I with List II.

List IList II
(P) 3 more than twice a number is 15.(1) $2n - 3 = 15$
(Q) Twice the sum of a number and 3 is 15.(2) $2n + 3 = 15$
(R) 3 less than twice a number is 15.(3) $\frac{n}{2} + 3 = 15$
(S) Half of a number, increased by 3, is 15.(4) $2(n + 3) = 15$

Each entry has exactly one match.

Choose the correct combination.

  1. P–2, Q–1, R–4, S–3
  2. P–4, Q–2, R–1, S–3
  3. P–2, Q–4, R–1, S–3
  4. P–3, Q–4, R–1, S–2

Solution.

Step 13 more than twice a number is $2n + 3$, so P–2; 3 less is $2n - 3$, so R–1.
Step 2Twice the sum of the number and 3 is $2(n + 3)$, so Q–4.
Step 3Half the number, increased by 3, is $\frac{n}{2} + 3$, so S–3.
Answer(c) P–2, Q–4, R–1, S–3
