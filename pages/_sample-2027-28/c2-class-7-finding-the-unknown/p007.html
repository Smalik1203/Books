A shorter way to write the steps

We can solve equations faster if we notice one thing. Look again at the first step for $11y + (-5) = 61$. We subtracted $-5$ from both sides, and this removed the term $-5$ from the LHS. So we could simply have written $11y = 61 - (-5)$.

In the same way, when we had $11y = 66$, dividing both sides by 11 removed the factor 11 from the LHS. So we could have written $y = 66 \div 11$ straight away. Table 7.9 sets the two ways side by side, for this equation and for $6y + 7 = 4y + 21$.

Table 7.9 Two ways to write the same solution

$11y + (-5) = 61$$11y + (-5) = 61$
$11y + (-5) - (-5) = 61 - (-5)$$11y = 61 - (-5)$
$11y = 66$$11y = 66$
$11y \div 11 = 66 \div 11$$y = 66 \div 11$
$y = 6$$y = 6$
$6y + 7 = 4y + 21$$6y + 7 = 4y + 21$
$6y + 7 - 4y = 4y + 21 - 4y$$6y + 7 - 4y = 21$
$2y + 7 = 21$$2y + 7 = 21$
$2y + 7 - 7 = 21 - 7$$2y = 21 - 7$
$2y = 14$$2y = 14$
$2y \div 2 = 14 \div 2$$y = 14 \div 2$
$y = 7$$y = 7$
