position 1 uses $2 \times 1 + 1 = 3$ matchsticks

position 2 uses $2 \times 2 + 1 = 5$ matchsticks

position 3 uses $2 \times 3 + 1 = 7$ matchsticks

The pattern goes on in the same way, so the arrangement at position $n$ uses $2n + 1$ matchsticks. For Jasmine’s question, we need the value of $n$ for which $2n + 1$ is 99. That is, we need $n$ such that

$2n + 1 = 99$

How can you find the value of $n$? Can an arrangement in this pattern be made with exactly 200 matchsticks?

Equations

Equation

A statement that two algebraic expressions are equal is called an equation. We write it as the two expressions with an equals sign $=$ between them.

Here are some more equations: $3x + 4 = 7$, $20 = y - 3$, $\frac{a}{3} = 50$ and $2z + 4 = 5z - 14$.

The expression on the left of the equals sign is the left-hand side (LHS) of the equation, and the expression on the right is the right-hand side (RHS). In $2n + 1 = 99$, the LHS is $2n + 1$ and the RHS is 99.

Finding the values of the letter-numbers that make the LHS equal to the RHS is called solving the equation. The matchstick problem shows why this is useful. When we write an unknown quantity as a letter-number and make an equation, we can then find its value.

Go back to the weights in Fig. 7.2, Fig. 7.4 and Fig. 7.5. Make an equation for each, using a letter-number for the unknown weight.

In Fig. 7.4(a), each square weighs 2. Let one circle weigh $c$. The three squares weigh $2 + 2 + 2 = 6$ and the two circles weigh $c + c$. The bar is level, so

$6 = c + c$, that is, $2c = 6$

In Fig. 7.4(b), each triangle weighs 4. Let one circle weigh $y$. The left side weighs 16, and the right side weighs $4 + 2y$. So we have the equation $4 + 2y = 16$.

Solve the equations you have made. Do you get the same weights that you found before? Then make up five equations of your own, and find ways to solve them.
