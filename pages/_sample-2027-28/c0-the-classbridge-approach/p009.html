A solved example prints its answer, because the working is the lesson. A practice question does not, so that a student commits to an answer before checking it, and a teacher can set any page of questions as a test: in the class books the answers to By the Book and to Beyond the Book are kept apart from the questions. Every answer, with its working, is also given in the companion book of detailed answers. This specimen leaves them out.

In the class books Beyond the Book is longer than in these samples, which have been shortened to fit five chapters into one book: a class book carries fifteen solved examples in each chapter, and a fuller set of practice questions after them. The shape is the same; only the number of questions changes.

6How the mathematics grows

The syllabus returns to each strand of mathematics every year and takes it further. The table follows five strands from Class 6 to Class 10. A student who meets an idea in one class meets it again, deeper, in the next, and the books are written so that each chapter can lean on the ones before it. The table names topics rather than chapter titles, since one chapter often serves more than one strand.
