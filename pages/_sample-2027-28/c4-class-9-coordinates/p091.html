    1. $4$
    2. $12$
    3. $16$
    4. $20$
Assertion and reason

In Questions 8 to 11, choose (a) if both A and R are true and R explains A; (b) if both are true but R does not explain A; (c) if A is true but R is false; (d) if A is false but R is true.

  1. Assertion (A): It never matters which of two points is called the first when finding the distance between them.

    Reason (R): The formula squares each shift, and a square is never negative.

  1. Assertion (A): The point $(-3, -3)$ lies in Quadrant IV.

    Reason (R): Both coordinates of $(-3, -3)$ are negative.

  1. Assertion (A): The points $(2, 0)$ and $(-2, 0)$ are the same distance from the origin.

    Reason (R): Every point of the x-axis has y-coordinate $0$.

  1. Assertion (A): The points $(3, 4)$ and $(4, 3)$ are the same distance from the origin.

    Reason (R): Two points the same distance from the origin always lie in the same quadrant.
