Competitive-Style Thinking
Four moves worth more than another formula.
Eliminate No distance is negative, and none is smaller than either shift. Two options are usually dead before any arithmetic.
Check sufficiency Ask what has been fixed. One distance fixes a circle, not a point — so the answer is often a pair.
Find the constraint $d^2 = (\Delta x)^2 + (\Delta y)^2$. Any three of those four numbers give the fourth.
Estimate first $d$ lies between the larger shift and the sum of the two. Bound it, then see which option survives.

Name the move, then use it.

  1. Eliminate. Strike out two options on sight, then answer. The distance between $(2,3)$ and $(14,8)$ is
    1. $7$
    2. $13$
    3. $17$
    4. $60$
  2. Eliminate. A point $25$ units from the origin has $x = 7$. Then $|y|$ is
    1. $18$
    2. $24$
    3. $32$
    4. $625$
  3. Sufficiency. The distance between $(3, a)$ and $(6, 5)$ is $5$. Say why this does not fix $a$, and give every value it allows.
  4. Sufficiency. A circle is centred at the origin through $(6, 8)$. Which single fact settles whether $(-9, 5)$ lies inside it?
    1. The circle's radius
    2. The distance of $(-9,5)$ from the origin
    3. The quadrant $(-9,5)$ lies in
    4. The circle's area
