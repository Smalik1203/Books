Problem 2

The distance between $(a, 2)$ and $(7, 6)$ is $5$. Then $a$ is

  1. $4$ only
  2. $10$ only
  3. $4$ or $10$
  4. $3$ or $11$
Solution

The shift in $y$ is $6 - 2 = 4$, and the distance is $5$.

$(7 - a)^2 + 4^2 = 25$

$(7 - a)^2 = 9$

$7 - a = 3$  or  $7 - a = -3$

$a = 4$  or  $a = 10$

Option (c). The two points are $(4, 2)$ and $(10, 2)$, one on each side of $(7, 2)$ and $3$ units from it. Options (a) and (b) each keep one sign of the square root and drop the other. Option (d) comes from $7 - a = \pm 4$, which would need the other shift to be $3$. It is $4$.

Problem 3

Which of these points is farthest from the origin?

  1. $(7, 1)$
  2. $(5, 5)$
  3. $(-6, 4)$
  4. $(0, -7)$
Solution

The distance of $(x, y)$ from the origin is $\sqrt{x^2 + y^2}$. To compare four of them there is no need for a single square root: the larger distance has the larger square.

$7^2 + 1^2 = 50$

$5^2 + 5^2 = 50$

$(-6)^2 + 4^2 = 52$

$0^2 + (-7)^2 = 49$

The largest is $52$, so the farthest point is $(-6, 4)$: option (c). Option (d) has the largest single coordinate, but its other coordinate is $0$ and adds nothing. Options (a) and (b) are equally far from $O$, which is easy to miss without the squares. And the negative coordinate in (c) makes no difference to the distance, because it is squared.
