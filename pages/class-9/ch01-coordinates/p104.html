Problem 1

The points $A (2, 4)$, $B (5, 8)$, $C (9, 5)$ and $D (6, 1)$ are joined in that order (Fig. 1B.3). $ABCD$ is

  1. a square
  2. a rhombus that is not a square
  3. a rectangle that is not a square
  4. a parallelogram with no right angle
Solution

A square has four equal sides and a right angle, and the squares of the distances settle both.

$AB^2 = 3^2 + 4^2 = 25$    $BC^2 = 4^2 + 3^2 = 25$

$CD^2 = 3^2 + 4^2 = 25$    $DA^2 = 4^2 + 3^2 = 25$

Four equal sides, so $ABCD$ is at least a rhombus — which is where option (b) stops. For the angle at $B$, take the diagonal.

$AC^2 = 7^2 + 1^2 = 50 = AB^2 + BC^2$

So the angle at $B$ is a right angle, and a rhombus with a right angle is a square: option (a). Option (c) checks the right angle and not the sides, option (d) the opposite sides alone.
