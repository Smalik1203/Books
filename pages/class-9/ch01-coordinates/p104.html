Example 3 · Single correct

Which of these points is farthest from the origin?

Choose one correct option.

  1. $(7, 1)$
  2. $(5, 5)$
  3. $(-6, 4)$
  4. $(0, -7)$

Solution.

Step 1Compare squared distances: $49 + 1 = 50$, $25 + 25 = 50$, $36 + 16 = 52$ and $0 + 49 = 49$.
Step 2The largest is 52, for $(-6, 4)$.
Answer(c) $(-6, 4)$
Example 4 · Single correct

Which point on the $y$-axis is equidistant from $A(-5, 2)$ and $B(3, 4)$?

Choose one correct option.

  1. $(0, 1)$
  2. $(0, -4)$
  3. $(1, 0)$
  4. $(0, -1)$

Solution.

Step 1For $(0, y)$: $25 + (y - 2)^2 = 9 + (y - 4)^2$, so $29 - 4y = 25 - 8y$.
Step 2$4y = -4$ and $y = -1$. Check: both distances are $\sqrt{34}$.
Answer(d) $(0, -1)$
Example 5 · Single correct

The midpoint of $P(a, 3)$ and $Q(5, b)$ is $M(2, -1)$. What is $(a, b)$?

Choose one correct option.

  1. $(-1, -5)$
  2. $(-3, -4)$
  3. $(1, -5)$
  4. $(-1, -2)$

Solution.

Step 1$\frac{a + 5}{2} = 2$ gives $a = -1$.
Step 2$\frac{3 + b}{2} = -1$ gives $b = -5$.
Answer(a) $(-1, -5)$
