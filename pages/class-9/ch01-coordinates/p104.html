Solution 1

A square has four equal sides and a right angle. Both can be checked with distances, and the squares of the distances are enough:

$AB^2 = 3^2 + 4^2 = 25$,   $BC^2 = 4^2 + 3^2 = 25$,   $CD^2 = 3^2 + 4^2 = 25$,   $DA^2 = 4^2 + 3^2 = 25$

Four equal sides, so $ABCD$ is at least a rhombus. That is where option (b) stops. For the angle at $B$, take the diagonal: $AC^2 = 7^2 + 1^2 = 50$, and $AB^2 + BC^2 = 50$ too. So the angle at $B$ is a right angle, and a rhombus with a right angle is a square: option (a). Option (c) is what you get by checking the right angle and not the sides. Option (d) is a parallelogram checked by its opposite sides alone.

Problem 2 · Try it first

The distance between $(a, 2)$ and $(7, 6)$ is $5$. Then $a$ is

  1. $4$ only
  2. $10$ only
  3. $4$ or $10$
  4. $3$ or $11$
Solution 2

The shift in $y$ is $6 - 2 = 4$ and the distance is $5$, so the shift in $x$ must satisfy

$(7 - a)^2 + 4^2 = 25$,  so  $(7 - a)^2 = 9$

Then $7 - a = 3$ or $7 - a = -3$, and $a = 4$ or $a = 10$: option (c). Options (a) and (b) each keep one sign of the square root and drop the other. The two points are $(4, 2)$ and $(10, 2)$, one on each side of $(7, 2)$ and $3$ units from it. Option (d) comes from $7 - a = \pm 4$, which would need the other shift to be $3$. It is $4$.
