B5.1 hint Write it as $(x, 0)$ and equate the two squared distances.
solution $(x-2)^2 + 25 = (x+2)^2 + 81$ gives $8x = -56$, so the point is $(-7, 0)$.
key idea The $x^2$ terms cancel, and a condition full of roots turns linear.
B7.5 hint Write $PA^2 = 4PB^2$, not $PA = 2PB$.
solution $(x+3)^2 + y^2 = 4\left[(x-3)^2 + y^2\right]$ reduces to $x^2 + y^2 - 10x + 9 = 0$, that is $(x-5)^2 + y^2 = 16$.
key idea A condition on distances becomes an equation, and the equation names a shape.
B2.3 A is true: $(-x)^2 + (-y)^2 = x^2 + y^2$. But R is false — $(x, y) \to (-x, -y)$ is a half-turn about $O$, not a reflection, which would change only one sign. Hence (c).
key idea A true assertion does not make its reason true. Test the two halves apart before pairing them.
What to take away
  1. Square a distance before using it; the roots are rarely needed.
  2. A condition on distances is an equation, and an equation is a shape.
  3. Signs alone fix the quadrant; a zero fixes an axis.
  4. The straight line is one measurement of a pair of points, not always the useful one. Symmetry pays: find one point and the plane hands you three.
