Brahmagupta’s formula

If a cyclic 4-gon has sides $a$, $b$, $c$, $d$ and semi-perimeter $s = \frac{1}{2}(a + b + c + d)$, then

$$\text{area of the 4-gon} = \sqrt{(s - a)(s - b)(s - c)(s - d)}.$$

It is an amazing and beautiful formula! Does it remind you of Heron’s formula for the area of a triangle? We can check that it works in some special cases.

Example 6

Check Brahmagupta’s formula for a rectangle.

Every rectangle is cyclic, so Brahmagupta’s formula should apply. Let the sides of the rectangle be $a$ and $b$.

Solution.

Step 1 $s = \frac{1}{2}(2a + 2b) = a + b$ semi-perimeter
Step 2 area $= \sqrt{(a + b - a)(a + b - b)(a + b - a)(a + b - b)} = \sqrt{ab \cdot ab} = ab$ Brahmagupta’s formula
Answer The formula gives $ab$, which is correct.

Try the formula on other special cases too.

Example 7

Check Brahmagupta’s formula for an isosceles trapezium.

Solution. Every isosceles trapezium is cyclic, so the formula should apply.

Step 1 the perimeter is $2a + 2b + 2c$, so $s = a + b + c$ semi-perimeter
Step 2 $s - 2a = c + b - a$, $s - 2b = c + a - b$, $s - c = a + b$
Step 3 area $= \sqrt{(s - 2a)(s - 2b)(s - c)(s - c)} = (a + b)\sqrt{c^2 - (b - a)^2}$ Brahmagupta
Step 4 the height from $B$ to $DC$ is $h = \sqrt{c^2 - (b - a)^2}$ Baudhāyana–Pythagoras
Answer The formula gives $(a + b)h$: half the sum of the parallel sides times the height, the area of the trapezium.
