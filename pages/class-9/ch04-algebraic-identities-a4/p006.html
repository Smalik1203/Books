That is worth remembering as a habit: take out any common factor first. It can turn an expression that seems to need surds into one that does not.

Think and Reflect

Everything so far has been about $(a + b)^2$. Nothing in the argument said $b$ had to be positive — so replace $b$ by $-b$ throughout the identity. What comes out?

Since $(-b)^2 = b^2$ and $2a(-b) = -2ab$, only the middle term changes sign — a second identity, free of charge:

$$(a - b)^2 = a^2 - 2ab + b^2$$

It is an identity for the same reason the first one is — no particular values were used in getting it — and it does all the same jobs: expanding brackets, squaring numbers in the head, and spotting perfect squares to factorise.

Back to the pattern

Return now to the first page of this chapter. Three consecutive squares, add the outer two, subtract twice the middle — always 2. Arithmetic can confirm that forever without saying why; algebra says it in one line.

The move that unlocks it is choosing how to name the numbers. Three consecutive whole numbers are not $n$, $n + 1$, $n + 2$; they are more usefully written with the middle one at the centre:

$$n - 1, \qquad n, \qquad n + 1$$

Now the outer two squares are $(n - 1)^2$ and $(n + 1)^2$ — one needing each identity. Add them:

$(n - 1)^2 + (n + 1)^2 = \left(n^2 - 2n + 1\right) + \left(n^2 + 2n + 1\right)$

$= 2n^2 + 2$

Watch what happened to the middle terms: $-2n$ from the first bracket and $+2n$ from the second cancel exactly. That cancellation is the whole secret of the pattern. Now subtract twice the middle square, $2n^2$:

$$\left(2n^2 + 2\right) - 2n^2 = 2$$
