Solution

Theorem 12 is the test: a quadrilateral is cyclic exactly when two opposite angles add to $180^\circ$.

(b) rectangle:   $90^\circ + 90^\circ = 180^\circ$

(a) rhombus:   equal opposite angles, $180^\circ$ only if each is $90^\circ$

(c) parallelogram:   $60^\circ + 60^\circ \ne 180^\circ$

(d)   $100^\circ + 100^\circ = 200^\circ$

Only (b) must be cyclic. A rhombus with a right angle is a square, so some rhombuses are cyclic but a rhombus need not be. In (d) it is the neighbours $100^\circ + 80^\circ$ that add to $180^\circ$, which is how it gets chosen. Exercise Set 5.7 had already shown the rectangle is the only parallelogram a circle passes through.
