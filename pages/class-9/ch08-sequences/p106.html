Example 2 · Single correct

Which term of the AP $4, 11, 18, \ldots$ is 256?

Choose one correct option.

  1. 36
  2. 37
  3. 38
  4. 252

Solution.

Step 1$4 + (n - 1) \times 7 = 256$, so $(n - 1) \times 7 = 252$.
Step 2$n - 1 = 36$, so 256 is the 37th term.
Answer(b) 37
Example 3 · Single correct

What is the 6th term of the GP $2, -6, 18, \ldots$?

Choose one correct option.

  1. 486
  2. 1458
  3. $-486$
  4. $-1458$

Solution.

Step 1$a = 2$ and $r = -3$, so $t_6 = 2 \times (-3)^5$.
Step 2$(-3)^5 = -243$, so $t_6 = -486$: an odd power keeps the minus sign.
Answer(c) $-486$
Example 4 · Single correct

What is $1 + 2 + 3 + \cdots + 50$?

Choose one correct option.

  1. 1250
  2. 2550
  3. 1225
  4. 1275

Solution.

Step 1The sum of the first $n$ natural numbers is $\frac{n(n + 1)}{2}$.
Step 2$\frac{50 \times 51}{2} = 1275$.
Answer(d) 1275
