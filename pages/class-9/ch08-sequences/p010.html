8.4Arithmetic Progressions

Some sequences follow no clear rule at all — the primes are the standing example. Others follow the simplest rule there is. This section is about those: the sequences that go up, or down, by the same amount every time.

Here is a pattern of tiles that grows in stages.

Counting the tiles gives $1, 5, 9, 13, \ldots$ — and the picture says why. At every stage four tiles are added, one at each tip. So the counts can be written

$1, \quad 1 + 4, \quad 1 + 4 + 4, \quad 1 + 4 + 4 + 4, \ \ldots$

or, gathering the fours,

$1, \quad 1 + 1 \times 4, \quad 1 + 2 \times 4, \quad 1 + 3 \times 4, \ \ldots$

Now the pattern is in plain sight. The number of fours is always one less than the stage number, so

$$t_n = 1 + (n - 1) \times 4$$

which tidies to $t_n = 4n - 3$. The first six terms are $1, 5, 9, 13, 17, 21$, and the difference between consecutive terms is $4$ every time.

A sequence like this — one where the difference between consecutive terms is the same throughout — is an arithmetic progression, or AP. The two numbers that describe it are the first term and that fixed gap, which is called the common difference.

Both numbers are needed, and neither is enough alone. Told only that the common difference is $4$ you would not know where the sequence starts; told only that it starts at $1$ you would not know where it goes. Between them they fix every term, which is why an AP can be written down in two numbers however long it runs.
