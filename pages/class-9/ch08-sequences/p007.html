8.3The Recursive Rule

There is a second way to write down a sequence, and it is the way most people describe one out loud. Asked about $1, 4, 7, 10, 13, \ldots$ you would probably not say "the $n$th term is $3n - 2$". You would say: start at $1$ and keep adding $3$.

That is a rule too, and it is worth writing properly. Each term is $3$ more than the one before, so

start $t_1 = 1$
then $t_n = t_{n-1} + 3$   for $n \geq 2$

This is a recursive rule. It says where to start and how to get from any term to the next, and between them those two things pin the sequence down completely.

Two Rules, Two Jobs

An explicit rule gives $t_n$ from $n$: it reaches any term directly.

A recursive rule gives $t_n$ from the terms before it, and a starting value: it walks.
