Using What You Know
The chapter's identities, in questions that do not say which one to use.

The chapter ended with eight identities. Every question below can be answered with those eight alone. What is new is that the question no longer says which one to use. Try each question before you read on.

If $x + y + z = 0$, find the value of $x^3 + y^3 + z^3 - 3xyz$.

The last identity of the chapter is

$$x^3 + y^3 + z^3 - 3xyz = (x + y + z)\left(x^2 + y^2 + z^2 - xy - yz - zx\right)$$

The first bracket on the right is $x + y + z$. We are told it is $0$. So the product is $0$. This means $x^3 + y^3 + z^3 = 3xyz$ whenever $x + y + z = 0$. Notice that we did not need to find $x$, $y$ and $z$. There are infinitely many triples that add to zero. One of them is $1, 2, -3$. The result holds for every one of them. A condition given in a question is often one side of an identity. Read the condition first. Then ask which identity it belongs to.

If $a + b = 5$ and $ab = 6$, find $a^2 + b^2$ and $a^3 + b^3$.

We know $(a + b)^2 = a^2 + 2ab + b^2$. So $a^2 + b^2 = 25 - 12 = 13$. We also know $(a + b)^3 = a^3 + b^3 + 3ab(a + b)$. So $a^3 + b^3 = 125 - 90 = 35$. Here $a$ and $b$ happen to be $2$ and $3$. Check: $4 + 9 = 13$ and $8 + 27 = 35$. But we never needed to find them. Often it is not even possible. Take $a + b = 5$ and $ab = 7$. There are no whole numbers with this sum and product. Still, $a^2 + b^2 = 11$ is just as certain. The sum and the product fix every expression that treats $a$ and $b$ in the same way. Only the difference needs one more step, $(a - b)^2 = (a + b)^2 - 4ab$. Even that does not tell us the sign of $a - b$.
