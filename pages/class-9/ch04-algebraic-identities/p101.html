Using What You Know

The chapter ended with eleven identities. Every question below can be answered with those eleven alone. What is new is that the question no longer says which one to use. Try each question before you read on.

If $a + b + c = 0$, show that $a^2 - bc = b^2 - ca$.

Nothing here says what $a$, $b$ and $c$ are, so the condition has to be used as it stands. Take one side from the other:

$$\left(a^2 - bc\right) - \left(b^2 - ca\right) = \left(a^2 - b^2\right) + c(a - b)$$

The first bracket is a difference of squares, $(a + b)(a - b)$, and the condition says $a + b = -c$. So $a^2 - b^2 = -c(a - b)$, and the whole difference is $-c(a - b) + c(a - b) = 0$. The two sides are equal. Notice that we did not need to find $a$, $b$ and $c$. There are infinitely many triples that add to zero. One of them is $1, 2, -3$, which gives $1 + 6 = 7$ on the left and $4 + 3 = 7$ on the right. The result holds for every one of them. A condition given in a question is often one piece of an identity. Read the condition first. Then ask which identity it belongs to.

If $a + b = 5$ and $ab = 6$, find $a^2 + b^2$ and $a^3 + b^3$.

We know $(a + b)^2 = a^2 + 2ab + b^2$. So $a^2 + b^2 = 25 - 12 = 13$. We also know $(a + b)^3 = a^3 + b^3 + 3ab(a + b)$. So $a^3 + b^3 = 125 - 90 = 35$. Here $a$ and $b$ happen to be $2$ and $3$. Check: $4 + 9 = 13$ and $8 + 27 = 35$. But we never needed to find them. Often it is not even possible. Take $a + b = 5$ and $ab = 5$. There are no whole numbers with this sum and product. Still, $a^2 + b^2 = 15$ is just as certain. The sum and the product fix every expression that treats $a$ and $b$ in the same way. Only the difference needs one more step, $(a - b)^2 = (a + b)^2 - 4ab$. Even that does not tell us the sign of $a - b$.
