Type 2 · The square of three terms

Example 3

If $a + b + c = 9$ and $a^2 + b^2 + c^2 = 35$, then $ab + bc + ca$ is

  1. $23$
  2. $46$
  3. $58$
  4. $13$

Solution.

Step 1 $(a + b + c)^2 = a^2 + b^2 + c^2 + 2(ab + bc + ca)$ the three-term identity
Step 2 $81 = 35 + 2(ab + bc + ca)$
Step 3 $2(ab + bc + ca) = 46$, so $ab + bc + ca = 23$
Answer (a)
Check $1$, $3$ and $5$ fit, and $3 + 15 + 5 = 23$

Option (b) is $2(ab + bc + ca)$, where the working stops one line early. Option (c) adds $35$ instead of taking it away: $(81 + 35) \div 2 = 58$. Option (d) forgets to square the sum: $(35 - 9) \div 2 = 13$.

Type 3 · The difference of squares

Example 4

Factorise $a^2 - b^2 - 2bc - c^2$.

Solution.

Step 1 $a^2 - b^2 - 2bc - c^2 = a^2 - \left(b^2 + 2bc + c^2\right)$ group the last three terms
Step 2 $= a^2 - (b + c)^2$ a perfect square
Step 3 $= \left[a + (b + c)\right]\left[a - (b + c)\right]$ difference of squares
Answer $a^2 - b^2 - 2bc - c^2 = (a + b + c)(a - b - c)$
Check at $a = 5$, $b = 2$, $c = 1$: $25 - 4 - 4 - 1 = 16$ and $8 \times 2 = 16$
