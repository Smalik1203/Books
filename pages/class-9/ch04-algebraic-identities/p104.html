Multiple Choice · Level 1
One step, from one result.

Choose the correct option.

  1. $(2x - 3y)^2$ expands to
    1. $4x^2 - 6xy + 9y^2$
    2. $4x^2 - 12xy + 9y^2$
    3. $4x^2 - 12xy - 9y^2$
    4. $2x^2 - 12xy + 3y^2$
  2. The value of $103 \times 97$ is
    1. $9891$
    2. $9991$
    3. $9999$
    4. $10009$
  3. $x^2 - 11x + 30$ factorises as
    1. $(x + 5)(x + 6)$
    2. $(x - 5)(x - 6)$
    3. $(x - 3)(x - 10)$
    4. $(x - 2)(x - 15)$
  4. If $x + \dfrac{1}{x} = 5$, then $x^2 + \dfrac{1}{x^2}$ equals
    1. $21$
    2. $23$
    3. $25$
    4. $27$
  5. $(a + b + c)^2 - \left(a^2 + b^2 + c^2\right)$ is equal to
    1. $0$
    2. $abc$
    3. $ab + bc + ca$
    4. $2(ab + bc + ca)$
  6. For $x \neq -3$, the expression $\dfrac{x^2 - 9}{x + 3}$ simplifies to
    1. $x - 3$
    2. $x + 3$
    3. $x - 9$
    4. $\dfrac{x - 3}{3}$
  7. $27a^3 + 8b^3$ factorises as
    1. $(3a + 2b)\left(9a^2 - 6ab + 4b^2\right)$
    2. $(3a + 2b)\left(9a^2 + 6ab + 4b^2\right)$
    3. $(3a - 2b)\left(9a^2 + 6ab + 4b^2\right)$
    4. $(3a + 2b)\left(3a^2 - 6ab + 2b^2\right)$
  8. Which of these is not an identity?
    1. $(x + 1)^2 = x^2 + 2x + 1$
    2. $x^2 - 4 = (x - 2)(x + 2)$
    3. $x^2 + 5x = 6x$
    4. $(x - 1)^3 = x^3 - 3x^2 + 3x - 1$
  9. A cube has volume $8p^3 + 36p^2q + 54pq^2 + 27q^3$ cubic units. Its edge is
    1. $2p + 3q$
    2. $2p + 9q$
    3. $4p + 3q$
    4. $8p + 27q$
