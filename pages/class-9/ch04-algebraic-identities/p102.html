Think and Reason
Judge a claim — and the reason offered for it.

Questions 1–4 take this key. (a) both true, R explains A; (b) both true, R does not explain A; (c) A true, R false; (d) A false, R true.

  1. A. $(a - b)^2 = (b - a)^2$ for every $a$ and $b$.  R. A number and its negative have the same square.
  2. A. $x^3 + y^3 + z^3 = 3xyz$ for all $x$, $y$, $z$ with $xyz \neq 0$.  R. $x^3 + y^3 + z^3 - 3xyz = (x+y+z)\left(x^2+y^2+z^2-xy-yz-zx\right)$.
  3. A. $a^2 + b^2 \geq 2ab$ for every $a$ and $b$.  R. $a^2 + b^2$ and $2ab$ are both non-negative.
  4. A. $(x+2)(x+3) = x^2 + 5x + 6$ is an identity.  R. It is true at $x = 1$.
  5. Which of these are identities?
    1. $(x + 2)(x + 3) = x^2 + 5x + 6$
    2. $x^2 + 5x + 6 = 0$
    3. $x^2 - 4 = (x - 2)(x + 2)$
    1. (i) only
    2. (i) and (iii)
    3. (ii) and (iii)
    4. all three
  6. Given $a + b = 5$ and $ab = 6$, which must be true?
    1. $a^2 + b^2 = 13$
    2. $(a - b)^2 = 1$
    3. $a^3 + b^3 = 35$
    1. (i) only
    2. (i) and (ii)
    3. (ii) and (iii)
    4. all three
  7. For every whole number $n$, which must be true of $n^3 - n$?
    1. It is even.
    2. It is a multiple of $3$.
    3. It is a multiple of $12$.
    1. (i) only
    2. (ii) and (iii)
    3. (i) and (ii)
    4. all three
  8. Write $p = x + y + z$, $q = xy + yz + zx$ and $r = xyz$. Show that $x^2 + y^2 + z^2 = p^2 - 2q$, and say why no fourth quantity is ever needed for a symmetric expression.
