As it stands, this is not a perfect square. It is not a difference of squares either. But it has two of the three terms of a perfect square: $\left(x^2 + 2y^2\right)^2 = x^4 + 4x^2y^2 + 4y^4$. Add the missing middle term, and take it away again. The expression has not changed. Now it becomes

$$x^4 + 4y^4 = \left(x^2 + 2y^2\right)^2 - (2xy)^2$$

This is a difference of squares (Fig. 4B.2). So $x^4 + 4y^4 = \left(x^2 + 2y^2 - 2xy\right)\left(x^2 + 2y^2 + 2xy\right)$. Check at $x = y = 1$. The left side is $5$ and the right side is $1 \times 5$. When no identity fits an expression, ask what single term would make one fit. The same step writes $a^4 + a^2 + 1$ as $\left(a^2 + 1\right)^2 - a^2$.

Is $(a + b)^3 = a^3 + b^3$ an identity? Is $x^2 + 5x + 6 = (x + 2)(x + 3)$ an identity?

Put $a = b = 1$ in the first. The left side is $8$ and the right side is $2$. One value where the two sides differ is enough. The first is not an identity. Now put $x = 1$ in the second. Both sides are $12$. That proves nothing. An equation can hold at one value without holding at all values. For example, $x^2 + 5x + 6 = 12$ is also true at $x = 1$. To show the second is an identity, we multiply out the right side. It is an identity. So a value can disprove, but it cannot prove. In a question with four options, one value can rule out an option quickly. Only the identity can confirm the option that is left.
