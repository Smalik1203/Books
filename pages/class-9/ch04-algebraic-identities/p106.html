Problem 5 · Try it first

The number of whole numbers $n$ for which $n^4 + 4$ is a prime number is

  1. $0$
  2. $1$
  3. $2$
  4. infinitely many
Solution 5

$n^4 + 4$ is $x^4 + 4y^4$ with $x = n$ and $y = 1$. Stage 1 factorised that:

$n^4 + 4 = \left(n^2 - 2n + 2\right)\left(n^2 + 2n + 2\right)$

A number written as a product of two factors is prime only if one of the factors is $1$. The smaller factor is $n^2 - 2n + 2 = (n - 1)^2 + 1$. This is $1$ only when $n = 1$. For every other whole number $n$ it is at least $2$. The other factor is also at least $2$. So the product is not prime. At $n = 1$ itself, $n^4 + 4 = 5$, which is prime. So there is exactly one such $n$, option (b).
