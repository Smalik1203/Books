Example 1 · Single correct

If $a + b + c = 9$ and $a^2 + b^2 + c^2 = 35$, what is $ab + bc + ca$?

Choose one correct option.

  1. 23
  2. 46
  3. 58
  4. 13

Solution.

Step 1$(a + b + c)^2 = a^2 + b^2 + c^2 + 2(ab + bc + ca)$, so $81 = 35 + 2(ab + bc + ca)$.
Step 2$ab + bc + ca = \frac{46}{2} = 23$.
Answer(a) 23
Example 2 · Single correct

$x^2 - 2x - 35$ is equal to

Choose one correct option.

  1. $(x + 7)(x - 5)$
  2. $(x - 7)(x + 5)$
  3. $(x - 7)(x - 5)$
  4. $(x + 7)(x + 5)$

Solution.

Step 1Two numbers with product $-35$ and sum $-2$: $-7$ and $5$.
Step 2So $x^2 - 2x - 35 = (x - 7)(x + 5)$.
Answer(b) $(x - 7)(x + 5)$
Example 3 · Single correct

If $x + y + z = 9$ and $xy + yz + zx = 26$, what is $x^3 + y^3 + z^3 - 3xyz$?

Choose one correct option.

  1. 9
  2. 81
  3. 27
  4. 243

Solution.

Step 1$x^3 + y^3 + z^3 - 3xyz = (x + y + z)\left[(x + y + z)^2 - 3(xy + yz + zx)\right]$.
Step 2$= 9 \times (81 - 78) = 27$.
Answer(c) 27
