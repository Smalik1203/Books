B9 · Foundation Test
  1. If $x + y = 12$ and $xy = 27$, then $x^3 + y^3$ is
    1. $756$
    2. $810$
    3. $972$
    4. $1728$
  2. Factorise $4a^2 - 4a + 1 - b^2$ completely.
  3. The value of $\dfrac{(0.87)^3 + (0.13)^3}{(0.87)^2 - 0.87 \times 0.13 + (0.13)^2}$ is
    1. $0.74$
    2. $0.87$
    3. $1$
    4. $1.13$
  4. Simplify $\dfrac{x^2 - 5x + 6}{x^2 - 9}$, and state the values of $x$ that had to be excluded.
  5. Is $(a + b)^3 = a^3 + b^3$ ever true? Find every pair $(a, b)$ for which it holds, and explain why there are no others.
  6. Evaluate $998^3$ using an identity, showing each term.
  7. The table gives the value of $x^2 + bx + c$ at four points. Find $b$ and $c$, then factorise the expression.
    $x$$0$$1$$2$$3$
    $x^2 + bx + c$$12$$6$$2$$0$
  8. If $a - b = 5$ and $ab = 14$, then $a^2 + b^2$ is
    1. $39$
    2. $53$
    3. $81$
    4. $95$
  9. Given $x + \dfrac{1}{x} = 3$, show that $x^3 + \dfrac{1}{x^3} = 18$.
  10. A rectangular garden has area $x^2 + 11x + 24$ square metres and length $x + 8$ metres. Find its breadth and its perimeter.
  11. If $a + b + c = 0$, show that $(a+b)(b+c)(c+a) = -abc$.
  12. $\tfrac{1}{2}\left[(a+b)^2 - (a-b)^2\right]$ equals
    1. $ab$
    2. $2ab$
    3. $4ab$
    4. $a^2 + b^2$
  13. A student claims $n^2 + n$ is even for every whole number $n$. Prove it by factorising. Is $n^3 + n$ always even as well? Give your reasoning, not examples.
