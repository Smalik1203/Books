Example 14 · Matching

Match List I with List II. Each entry has exactly one match.

List IList II
(P) $(a + b)^2 - (a - b)^2$(1) $a^2 - b^2$
(Q) $(a + b)^2 + (a - b)^2$(2) $6a^2b + 2b^3$
(R) $(a + b)(a - b)$(3) $4ab$
(S) $(a + b)^3 - (a - b)^3$(4) $2a^2 + 2b^2$

Choose the correct combination.

  1. P–3, Q–4, R–1, S–2
  2. P–4, Q–3, R–1, S–2
  3. P–3, Q–1, R–4, S–2
  4. P–2, Q–4, R–1, S–3

Solution.

Step 1Subtracting the squares leaves $4ab$ and adding gives $2a^2 + 2b^2$; the cubes leave $6a^2b + 2b^3$.
Answer(a) P–3, Q–4, R–1, S–2
Example 15 · Matching

Match List I with List II. Each entry has exactly one match.

List IList II
(P) $x^2 + 5x + 6$(1) $(x - 3)(x + 2)$
(Q) $x^2 - x - 6$(2) $(x + 3)(x - 2)$
(R) $x^2 + x - 6$(3) $(x - 2)(x - 3)$
(S) $x^2 - 5x + 6$(4) $(x + 2)(x + 3)$

Choose the correct combination.

  1. P–3, Q–1, R–2, S–4
  2. P–1, Q–4, R–2, S–3
  3. P–4, Q–2, R–1, S–3
  4. P–4, Q–1, R–2, S–3

Solution.

Step 1Two numbers with the right product and sum: $2, 3$; then $-3, 2$; then $3, -2$; then $-2, -3$.
Answer(d) P–4, Q–1, R–2, S–3
