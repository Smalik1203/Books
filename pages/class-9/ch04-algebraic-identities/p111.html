    1. $6$
    2. $10$
    3. $30$
    4. $60$

    $n^5 - n = (n - 1)\,n\,(n + 1)\left(n^2 + 1\right)$. Also, $n^2 + 1 = (n - 2)(n + 2) + 5$. Problem 4 does the rest.
