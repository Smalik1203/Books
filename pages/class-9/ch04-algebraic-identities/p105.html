Example 7 · Multiple correct

Which of these are factors of $6x^2 + 5x - 6$?

Select all correct options.

  1. $2x + 3$
  2. $3x - 2$
  3. $2x - 3$
  4. $3x + 2$

Solution.

Step 1Split the middle term: $6 \times (-6) = -36 = 9 \times (-4)$, so $6x^2 + 9x - 4x - 6 = 3x(2x + 3) - 2(2x + 3)$.
Step 2$6x^2 + 5x - 6 = (2x + 3)(3x - 2)$; the other two are not factors.
Answer(a), (b)
Example 8 · Multiple correct

$a - b = 4$ and $ab = 21$. Which statements are correct?

Select all correct options.

  1. $a^2 + b^2 = 58$
  2. $(a + b)^2 = 100$
  3. $a + b$ could be $-10$.
  4. $a^3 - b^3 = 64$

Solution.

Step 1$a^2 + b^2 = 16 + 42 = 58$ and $(a + b)^2 = 100$, so $a + b = \pm 10$ ($a = -3$, $b = -7$ works); $a^3 - b^3 = 4 \times 79 = 316$.
Answer(a), (b), (c)
