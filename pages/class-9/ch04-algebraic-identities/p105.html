Multiple Choice · Level 2
Two steps, and a figure to settle first.

Choose the correct option.

  1. If $a + b + c = 0$ and $abc \neq 0$, then $\dfrac{a^3 + b^3 + c^3}{abc}$ equals
    1. $-3$
    2. $0$
    3. $1$
    4. $3$
  2. $x^2 + kx + 36$ is a perfect square for
    1. $k = 6$ only
    2. $k = 12$ only
    3. $k = 6$ and $k = -6$
    4. $k = 12$ and $k = -12$
  3. If $x - \dfrac{1}{x} = 3$, then $x^3 - \dfrac{1}{x^3}$ equals
    1. $27$
    2. $30$
    3. $36$
    4. $45$
  4. $\dfrac{587^2 - 413^2}{587 - 413}$ is
    1. $174$
    2. $587$
    3. $1000$
    4. $174000$
  5. $a^4 + a^2 + 1$ factorises as
    1. $\left(a^2 + 1\right)\left(a^2 + a + 1\right)$
    2. $\left(a^2 + a + 1\right)\left(a^2 - a + 1\right)$
    3. $\left(a^2 - 1\right)\left(a^2 + a + 1\right)$
    4. it does not factorise
  6. The only factor common to $x^2 - x - 12$ and $x^2 - 9$ is
    1. $x - 3$
    2. $x + 3$
    3. $x - 4$
    4. $x + 4$
  7. If $p + q = 10$ and $p^3 + q^3 = 100$, then $pq$ equals
    1. $10$
    2. $20$
    3. $30$
    4. $90$
  8. For $a \neq \pm b$, the expression $\dfrac{a^3 - b^3}{a^2 - b^2}$ simplifies to
    1. $a - b$
    2. $\dfrac{a^2 + ab + b^2}{a + b}$
    3. $\dfrac{a^2 - ab + b^2}{a - b}$
    4. $\dfrac{a + b}{a - b}$
  9. Two positive numbers differ by $4$, and their squares differ by $96$. The larger number is
    1. $12$
    2. $14$
    3. $26$
    4. $28$
