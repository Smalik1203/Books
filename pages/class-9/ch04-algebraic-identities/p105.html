Solution 3

Call the sides $x$ and $y$. We want $xy$. We are given $x + y = 17$. By Pythagoras, $x^2 + y^2 = 169$. The square of the sum contains $2xy$, so

$2xy = (x + y)^2 - \left(x^2 + y^2\right) = 289 - 169 = 120$

So the area is $60$ cm$^2$, option (b). We never found a side. We could have: $(x - y)^2 = 169 - 120 = 49$, so the sides are $12$ and $5$. Option (c) is $2xy$ itself, not halved.

Problem 4 · Try it first

For every whole number $n$, the number $n^3 - n$ is a multiple of

  1. $4$
  2. $6$
  3. $12$
  4. $24$
Solution 4

The question says for every $n$. So trying values can rule options out, but it cannot rule one in. At $n = 2$, $n^3 - n = 6$. This is not a multiple of $4$, $12$ or $24$. Only (b) is left. It still has to be shown for every $n$. Factorise:

$n^3 - n = n\left(n^2 - 1\right) = (n - 1)\,n\,(n + 1)$

This is the product of three whole numbers in a row (Fig. 4B.5). Of any two numbers in a row, one is even. Of any three in a row, one is a multiple of $3$. So the product always has a factor $2$ and a factor $3$. So $6$ divides it. Option (b). Trying $n = 3, 4, 5$ gives multiples of $12$. That is how (c) gets chosen.
