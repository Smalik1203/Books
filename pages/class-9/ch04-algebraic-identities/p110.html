Assertion and reason

In Questions 18 to 21, choose (a) if both A and R are true and R explains A; (b) if both are true but R does not explain A; (c) if A is true but R is false; (d) if A is false but R is true.

  1. Assertion (A): $(a - b)^2 = (b - a)^2$ for every $a$ and $b$.

    Reason (R): A number and its negative have the same square.

  1. Assertion (A): $x^3 + y^3 + z^3 = 3xyz$ for all $x$, $y$ and $z$ that are not zero.

    Reason (R): $x^3 + y^3 + z^3 - 3xyz = (x + y + z)\left(x^2 + y^2 + z^2 - xy - yz - zx\right)$.

  1. Assertion (A): $101 \times 99 = 9999$.

    Reason (R): $(a + b)^2 = a^2 + 2ab + b^2$.

  1. Assertion (A): $x - 1$ is a factor of $x^3 - 1$.

    Reason (R): $x^3 - 1 = (x - 1)\left(x^2 - x + 1\right)$.
