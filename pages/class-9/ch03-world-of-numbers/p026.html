Competitive Practice

One option is correct in each. These are the forms the chapter's ideas take in entrance and olympiad papers — most can be settled by reasoning rather than by working, if you can see which idea is being asked about.

  1. Which of these is irrational?
    1. $\sqrt{36}$
    2. $0.25$
    3. $\sqrt{7}$
    4. $\dfrac{22}{7}$
  1. The decimal expansion of $\dfrac{17}{8}$ is
    1. terminating
    2. non-terminating, repeating
    3. non-terminating, non-repeating
    4. none of these
  1. $0.\overline{3} + 0.\overline{4}$ equals
    1. $0.\overline{7}$
    2. $\dfrac{7}{9}$
    3. both (a) and (b)
    4. neither
  1. Between any two distinct rational numbers there are
    1. exactly one rational number
    2. finitely many rational numbers
    3. infinitely many rational numbers
    4. no rational number at all
  1. In lowest terms, which of these cannot be the denominator of a terminating decimal?
    1. $16$
    2. $25$
    3. $40$
    4. $30$
  1. $\sqrt{2} \times \sqrt{8}$ equals
    1. an irrational number
    2. $4$
    3. $\sqrt{10}$
    4. $2\sqrt{2}$
  1. If $x = 0.\overline{7}$, then $9x$ equals
    1. $7$
    2. $0.7$
    3. $70$
    4. $63$
  2. $0.\overline{9}$ equals
    1. a number slightly less than $1$
    2. $1$
    3. $0.99$
    4. an irrational number
