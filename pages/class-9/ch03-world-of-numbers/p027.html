1. How many integers lie strictly between $-3$ and $3$?
    1. $5$
    2. $6$
    3. $7$
    4. infinitely many
  2. $(-5) \times (-3) \times (-2)$ equals
    1. $30$
    2. $-30$
    3. $10$
    4. $-10$
  3. Which of these is not a rational number?
    1. $0$
    2. $-\dfrac{7}{3}$
    3. $\sqrt{\dfrac{9}{4}}$
    4. $0.101101110\ldots$
  4. The repeating block of $\dfrac{1}{13}$ has length
    1. $3$
    2. $6$
    3. $12$
    4. $13$
  5. Assertion. Every integer is a rational number.
    Reason. Every integer $n$ can be written as $\dfrac{n}{1}$.
    1. Both are true, and the reason explains the assertion.
    2. Both are true, but the reason does not explain the assertion.
    3. The assertion is true and the reason is false.
    4. The assertion is false.
  6. A rational $\dfrac{p}{q}$ is in lowest terms and its decimal terminates after exactly three places. Which must be true of $q$?
    1. $q$ is a factor of $1000$ but not of $100$.
    2. $q$ is a multiple of $1000$.
    3. $q = 1000$.
    4. $q$ has 3 as a prime factor.

One chapter, five kinds of number, and a single pattern running through all of them: each was invented because a perfectly sensible question had no answer among the numbers that already existed.
