Competitive-Style Thinking
Four moves worth more than another rule.
Eliminate A root sign proves nothing. Test the number under it for a perfect square before touching the options.
Check sufficiency The terminating test needs the fraction in lowest terms. Reduce first, then look at the denominator's factors.
Find the constraint Dividing by $q$ there are only $q - 1$ possible remainders, so the cycle cannot be longer than that.
Estimate first Bound a surd between two whole numbers before comparing. $\sqrt{50}$ lies between $7$ and $8$, and that is often enough.

Name the move, then use it.

  1. Eliminate. Which of these is rational?
    1. $\sqrt{18}$
    2. $\sqrt{20}$
    3. $\sqrt{45}$
    4. $\sqrt{49}$
  2. Sufficiency. Which of these has a terminating decimal?
    1. $\dfrac{7}{30}$
    2. $\dfrac{6}{15}$
    3. $\dfrac{5}{12}$
    4. $\dfrac{4}{21}$
  3. Constraint. The cycle of $\dfrac{1}{13}$ cannot be longer than
    1. $6$ digits
    2. $12$ digits
    3. $13$ digits
    4. $130$ digits
  4. Constraint. One row below is wrong. Find it, name the mistake, and give the right value.
    Fraction$\dfrac{3}{8}$$\dfrac{5}{16}$$\dfrac{7}{25}$$\dfrac{9}{40}$
    Decimal$0.375$$0.3125$$0.028$$0.225$
  5. Estimate. Bounding each surd between whole numbers kills three of these. The largest is
    1. $\sqrt{50}$
    2. $\sqrt{27}$
    3. $3\sqrt{5}$
    4. $2\sqrt{11}$
  6. Sufficiency. Write $0.4\overline{27}$ as $\dfrac{p}{q}$ in lowest terms. Name the job each multiplier does, and say what the denominator records about the decimal.
  7. Estimate. Put $a = 0.\overline{6}$, $b = 0.1\overline{6}$ and $c = 0.\overline{16}$ in increasing order. Two are close enough that the decimals alone should not satisfy you.
