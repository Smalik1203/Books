Solution 1

The block is three digits long and it starts at the point, so one multiplier is enough. With $x = 0.123123\ldots$, $1000x = 123.123123\ldots$, and subtracting leaves $999x = 123$:

$x = \dfrac{123}{999} = \dfrac{41}{333}$

That is option (a). Option (c) is $\dfrac{123}{990}$, which has a $0$ in its denominator's $99\ldots9$ and so belongs to a decimal with one digit outside the cycle — the answer to $0.1\overline{23}$, not to this one. Option (b) is that same fraction reduced.

Option (d) is $\dfrac{123}{1000}$, which is $0.123$ exactly, a terminating decimal. A denominator of $9$s is what a repeating decimal leaves behind, and a denominator of $10$s is what a terminating one leaves. Reading the denominator tells you which kind of decimal it came from.

Problem 2 · Try it first

$2.3\overline{5}$ in lowest terms is

  1. $\dfrac{47}{20}$
  2. $\dfrac{106}{45}$
  3. $\dfrac{212}{99}$
  4. $\dfrac{235}{99}$
Solution 2

One digit after the point does not repeat and one does, so two multipliers are needed. Put $x = 2.3555\ldots$ The first pushes the $3$ past the point; the second moves the cycle on by one place, so the tails line up and cancel:

$10x = 23.5555\ldots$,   $100x = 235.5555\ldots$

$90x = 212$,  so  $x = \dfrac{212}{90} = \dfrac{106}{45}$

The answer is (b). Option (a) is $\dfrac{47}{20} = 2.35$, the number this would be if the $5$ stopped instead of repeating. Options (c) and (d) both carry a $99$, and $99$ belongs to a decimal that repeats from the point onwards: (d) is $2.\overline{35}$, and (c) is what comes of using $99$ where the $90$ belongs.

The $90$ is the whole point. One $9$ for the digit that repeats, one $0$ for the digit that does not — and the denominator says so before any cancelling is done.
