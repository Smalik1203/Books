Behind Each Answer
Five questions, with the reasoning as well as the working. Try each one before reading its solution.
Problem 1

$0.\overline{123}$ in lowest terms is

  1. $\dfrac{41}{333}$
  2. $\dfrac{41}{330}$
  3. $\dfrac{123}{990}$
  4. $\dfrac{123}{1000}$
Solution

The block is three digits long and starts at the point, so one multiplier is enough.

$x = 0.123123\ldots$

$1000x = 123.123123\ldots$

$999x = 123$

$x = \dfrac{123}{999} = \dfrac{41}{333}$

Option (a). Option (c) is $\dfrac{123}{990}$, whose $0$ belongs to a decimal with one digit outside the cycle — the answer to $0.1\overline{23}$, not to this one; option (b) is that same fraction reduced. Option (d) is $\dfrac{123}{1000}$, which is $0.123$ exactly. A denominator of $9$s is what a repeating decimal leaves behind and a denominator of $10$s what a terminating one leaves, so the denominator says which kind it came from.

The reduction is worth following through, because it looks at first as though it might spoil the rule. $\tfrac{123}{999}$ became $\tfrac{41}{333}$, and the nines are gone from the denominator. But $333 = 3^{2} \times 37$, which carries no $2$ and no $5$ — so the rule still says the decimal repeats, which of course it does.

Each wrong option here is the correct answer to a question that was not asked. Option (d) answers $0.123$. Option (c) answers $0.1\overline{23}$. Option (b) is option (c) tidied up. Only one decimal in the four has its cycle starting immediately after the point, and picking out which is the whole of the question.

And the reduced form can always be sent back the way it came, which is the cheapest check there is.

$41 \div 333 = 0.123123\ldots = 0.\overline{123}$
