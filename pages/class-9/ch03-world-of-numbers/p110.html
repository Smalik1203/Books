In Questions 16 to 19, choose (a) if both A and R are true and R explains A; (b) if both are true but R does not explain A; (c) if A is true but R is false; (d) if A is false but R is true.

    Reason (R): A decimal with $n$ places can be written as a whole number over $10^n$.

    Reason (R): The square root of a natural number that is not a perfect square is irrational.

    Reason (R): Only one fraction with denominator $24$ lies strictly between $\dfrac{1}{4}$ and $\dfrac{1}{3}$.

    Reason (R): A decimal that never terminates is irrational.
