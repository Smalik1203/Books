Problem 2

$2.3\overline{5}$ in lowest terms is

  1. $\dfrac{47}{20}$
  2. $\dfrac{106}{45}$
  3. $\dfrac{212}{99}$
  4. $\dfrac{235}{99}$
Solution

One digit after the point does not repeat and one does, so two multipliers are needed: the first pushes the $3$ past the point, the second moves the cycle on a place so the tails cancel.

$x = 2.3555\ldots$

$10x = 23.555\ldots$

$100x = 235.555\ldots$

$90x = 212$

$x = \dfrac{212}{90} = \dfrac{106}{45}$

Option (b). The $90$ is the whole point: one $9$ for the digit that repeats, one $0$ for the digit that does not. Option (a) is $\dfrac{47}{20} = 2.35$, this number with the $5$ stopped instead of repeating. Options (c) and (d) carry a $99$, which belongs to a decimal repeating from the point onwards: (d) is $2.\overline{35}$, and (c) uses $99$ where the $90$ belongs.

Problem 3

$\dfrac{p}{q}$ is in lowest terms and terminates after exactly four decimal places. Then

  1. $q$ divides $10^4$ but not $10^3$
  2. $q = 10^4$
  3. $q$ is a multiple of $10^4$
  4. $q$ has $3$ as a prime factor
