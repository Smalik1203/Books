Example 6 · Single correct

Given that $\sqrt{2}$, $\sqrt{3}$ and $\pi$ are irrational, which of these is rational?

Choose one correct option.

  1. $5\sqrt{2}$
  2. $(\sqrt{3} - \sqrt{2})(\sqrt{3} + \sqrt{2})$
  3. $\pi + 1$
  4. $\sqrt{2} + \sqrt{3}$

Solution.

Step 1$(\sqrt{3} - \sqrt{2})(\sqrt{3} + \sqrt{2}) = 3 - 2 = 1$.
Step 2A non-zero rational times an irrational, or an irrational plus a rational, stays irrational.
Answer(b) $(\sqrt{3} - \sqrt{2})(\sqrt{3} + \sqrt{2})$
Example 7 · Multiple correct

Which of these numbers are irrational?

Select all correct options.

  1. $\sqrt{6}$
  2. $\sqrt{16}$
  3. $0.\overline{3}$
  4. $2 + \sqrt{3}$

Solution.

Step 16 is not a perfect square, so $\sqrt{6}$ is irrational, and so is $2 + \sqrt{3}$.
Step 2$\sqrt{16} = 4$ and $0.\overline{3} = \frac{1}{3}$ are rational.
Answer(a), (d)
Example 8 · Multiple correct

Which of these have terminating decimal expansions?

Select all correct options.

  1. $\frac{17}{64}$
  2. $\frac{5}{24}$
  3. $\frac{7}{40}$
  4. $\frac{3}{15}$

Solution.

Step 1A fraction in lowest terms terminates when its denominator has no prime but 2 and 5: $64 = 2^6$, $40 = 2^3 \times 5$ and $\frac{3}{15} = \frac{1}{5}$.
Step 2$24 = 2^3 \times 3$, so $\frac{5}{24}$ repeats.
Answer(a), (c), (d)
