Example 10

$ABCD$ is a quadrilateral whose diagonal $AC$ lies inside it. Prove that $\angle A + \angle B + \angle C + \angle D = 360^\circ$.

Solution.

Step 1 $\angle BAC + \angle B + \angle BCA = 180^\circ$ angle sum in $\triangle ABC$
Step 2 $\angle CAD + \angle D + \angle ACD = 180^\circ$ angle sum in $\triangle ACD$
Step 3 $\angle BAC + \angle CAD = \angle A$ and $\angle BCA + \angle ACD = \angle C$ $AC$ lies inside both angles
Step 4 adding Steps 1 and 2 gives $\angle A + \angle B + \angle C + \angle D = 180^\circ + 180^\circ$ using Step 3
Answer $\angle A + \angle B + \angle C + \angle D = 360^\circ$

Example 11

An exterior angle of a triangle is $3x$, and the two interior opposite angles are $x$ and $40^\circ$. The exterior angle is

  1. $20^\circ$
  2. $60^\circ$
  3. $120^\circ$
  4. $140^\circ$

Solution.

Step 1 $3x = x + 40$ exterior angle theorem
Step 2 $2x = 40$, so $x = 20$
Step 3 $3x = 60$
Answer (b)
Check the interior angles are $20^\circ$, $40^\circ$ and $120^\circ$, and $120^\circ$ is the supplement of $60^\circ$

Option (a) is $x$; option (c) is $3x$ with $x$ read as $40$; option (d) is $180^\circ - 40^\circ$, from using the linear pair instead of the theorem.
