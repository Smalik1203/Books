In both cases the expression turned out to be a perfect square, so the factor appears twice: $x^2 + 4x + 4 = (x + 2)(x + 2)$. That is worth saying plainly, because it is easy to read $(x + 2)^2$ and report only one factor.

Example 7

Factorise $50p^2 + 60pq + 18q^2$.

What are $a$ and $b$ here? You would need a term whose square is $50p^2$, and that is $\sqrt{50}\,p$ — a surd, and awkward to carry through the working.

So look again before reaching for a square root. All three terms share a factor of 2:

$50p^2 + 60pq + 18q^2 = 2\left(25p^2 + 30pq + 9q^2\right)$

The bracket is friendly: $25p^2 = (5p)^2$, $9q^2 = (3q)^2$, and twice $5p \times 3q$ is $30pq$. So $a = 5p$ and $b = 3q$:

$50p^2 + 60pq + 18q^2 = 2\left[(5p)^2 + 2(5p)(3q) + (3q)^2\right]$

$= 2(5p + 3q)^2$

That is worth remembering as a habit: take out any common factor first. It can turn an expression that seems to need surds into one that does not.

Think and Reflect

Everything so far has been about $(a + b)^2$. Nothing in the argument said $b$ had to be positive — so replace $b$ by $-b$ throughout the identity. What comes out?

Since $(-b)^2 = b^2$ and $2a(-b) = -2ab$, only the middle term changes sign. That gives a second identity, free of charge:

$$(a - b)^2 = a^2 - 2ab + b^2$$

It is an identity for the same reason the first one is — no particular values were used in getting it — and it does all the same jobs: expanding brackets, squaring numbers in the head, and spotting perfect squares to factorise.
