Linear pattern

Take a linear polynomial and evaluate it at $1$, $2$, $3$, and so on. The difference between one value and the next is the same throughout. A sequence of numbers built this way — with a constant difference between consecutive terms — is a linear pattern.

There is a second thing to do with a linear polynomial besides evaluating it. Set it equal to a number, and you have a linear equation — a question rather than a rule, with an answer to be found.

Example 6

Two numbers add to $64$, and one of them is $10$ more than the other. Find them.

Solution.

Step 1 call the smaller one $x$; then the larger is $x + 10$
Step 2 $x + (x + 10) = 64$ their sum is $64$
Step 3 $2x + 10 = 64$
Step 4 $2x = 54$
Step 5 $x = 27$
Answer the numbers are $27$ and $37$

Notice what was equated to what: $2x + 10$ is a linear polynomial, and setting it equal to $64$ turned it into a linear equation with a single answer.

There is another way to look at a polynomial, and for the rest of this chapter it is the more useful one. Rather than an expression to be simplified, treat it as a machine: feed it a number, and it hands one back.

Take $2x + 3$. Put in $x = 4$ and it returns $2 \times 4 + 3 = 11$. Put in $x = -6$ and it returns $2 \times (-6) + 3 = -9$. Every input has exactly one output, and a rule of that kind is called a function of $x$.
