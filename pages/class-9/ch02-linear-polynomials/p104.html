Problem 2 · Try it first

An auto-rickshaw charges ₹$25$ for the first $2$ km and ₹$15$ for every kilometre after that. The fare for $n$ km is $15n - 5$ rupees for $n \geq 2$. The fare for a $1$ km ride is

  1. ₹$10$
  2. ₹$15$
  3. ₹$25$
  4. ₹$40$
Solution 2

The rule $15n - 5$ was found in Example 8, and it was found from the rows for $2$ km onwards. It says nothing about $1$ km. For that we go back to the words. The first $2$ km cost ₹$25$, so a $1$ km ride costs ₹$25$, option (c).

Option (a) is what the rule gives at $n = 1$. The rule works there as arithmetic, but not as a fare. Option (b) is the rate for each extra kilometre. Option (d) is the fare for $3$ km. A rule fitted to part of a table holds only on that part. Before using a rule, ask where it came from.

Problem 3 · Try it first

A candle is $24$ cm tall two hours after it is lit and $15$ cm tall five hours after. It burns at a steady rate. Its height when it was lit was

  1. $18$ cm
  2. $27$ cm
  3. $30$ cm
  4. $33$ cm
Solution 3

A steady rate means linear decay, so the height is $at + b$ with $a$ negative. In three hours the candle lost $9$ cm, so it loses $3$ cm an hour, and $a = -3$. When it was lit, $t = 0$, which is two hours before the first reading. In those two hours it lost $6$ cm, so at the start it was

$24 + 6 = 30$ cm

Option (c). The rule is $h = 30 - 3t$, and at $t = 5$ it gives $15$. Option (b) adds only one hour's loss. Option (d) adds three hours' loss, the whole gap between the readings. Option (a) takes $6$ cm away, going forward in time instead of back.
