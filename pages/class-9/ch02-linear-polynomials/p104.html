Behind Each Answer
Five questions, with the reasoning as well as the working. Try each one before reading its solution.
Problem 1

A linear polynomial has $p(2) = 7$ and $p(5) = 16$. Then $p(0)$ is

  1. $1$
  2. $3$
  3. $4$
  4. $10$
Solution

Write it as $p(x) = ax + b$. Three steps in $x$ carry $p$ from $7$ to $16$.

$3a = 16 - 7 = 9$

$a = 3$

From $x = 2$ back to $x = 0$ is two steps, so $p$ falls by $2a$.

$p(0) = 7 - 2(3) = 1$

Option (a). Check: $p(x) = 3x + 1$ gives $p(5) = 16$. Option (b) is the slope, not the value at $0$. Option (c) takes one step back instead of two. Option (d) goes forward three steps instead of back two.

Problem 2

An auto-rickshaw charges ₹$25$ for the first $2$ km and ₹$15$ for every kilometre after that. The fare for $n$ km is $15n - 5$ rupees for $n \geq 2$. The fare for a $1$ km ride is

  1. ₹$10$
  2. ₹$15$
  3. ₹$25$
  4. ₹$40$
Solution

Putting $n = 1$ into the rule does give an answer.

$15(1) - 5 = 10$

But the rule was found in Example 8 from the rows for $2$ km onwards, and it holds only there. The fare for $1$ km comes from the words instead: the first $2$ km cost a flat ₹$25$, and a $1$ km ride is inside that first $2$ km.

fare for $1$ km $=$ ₹$25$

Option (c). Option (a) is the ₹$10$ above: the rule works there as arithmetic, but not as a fare. Option (b) is the rate for each extra kilometre. Option (d) is $15(3) - 5$, the fare for $3$ km. A rule fitted to part of a table holds only on that part.
