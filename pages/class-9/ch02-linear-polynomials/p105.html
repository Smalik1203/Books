Multiple Choice · Level 2
Two steps, and a figure to settle first.

Choose the correct option.

  1. A linear polynomial has $p(2) = 7$ and $p(5) = 16$. Then $p(0)$ is
    1. $1$
    2. $3$
    3. $4$
    4. $10$
  2. The second differences of $1, 4, 9, 16, 25$ are all equal to
    1. $1$
    2. $2$
    3. $3$
    4. they are not equal
  3. $y = ax + 3$ and $y = 2x + b$ describe the same line exactly when
    1. $a = 2$
    2. $b = 3$
    3. $a = 2$ and $b = 3$
    4. never, whatever $a$ and $b$
  4. The graph of $y = ax + b$ passes through $(0, -4)$ and $(3, 5)$. Then $a + b$ is
    1. $-1$
    2. $1$
    3. $5$
    4. $9$
  5. A phone bought for ₹$10{,}000$ loses ₹$800$ of its value each year. The first whole year at whose end it is worth less than half its price is the
    1. $5$th
    2. $6$th
    3. $7$th
    4. $8$th
  6. A row of hexagons uses $6$ matchsticks for the first and $5$ more for each one added. The stage using exactly $106$ matchsticks is
    1. $20$
    2. $21$
    3. $22$
    4. there is none
  7. The lines $y = 2x + 1$ and $y = -x + 7$ cross at
    1. $(1, 3)$
    2. $(2, 5)$
    3. $(3, 4)$
    4. $(4, 3)$
  8. In $y = ax + b$ with $a < 0$ and $b > 0$, the line
    1. rises, cutting the y-axis above $O$
    2. rises, cutting the y-axis below $O$
    3. falls, cutting the y-axis above $O$
    4. falls, cutting the y-axis below $O$
  9. $p(x) = ax + b$, with $p(1) = 4$ and $p(4) = 4$. Then $p(100)$ is
    1. $4$
    2. $100$
    3. $400$
    4. impossible to say
