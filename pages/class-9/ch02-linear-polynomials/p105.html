Problem 4 · Try it first

The points $(1, 2)$, $(4, 11)$ and $(6, k)$ lie on one straight line. Then $k$ is

  1. $15$
  2. $16$
  3. $17$
  4. $18$
Solution 4

The first two points fix the line. Three steps in $x$ raise $y$ by $9$, so $a = 3$, and $2 = 3 + b$ gives $b = -1$. The line is $y = 3x - 1$, and at $x = 6$ it gives $17$, option (c).

There is a shorter way. From $x = 4$ to $x = 6$ is two steps, and each step adds $3$:

$k = 11 + 2 \times 3 = 17$

Option (d) is $3 \times 6$, which forgets $b$. Option (a) adds $4$, the difference in $x$, as if the slope were $2$. Option (b) adds the slope only once.

Problem 5 · Try it first

A line passes through $(2, 6)$ and $(5, 0)$. It crosses the $y$-axis at

  1. $(0, 10)$
  2. $(0, 8)$
  3. $(0, 12)$
  4. $(0, 6)$
Solution 5

From $x = 2$ to $x = 5$, $y$ falls by $6$, so $a = -2$. Going back, the line rises. From $x = 2$ to $x = 0$ is two steps back, so $y$ rises by $4$:

$b = 6 + 4 = 10$

The crossing is $(0, 10)$, option (a), and the line is $y = -2x + 10$ (Fig. 2B.2). Check: at $x = 5$ it gives $0$, which is the second point. Option (b) goes back one step. Option (c) goes back three steps, the gap between the two given points. Option (d) is the $y$-coordinate of the first point, as if that point were on the axis.
