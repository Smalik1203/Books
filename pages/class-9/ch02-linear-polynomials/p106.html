Type 4 · Linear patterns: the $n$th term, and which term

Example 6

The first row of a hall has $18$ seats, and each row has $3$ more seats than the row in front of it. How many seats are in the $13$th row, and which row has $63$ seats?

Solution.

Step 1 the counts $18, 21, 24, \ldots$ rise by $3$ a row, so row $n$ has $3n + b$ seats constant difference $3$
Step 2 $3(1) + b = 18$, so $b = 15$ the first row
Step 3 row $n$ has $3n + 15$ seats, and row $13$ has $3(13) + 15 = 54$
Step 4 $3n + 15 = 63$, so $3n = 48$ and $n = 16$
Answer the $13$th row has $54$ seats, and the $16$th row has $63$
Check row $16$ is $3$ rows behind row $13$, and $54 + 3 \times 3 = 63$
Example 7

A courier charges ₹$40$ for a parcel of up to $2$ kg, and ₹$15$ for each kilogram after that. For $n \geq 2$ whole kilograms the charge is $15n + 10$ rupees. The charge for a $1$ kg parcel is

  1. ₹$25$
  2. ₹$15$
  3. ₹$40$
  4. ₹$55$

Solution.

Step 1 the rule $15n + 10$ holds only for $n \geq 2$ as the question says
Step 2 a $1$ kg parcel is within the first $2$ kg, so it pays the flat charge read the words
Answer (c)

Option (a) is $15(1) + 10$: the rule gives a number at $n = 1$, but not a charge. Option (b) is the rate for each extra kilogram. Option (d) is $15(3) + 10$, the charge for $3$ kg. A rule fitted to part of a table holds only on that part.
