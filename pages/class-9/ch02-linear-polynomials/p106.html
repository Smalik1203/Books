Problem 4

The points $(1, 2)$, $(4, 11)$ and $(6, k)$ lie on one straight line. Then $k$ is

  1. $15$
  2. $16$
  3. $17$
  4. $18$
Solution

The first two points fix the line. Three steps in $x$ raise $y$ by $9$.

$3a = 11 - 2 = 9$, so $a = 3$

$2 = 3(1) + b$, so $b = -1$

The line is $y = 3x - 1$, and $k$ is its value at $x = 6$.

$k = 3(6) - 1 = 17$

Option (c). The line need not be found in full: from $x = 4$ to $x = 6$ is two steps, so $k = 11 + 2 \times 3 = 17$ as well. Option (d) is $3 \times 6$, which forgets $b$. Option (a) adds $4$, the difference in $x$, as if the slope were $2$. Option (b) adds the slope only once.

Problem 5

A line passes through $(2, 6)$ and $(5, 0)$. It crosses the $y$-axis at

  1. $(0, 10)$
  2. $(0, 8)$
  3. $(0, 12)$
  4. $(0, 6)$
Solution

From $x = 2$ to $x = 5$ is three steps, and $y$ falls by $6$.

$3a = 0 - 6 = -6$, so $a = -2$

The $y$-axis is at $x = 0$, two steps back from $x = 2$. Going back, a falling line rises.

$b = 6 - 2(-2) = 10$

The crossing is $(0, 10)$, option (a), and the line is $y = -2x + 10$ (Fig. 2B.2). Check: at $x = 5$ it gives $0$, which is the second point. Option (b) goes back one step. Option (c) goes back three steps, the gap between the two given points. Option (d) is the $y$-coordinate of the first point, as if that point were on the axis.
