Using What You Know
The chapter's results, in questions that do not say which one to use.

The chapter ended with one expression, $ax + b$, and a few facts about it. A linear pattern has a constant difference. Two readings fix $a$ and $b$. The graph is a straight line, with slope $a$ and $y$-intercept $b$. Every question below can be answered with those facts alone. What is new is that the question no longer says which fact to use. Try each one before reading on.

The table gives $y$ at four values of $x$. Find the rule, and find $y$ when $x = 20$.

$x$$3$$5$$7$$9$
$y$$11$$17$$23$$29$

The differences down the $y$ row are $6$, $6$, $6$. So the pattern is linear. But $6$ is not the slope, because $x$ goes up by $2$ each time, not by $1$. Two steps of $x$ add $6$ to $y$, so one step adds $3$. That gives $a = 3$. For $b$, take any one row. At $x = 3$ we have $11 = 3 \times 3 + b$, so $b = 2$. The rule is

$$y = 3x + 2$$

and at $x = 20$ it gives $62$. Check with another row: at $x = 9$, $27 + 2 = 29$. Notice that we did not solve two equations, as Example 11 did. The constant difference gave $a$ by itself, and then one row was enough for $b$. The step in $x$ has to be watched, though. A table that goes up in twos shows twice the slope.
