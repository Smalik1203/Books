Example 14 · Matching

For $p(x) = 3x^2 - 5x + 2$, match each value with List II. Each entry has exactly one match.

List IList II
(P) $p(0)$(1) 4
(Q) $p(1)$(2) 10
(R) $p(2)$(3) 0
(S) $p(-1)$(4) 2

Choose the correct combination.

  1. P–4, Q–1, R–3, S–2
  2. P–3, Q–4, R–1, S–2
  3. P–4, Q–3, R–1, S–2
  4. P–2, Q–3, R–1, S–4

Solution.

Step 1$p(0) = 2$ and $p(1) = 3 - 5 + 2 = 0$.
Step 2$p(2) = 12 - 10 + 2 = 4$ and $p(-1) = 3 + 5 + 2 = 10$.
Answer(c) P–4, Q–3, R–1, S–2
Example 15 · Matching

Match each line with the point that lies on it. Each entry has exactly one match.

List IList II
(P) $y = 2x + 1$(1) $(5, 0)$
(Q) $y = -x + 4$(2) $(3, 7)$
(R) $y = 3x - 7$(3) $(1, -4)$
(S) $y = -2x + 10$(4) $(-2, 6)$

Choose the correct combination.

  1. P–2, Q–4, R–3, S–1
  2. P–4, Q–2, R–3, S–1
  3. P–2, Q–3, R–4, S–1
  4. P–1, Q–4, R–3, S–2

Solution.

Step 1Substituting, $(3, 7)$, $(-2, 6)$, $(1, -4)$ and $(5, 0)$ each fit exactly one line, in that order.
Answer(a) P–2, Q–4, R–3, S–1
