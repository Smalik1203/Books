The word function is not reserved for linear expressions. Feeding a number to $10x - x^{2}$ works exactly the same way, and it too returns one output for each input — it is a quadratic function rather than a linear one. The difference is not in the machine but in what comes out of it, which is what the rest of the chapter is about.
