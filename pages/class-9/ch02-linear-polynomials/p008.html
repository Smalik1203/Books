How many tiles are in the next three stages? Write the sequence of tile counts as far as Stage 7 before reading on.

Counting the first seven stages gives this.

Two tiles are added each time, so the counts run $1, 3, 5, 7, 9, \ldots$ — a linear pattern, with constant difference $2$.

Knowing the difference is $2$ is not the same as being able to answer for Stage $40$ without drawing thirty-nine pictures first. For that the count has to be tied to the stage number, and the table already says how: each count is one less than twice its stage. Stage $2$ gives $2 \times 2 - 1 = 3$, Stage $5$ gives $2 \times 5 - 1 = 9$, and in general

$$\text{tiles at Stage } n = 2n - 1$$

which is a polynomial of degree $1$ — a linear polynomial. That is the whole pattern in four characters, and it is the first time in this chapter that an expression has been found rather than handed over. The relationship between the stage number and the tile count is a linear relationship.
