## 4.2 The Parts of an Expression

### Exercise Set 4.1

1. Terms, each with its sign:
   - (a) $4p$, $-7q$
   - (b) $m^2$, $-mn$, $n^2$
   - (c) $-3t^2$, $t$, $-8$
   - (d) $ab$, $bc$, $ca$

2. Coefficient of $x$: (a) $5$ (b) $-1$ (c) $3$ (d) $1$.

3. (a) monomial (b) trinomial (c) binomial (d) monomial.

4. (a) $x^3 - 2x$ is a polynomial. (b) $\dfrac{4}{y} + y$ is not: $y$ is in a
   denominator, since $\dfrac{4}{y} = 4y^{-1}$. (c) $6$ is a polynomial, of degree $0$.
   (d) $\sqrt{n} + n^2$ is not: $n$ is under a root sign.

5. Degree: (a) $2$ (b) $3$ (c) $1$ (d) $0$.

6. (a) $2n + 7$ (b) $n^2 - 5$ (c) $\dfrac{n}{2} + \dfrac{n}{3}$, which is
   $\dfrac{5n}{6}$.

7. Answers will vary. The letter part must have degree $4$ in $x$ and $y$:
   $-6x^4$, $-6x^3y$, $-6x^2y^2$, $-6xy^3$, $-6y^4$. For example
   **$-6x^4$, $-6x^2y^2$, $-6xy^3$**.

8. Answers will vary. At $x = 3$, $2x = 6$ and $x^2 = 9$, so they differ. They
   agree when $x^2 = 2x$, which is at **$x = 0$ and $x = 2$** (both sides $0$, and
   both sides $4$).

9. Answers will vary. For example $x^2y^2 + x^2 + y$: the term $x^2y^2$ has degree
   $4$, and no letter has a power above $2$.

10. Adding like terms adds the coefficients and leaves the letter part alone:
    $x^3 + x^3 = 2x^3$, so the degree is **$3$**. Powers add when terms are
    **multiplied**: $x^3 \times x^3 = x^6$.

### Think and Reflect (4.2.2)

The width is $x - 3$. Perimeter $= 2(x + x - 3) = 4x - 6$, a polynomial of
degree $1$. Area $= x(x - 3) = x^2 - 3x$, of degree $2$. A perimeter adds
lengths, so each term has one letter. An area multiplies a length by a length,
so a letter is multiplied by a letter.

   leaves area $ab - ac$.

## 4.6 Three Results Worth Knowing

### Exercise Set 4.5

1. (a) $x^2 + 6x + 9$ (b) $4a^2 + 4a + 1$ (c) $m^2 + 10mn + 25n^2$
   (d) $16p^2 + 24pq + 9q^2$.

2. (a) $y^2 - 12y + 36$ (b) $9t^2 - 12t + 4$ (c) $a^2 - 14ab + 49b^2$
   (d) $25x^2 - 40xy + 16y^2$.

3. (a) $x^2 - 64$ (b) $4m^2 - 9$ (c) $a^2 - 25b^2$ (d) $49 - k^2$.

4. - (a) the square of a sum: $9 + 6z + z^2$
   - (b) none of the three: $x^2 + 9x + 14$
   - (c) the difference of two squares: $16a^2 - b^2$
   - (d) none directly. $(p - q)(q - p) = -(p - q)^2$, so it is $-p^2 + 2pq - q^2$.

5. (a) $(x + 6)^2$ (b) $(y + 10)(y - 10)$ (c) $(2a - 1)^2$ (d) $(3m + 5n)(3m - 5n)$.

6. $(x^2 + 8x + 16) - (x^2 - 8x + 16) = 16x$. With $a = x + 4$ and $b = x - 4$:
   $a + b = 2x$ and $a - b = 8$, and $(a + b)(a - b) = 16x$.

7. $(a^2 + 2ab + b^2) - (a^2 - 2ab + b^2) = 4ab$. So $4ab = 9^2 - 5^2 = 56$,
   and **$ab = 14$**.

8. **(a) and (b) are equal:** both are $a^2 - 2ab + b^2$. (c) is
   $-a^2 + 2ab - b^2$, which is different (unless $a = b$).

9. The drawing is a square of side $7$, cut at $5$ each way. The pieces have
   areas $25$, $10$, $10$ and $4$, and $25 + 10 + 10 + 4 = 49 = 7^2$.

10. The square of side $b$ has to be cut out of the square of side $a$, so $b$
    cannot be larger than $a$; and $a - b$ would be negative, which no length
    can be. At $a = 3$, $b = 7$: $(3 + 7)(3 - 7) = -40$ and $3^2 - 7^2 = 9 - 49 = -40$.

## 4.7 Putting Them to Work

### Think and Reflect (4.7.2)

$(a - b)^2 = a^2 - 2ab + b^2$; add $2ab$ to both sides to get
$a^2 + b^2 = (a - b)^2 + 2ab$. With $a + b = 7$ and $ab = 10$: $a^2 + b^2 = 29$,
so $(a - b)^2 = 29 - 20 = 9$ and $a - b = 3$ (or $-3$).

With $a + b = 4$ and $ab = 9$: $a^2 + b^2 = 16 - 18 = -2$, and
$(a - b)^2 = -2 - 18 = -20$. A square cannot be negative, so **no such pair of
numbers exists**.

   (c) $100 \times 44 \div 44 = 100$ (d) $10 \times 9.2 \div 10 = 9.2$.

6. $x^2 + y^2 = 5^2 + 2 \times 14 = 53$ and $(x + y)^2 = 53 + 28 = 81$.

7. Grassed area $= a^2 - b^2 = (a + b)(a - b)$. At $a = 25$, $b = 15$:
   $40 \times 10 = 400$ m² (and $625 - 225 = 400$).

8. $11 \times 13 = 143 = 144 - 1 = 12^2 - 1$. Two consecutive odd numbers are
   $n - 1$ and $n + 1$ for the even number $n$ between them, and
   $(n - 1)(n + 1) = n^2 - 1$.

9. $9991 = 10000 - 9 = 100^2 - 3^2 = (100 + 3)(100 - 3) = 103 \times 97$. What
   suggested it is that $9991$ is just below the square $10000$, and the gap
   $9$ is itself a square.

10. $(x - y)^2$ is a square, so it is never negative. Expanding,
    $x^2 - 2xy + y^2 \geq 0$, so $x^2 + y^2 \geq 2xy$.

11. $(x + y)^2 - (x - y)^2 = 4xy$, which is $4$ times $xy$. For whole numbers
    $x$ and $y$, that is a multiple of $4$.

12. Let the sides be $a$ and $b$. Then $2(a + b) = 24$, so $a + b = 12$, and
    $ab = 32$. So $a^2 + b^2 = 12^2 - 2 \times 32 = 80$ cm². (The sides are $8$
    and $4$, and $64 + 16 = 80$.)

13. $99 \times 101 = (100 - 1)(100 + 1) = 100^2 - 1$, so **$100^2$ is larger, by $1$**.

14. $(n + 1)^2 - n^2 = 2n + 1$, which is odd, and $2n + 1 = n + (n + 1)$, the sum
    of the two numbers.

15. $x^2 + 8x + 20 = (x + 4)^2 + 4$. A square is never negative, so the smallest
    value is **$4$, when $x = -4$**.

16. (a) an identity: it is the square of a sum. (b) an equation: the two sides
    differ by $2x$, so it is true only at $x = 0$. (c) an equation, true only at
    $x = 5$.
