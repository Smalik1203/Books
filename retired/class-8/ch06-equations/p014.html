6.7No Answer, and Every Answer

Section 6.2 promised that a linear equation in one variable has exactly one solution, and every equation in this chapter's exercises has kept that promise. The promise can be broken, though, and it can be broken in two ways. Neither gives any warning: both look like perfectly ordinary questions until the last line of working, at which point the letter vanishes from the page and there is apparently nothing left to solve for.

6.7.1 When the letters all cancel and the numbers disagree

Example 13

Solve $2x + 3 = 2x + 5$.

Solution.

Step 1 $3 = 5$ $-2x$ both sides
Answer No solution

The last line is false, and nothing has been done wrong to get there. The letter has gone, so there is no value left to choose; and what remains is a statement that is false whatever $x$ was. The equation has no solution.

The balance makes it plain. Both pans hold two bags, and the left pan has three grams beside them while the right has five. Take the two bags off each pan and you are left with three grams against five grams, which no bag can rescue: the beam was never level and no weight of bag would have made it level.

6.7.2 When the letters all cancel and the numbers agree

Example 14

Solve $2(x + 3) = 2x + 6$.

Solution.

Step 1 $2x + 6 = 2x + 6$ expand
Step 2 $6 = 6$ $-2x$ both sides
Answer Every number is a solution

The last line is true — and true whatever $x$ was. So every number is a solution. Try $x = 1$, $x = -40$, $x = \tfrac12$; all of them work, because the two sides were never two different expressions at all. They were the same expression written two ways.
